浮动区间内的绩点

N是该等级内不同总评分数值的个数，r是从高到低的数值位次，不是学生人数或全班排名。

计算公式
N = 1：g = (L + U) / 2
2 ≤ N < 5：g = U − (U−L)r / (N+1)
N ≥ 5：g = U − (U−L)(r−1) / (N−1)

L/U为该等级绩点下/上限。先依课程规则定等级，再在区间内映射。

来源：复旦大学官方成绩制度说明，等级区间与浮动绩点规则。

国家学生体质健康标准 · 大学生组

国家体测计算器。

按性别与年级组计算七项标准分、力量与长跑附加分。国家体测成绩与体育课程最终等第分别判断。

按达到的最高列示档位试算，不作线性插值；低于最低档按0分试算。BMI保留1位小数用于本工具分档。长跑“3:17”是3分17秒；两项附加分各至多10分。

来源：《国家学生体质健康标准（2014年修订）》；复旦大学体育教学部《国家学生体质健康标准》测试（大学生）评分标准，页面标注2026-09-16。
