课程简介（中文）

通过本课程的学习，使学生系统掌握数据结构与算法的基本概念、基本原理和典型方法，理解常用数据结构的逻辑结构特性、存储方式及其基本运算，掌握典型算法的设计思想和实现方法。

课程以 Python 程序设计语言为主要实现工具，引导学生将抽象的数据结构与算法思想转化为可执行的程序实现，使学生具备对常见数据结构和算法进行正确实现和基本分析的能力。通过对算法时间复杂度和空间复杂度的学习，使学生建立对算法效率和资源消耗的基本认识。

通过本课程的系统训练，使学生初步具备运用数据结构与算法方法对实际问题进行建模和求解的能力，为后续专业课程的学习奠定必要的理论基础和方法基础。

课程简介（英文）

Through the study of this course, students will systematically master the basic concepts, fundamental principles and typical methods of data structures and algorithms, understand the logical structure characteristics, storage modes and basic operations of common data structures, and grasp the design concepts and implementation approaches of typical algorithms.
Taking Python programming language as the main implementation tool, this course guides students to transform abstract data structure and algorithm ideas into executable program implementations, enabling students to possess the ability to correctly implement and conduct basic analysis on common data structures and algorithms. By learning the time complexity and space complexity of algorithms, students will establish a basic understanding of algorithm efficiency and resource consumption.
Through the systematic training of this course, students will initially acquire the ability to model and solve practical problems using data structure and algorithm methods, laying a necessary theoretical and methodological foundation for the study of subsequent professional courses.

教学目标

 

 

基本要求： 

1．掌握 Python 程序设计的基本方法，能够使用 Python 语言正确实现常见数据结构及其典型算法，并理解程序实现与数据结构抽象之间的对应关系。

2．掌握算法时间复杂度和空间复杂度的基本分析方法，能够对常见算法进行基本的复杂度分析与比较。

3．能够运用链表、栈、队列、串、树和图等数据结构进行问题建模和程序设计，完成典型数据结构相关问题的实现。

4．掌握常见排序算法和检索算法的基本思想和实现方法，能够根据问题特点选择合适的数据结构与算法解决实际问题。

教学方式

以课堂授课为主，辅以编程练习、课程项目。

教学内容与进度安排

1．数据结构与算法基础
介绍数据结构与算法的基本概念、学习方法和分析思路，讲授算法时间复杂度和空间复杂度的基本分析方法，结合 Python 程序设计语言建立对算法性能的直观认识。

2．线性结构及其应用
系统讲授线性表及其典型实现方式，包括链表、栈、队列和串等数据结构，结合递归与迭代模型，分析其在程序设计中的典型应用。

3．树结构与图结构基础
讲授树和图的基本概念、存储结构和遍历方法，介绍常见的树结构应用以及图的基本算法，如图的遍历和最短路径等。

4．排序、检索与哈希方法
介绍常见的排序算法和检索方法，包括插入排序、Shell 排序、堆排序、快速排序等，以及二叉搜索树和哈希表等基本索引结构。

5．算法设计思想入门
介绍分治法、动态规划和贪心策略等基本算法设计思想，并结合典型问题进行应用分析。
