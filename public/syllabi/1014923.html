课程简介（中文）

课程讲解数据安全的基础理论、应用技术与治理方法。包括但不限于：数据加密与安全多方计算、身份认证与访问控制、数据分析方法、数据驱动的安全、隐私计算、数据管理标准、数据安全法案等，通过深入讲解数据安全与治理相关的理论、技术方法，建立学生的数据安全观，树立从事该方向前沿的志向。本课程形式包括课程宣讲、论文导读和主题研讨等。

课程简介（英文）

The course covers the fundamental theories, applied technologies, and governance methods of data security. Topics include, but are not limited to: data encryption and secure multi-party computation, identity authentication and access control, data analysis methods, data-driven security, privacy computing, data management standards, and data security legislation. Through in-depth exploration of theories and technical approaches related to data security and governance, the course aims to cultivate students' understanding of data security and inspire them to pursue cutting-edge advancements in this field. The course format includes lectures, paper discussions, and thematic seminars.

教学目标

数据安全和治理课程以前沿知识讲解和研讨为主，培养研究生同学掌握扎实的数据安全相关的扎实的理论、技术方法、实用场景和管理方法。使同学了解该方向的前沿知识，培养同学的批判性思维，帮助同学走上数据安全与治理方向的研究道路。
