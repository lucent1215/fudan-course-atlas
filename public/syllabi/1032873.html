课程简介（中文）

本课程主要介绍机器学习和深度学习领域模型以及在软工领域的应用，包括词向量和预训练语言模型、循环神经网络、Seq2Seq, Transformer和图神经网络等模型以及强化学习等，以及如何将这些模型应用于代码补全、代码总结、方法名预测、类型推断、测试生成、程序合成等问题。

课程简介（英文）

The course introduce the concepts, models, and algorithms of machine learning and deep learning. And we will focus on the applications on tasks from software engineering. The topics include word vector and pre-training language, recursive neural networks, seq2seq, Transformer, graph neural networks, and reinforcement learning. We will discuss the applications of these techniques on code completion, code summarization, code generation, method name recommendation, test generation etc.

教学目标

通过介绍机器学习和深度学习领域模型以及在软工领域的应用，包括预训练语言模型、循环神经网络、Seq2Seq, Transformer和图神经网络等模型以及强化学习等，让选课同学熟悉各种机器学习、深度学习模型和强化学习算法等，能将模型和算法应用于软件工程领域的问题，为后续的研究工作打好基础。
