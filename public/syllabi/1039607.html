课程简介（中文）

C语言程序设计是计算机及相关专业的重要专业基础课。本课程以C语言为载体，系统讲授程序设计的基本概念、语法规范与核心方法。课程内容涵盖数据类型、运算符、流程控制（顺序、选择、循环）、数组、函数、指针、结构体及文件操作等核心知识模块。
课程坚持理论与实践深度融合，通过大量的编程训练与上机实践，重点培养学生的结构化程序设计思想与计算思维。旨在帮助学习者掌握运用计算机解决实际问题的逻辑与方法，为后续深入学习AI，数据结构及各类高级编程语言奠定坚实的编程基础。

课程简介（英文）

C Programming is a fundamental professional course for computer science and related majors. This course uses the C language as a vehicle to systematically teach the basic concepts, syntax specifications, and core methods of program design. It  covers essential modules including data types, operators, flow control (sequence, selection, and loops), arrays, functions, pointers, structures, and file operations. The course focuses on cultivating students' structured programming mindset and computational thinking through extensive programming exercises and hands-on lab work. It aims to help learners master the logic and methods of using computers to solve real-world problems, laying a solid programming foundation for further in-depth study of AI, data structures, and various high-level programming languages.

教学目标

面向技术大类大一新生，以C语言为载体，以计算思维的培养为导向，通过程序设计的教学和实践，掌握使用程序设计的方法和解决问题的能力。同时训练学生养成良好的算法思想及合作开放的编程习惯和代码风格。

学生将系统掌握C语言的语法规范、数据类型、运算符及三种基本程序控制结构；深入理解并熟练运用数组、函数、指针、结构体及文件操作等核心知识，具备独立编写、调试结构化程序的能力。通过理论与实践的深度融合，使学生能够运用计算机解决实际问题，同时使学生具备利用AI工具解决真实场景问题的综合实践能力，为适应智能化时代的职业发展奠定坚实基础。

教学方式

每周3学时的课堂授课和2学时的上机实践。

教学内容与进度安排

第1周：课程简介，计算机基本原理，简单例子和编程环介绍。介绍软件危机，程序员的合作精神和意义，以及复旦计算机人早年对国产计算机的初创贡献。

第2周：第2章：C语言基本数据类型和输入输出基础。掌握基本数据类型的书写方法及准确含义，各种输入，输出方法及格式

第3周：第2章：C语言基本运算和表达式。掌握各种运算（算数，关系，逻辑，赋值）等运算的含义，范围；表达式的书写方式

第4周：第3章：基本语句和选择结构。了解计算机解决问题的基本方式，算法的基本逻辑；

第5周：第3章：循环结构。掌握用钢结构话控制结构编写程序的方法，并能编写简单的程序。

第6周：第4章：一维数组，通过排序算法，拓展的计算机技术的创新和发展的介绍，启发同学对创新的兴趣。

第7周：第4章：多维数组和字符串。掌握多维数组上的简单操作何字符串处理技术，当前何数组及字符串相关的实际问题何解决方法。

第8周：第5章： 函数和库函数基础，期中复习。通过函数的学习，了解结构化编程思想及中小应用程序的功能。

第9周： 期中考试

第10周：第6章：指针基础。了解指针的内容实现机理

第11周：第6章数组高级和指针行参 学习指针，数组，函数之间的有机组合来解决复杂问题。

第12周：第7章：结构和链表（1） 通过对比数组和链表，了解复杂数据结构的操作及在实际问题中的应用。

第13周：第7章：结构和链表（2），存储类别和作用域 

第14周：指针高级

第15周：第8章：文件处理技术

第16周：例题选讲和期末复习  通过例题选讲来进一步拓展对数据结构，计算思维以及程序设计的统一实现。
