课程简介（中文）

本课程包括统计基础，R 语言的介绍，数据的输入输出，R 的作图，基于R 语言的统计分析：包括如描述性统计分析, 属性数据和列联表，线性回归，方差分析，广义线性模型，主成分和因子分析，聚类分析, 以及一些R 的高级编程技巧。

课程简介（英文）

This course covers the basics of statistics, an introduction to the R language, data input and output, graphical representations in R, and statistical analysis using R. This includes topics such as descriptive statistical analysis, categorical data and contingency tables, linear regression, analysis of variance, generalized linear models, principal component and factor analysis, cluster analysis, as well as some advanced R programming techniques.
