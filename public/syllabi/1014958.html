课程简介（中文）

本课程衔接程序设计与面向对象程序设计（OOP），进一步培养下面的能力：

  1. ​设计模式应用——将OOP理论转化为可复用架构；
  2. ​测试驱动开发（TDD）​——通过测试先行确保代码可靠性与可维护性；
  3. ​UML领域建模——用可视化工具精准抽象业务逻辑。

这些能力直接提升软件工程核心素养​：

  • 应对迭代过程的架构​
  • 降低维护成本的代码可控性​

跨角色沟通的统一语言能力

课程简介（英文）

This course builds upon foundational courses in ​Programming and Object-Oriented Programming (OOP)​, further developing the following advanced skills:

  1. ​Design Pattern Application​ — Transforming OOP theory into reusable architectures (e.g., decoupling object creation via the Factory Pattern).
  2. ​Test-Driven Development (TDD)​​ — Ensuring code reliability and maintainability through a "test-first" approach.
  3. ​UML Domain Modeling​ — Precisely abstracting business logic using visual tools.

These skills directly enhance ​core software engineering competencies:

  • Architectural resilience​ to adapt to iterative changes.
  • Code maintainability​ to reduce long-term costs.

Ubiquitous language proficiency​ for cross-role collaboration.

教学目标

培养学生掌握软件架构和软件设计的相关技能，内容包括：

  1. 设计模式
  2. 重构
  3. 测试驱动的开发
  4. 软件架构
  5. 对象模型的设计及面向对象职责分配方法
  6. 基于微服务分布式软件架构（根据课程进度可选）

并通过实践环节，训练学生能够开发具有一定的复杂度的软件系统。在教学过程中对比对比国内与国外先进的软件系统在设计和架构上的差距，以及国内取得的进步，鼓励大家形成科技兴国的责任。

教学方式

教学内容与进度安排

W1 课程简介，设计模式简介（访问者模式）​​

​教学目标​：

  • 理解设计模式的本质价值​（解耦、复用、应对变化）
  • 掌握访问者模式的双重分派机制，能分析其在编译器/文件系统等场景的应用逻辑
  • 建立课程学习与OOP基础的认知联结​（如模式如何封装OOP的继承/多态）

W2 观察者模式, 装饰模式，组合模式​

​教学目标​：

  • 应用观察者模式实现事件驱动架构，解决对象间状态同步问题​（如GUI事件）
  • 通过装饰模式动态扩展对象功能，理解其与继承的替代关系​（I/O流案例）
  • 运用组合模式构造树形结构，培养递归设计思维​（设备/文件系统案例）

W3 迭代器模式，命令模式，模板模式​

​教学目标​：

  • 实现迭代器模式封装集合遍历，理解单一职责原则的实践价值
  • 用命令模式解耦请求发送与执行，支持撤销/重做功能（编辑器案例）
  • 通过模板模式定义算法骨架，掌握钩子方法（hook）​​ 的扩展技巧

W4 适配器模式，备忘录模式​

​教学目标​：

  • 使用适配器模式解决接口不兼容问题，辨析类适配器与对象适配器差异
  • 通过备忘录模式实现对象状态快照，设计撤销机制的数据存储方案

W5 策略模式，创建者模式，Spring依赖注入​

​教学目标​：

  • 掌握策略模式实现算法族切换，理解其对开闭原则（OCP）​​ 的支撑
  • 区别工厂方法/抽象工厂/建造者模式的适用场景（复杂对象构造案例）
  • 将模式思维迁移到Spring IoC容器，解释其控制反转与依赖注入的本质

W6 测试驱动开发(1)​​

​教学目标​：

  • 实践TDD循环​（红-绿-重构），编写可测试的隔离单元​（JUnit案例）
  • 解释测试先行的设计优势​（驱动接口抽象、降低耦合度）

W7 测试驱动开发(2)+重构(1)​​

​教学目标​：

  • 应用Mock对象​（Mockito）解耦依赖，完成集成测试​
  • 执行坏味道识别→重构，使用提取方法/引入多态等重构技法

W8 重构(2)​​

​教学目标​：

  • 实施模式导向的重构​：
    • 用策略模式替换条件表达式
    • 用工厂模式简化对象创建
  • 掌握重构的安全性保障​：测试覆盖率不低于80%

W9 SOLID设计原则​

教学目标​：

  • 逐条解析SOLID原则​：
  • 分析SOLID原则如何支撑设计模式与TDD​

​W10 设计模式/测试驱动开发Lab讨论​

​教学目标​：

  • 分组评审Lab1代码，指出模式误用/漏用/测试漏洞
  • 基于SOLID原则/设计模式提出重构方案，形成改进报告​

W11 软件架构概述​

​教学目标​：

  • 对比三层架构与MVC模式的分层逻辑
  • 绘制包图/组件图表达架构边界

W12 业务层：面向对象的领域模型​（1）

​教学目标​：

  • 使用UML类图表达领域概念间关系

W13 业务层：面向对象的领域模型（2）​

​教学目标​：

  • 使用UML类图表达领域概念间关系：POS系统案例

W14 业务层：对象设计及职责分配​

​教学目标​：

  • 应用GRASP原则分配对象职责：
    • ​高内聚​（信息专家模式）
    • ​低耦合​（控制器模式）

W15 DDD及微服务架构+领域模型Lab讨论

教学目标​：

  • 解释限界上下文（Bounded Context）​​ 如何切分微服务
  • 设计领域事件（Domain Event）​​ 驱动服务通信
  • 前4组讨论：分组评审Lab代码

W16 领域模型Lab讨论​

​教学目标​：

分组评审Lab2
