课程简介（中文）

本课程以C语言为程序描述语言，内容包括：基本数据类型、运算符和表达式，基本数据输入输出方法；控制结构、函数基础知识和正文文件用法；数组、字符串、指针及其应用；函数参数设定和应用、函数指针用法、递归函数基本知识、作用域规则和编译预处理命令；结构和动态数据结构基础及链表应用；数据文件技术。

课程简介（英文）

This course uses C language as the program description language, and the content includes: basic data types, operators and expressions, basic data input and output methods; control structure, function basics, and text file usage; arrays, strings, pointers and their applications; Function parameter setting and application, function pointer usage, recursive function basics, scope rules, and compilation preprocessing commands; Structure and dynamic data structure foundations and linked list applications; functions for handling data files.

教学目标

通过本课程的教学，了解C语言程序设计的基本规范、方法与技巧。结合上机实践，让学生初具独立构造算法、开发程序和程序调试及解决问题的能力。另外，通过课堂讲述，让学生深刻认识到程序设计在软件行业和计算机职业生涯中的重要性以及我国软件技术与国外存在的差距，激发学生努力学习，今后为中国计算机事业和软件产业的发展和进入世界前列作出贡献。

教学方式

课堂讲授、线上线下答疑、上机实践。

教学内容与进度安排

第一周：从学术和产业两个角度分析程序设计的重要性；程序设计基础，包括计算机和程序设计基础知识、C语言的历史和特点、Ｃ语言的词汇、数据类型、常量和变量、程序开发环境基础知识；介绍计算机科学奠基者之一图灵。目的：使学生概要了解程序设计的重要性和基本概念及核心内容。

第二周：基本数据类型及其运算；介绍计算机科学奠基者之一冯·诺伊曼。目的：使学生了解C语言的基本数据类型与运算。

第三周：数据输入和输出基础；综合习题讲解；介绍第一位图灵奖得主Alan J. Perlis。目的：使学生了解C语言中的数据输入和输出基本函数。

第四周：国庆节放假。

第五周：结构化程序设计，具体内容包括基本语句、顺序结构、选择结构、循环结构；介绍图灵奖得主Niklaus Wirth，他是PASCAL语言的发明者和结构化程序设计的提出者。目的：使学生了解C语言中的三类程序结构：顺序结构、选择结构和循环结构。

第六周：简单程序设计实例讲解；介绍首位中国图灵奖得主姚期智教授。目的：使学生了解C语言编写简单的程序。

第七周：数组的基本概念，一维数组和多维数组。目的：使学生了解C语言中的一维数组和多维数组。

第八周：字符数组，字符串处理技术基础，习题讲解。目的：使学生了解C语言中的字符数组。

第九周：期中考试。

第十周：函数：函数定义、函数调用、递归函数基础等。目的：使学生了解C语言中的函数定义与设计及调用。

第十一周：函数程序设计实例，存储类别和作用域，编译预处理命令简介等。目的：使学生了解C语言中的存储类别和作用域。

第十二周：指针和引用（第一部分）：具体内容包括指针的基本概念，指向一维数组元素的指针，指向二维数组一整行的指针。目的：使学生了解C语言中的指针和如何用指针访问一维、二维数组。

第十三周：指针和引用（第二部分）：具体内容包括指针数组，数组指针，指针形参，数组形参，函数指针，返回指针值的函数等。目的：使学生了解C语言中的指针数组，数组指针，指针形参，数组形参，函数指针等。

第十四周：结构和链表（第一部分）：具体内容包括结构类型和结构变量，结构数组，结构与函数，链表等。目的：使学生了解C语言中的结构类型和结构变量，结构数组，结构与函数及链表。

第十五周：结构和链表（第二部分）：具体内容包括联合、位域、枚举，类型定义和变量定义，结构指针形参和返回结构的函数等。目的：使学生了解C语言中的联合、位域、枚举，类型定义和变量定义。

第十六周：数据文件处理技术：具体内容包括文件类型和文件类型指针变量、常用的数据文件库函数、文件处理程序结构等。目的：使学生了解如何在C语言中从文件中读数据和向文件写数据。
