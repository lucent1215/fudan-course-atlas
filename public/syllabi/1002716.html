  • 期末考试Final Examination：闭卷 60.0%

课程简介（中文）

本课程面向零基础计算机专业方向大一本科生，系统讲授C语言程序设计，包括类型与表达式、控制流、函数、指针、数组、结构体等内容。通过课堂教学与上机实践相结合，培养学生的编程能力与调试技能。课程注重动手训练和动手能力的提升，配套作业、答疑和实践环节，为后续计算机专业课程打下坚实基础。

 

课程简介（英文）

This course is designed for first-year undergraduate students majoring in computer science or related majors with no prior programming experience. It provides a systematic introduction to C programming, covering topics such as data types and expressions, control flow, functions, pointers, arrays, and structures. Combining classroom instruction with hands-on in-class exercises and lab sessions, the course aims to develop students’ programming and debugging skills. This course includes in-class exercises, assignments, Q&A support, and practice components to build a solid foundation for advanced computer science courses.

教学目标

本课程面向计算机类专业的大一新生，旨在帮助零基础学生系统掌握C语言编程，养成良好的程序设计习惯。课程通过课堂讲授与上机实践相结合，传授C语言程序设计的基本知识，强调抽象思维、系统思维、逻辑推理与问题求解能力的培养。在人工智能快速发展的时代，编程能力已成为各行各业的重要基础。通过大量实践训练，课程不仅提升学生的编程实践与自主学习能力，也帮助其在学术过程中逐步养成规范、严谨的编程习惯，为后续专业课程学习和技术研究打下坚实基础。

教学方式

本课程采用“讲授+实践”相结合的教学方式，以实现知识传授、能力培养和习惯养成的教学目标。课堂教学侧重于系统讲解C语言的基本概念与程序设计方法，帮助学生构建清晰的知识体系；上机课则强化动手能力，指导学生在真实编程环境中进行实践训练。课后通过微信群开展作业辅导与答疑，鼓励学生主动思考、独立解决问题，培养其自主学习能力。同时，引导学生使用命令行工具、AI代码编辑器、分布式版本控制系统（例如GitHub）、及在线题库等资源，提升其工程素养。
