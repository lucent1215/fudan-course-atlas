课程简介（中文）

本课程涵盖面向对象程序设计的核心理论与实践，培养学生掌握现代软件开发方法论。主要内容包括：

设计模式：学习GoF经典设计模式，培养问题解决能力。

重构：掌握代码重构原则和技巧，提升软件可维护性和可扩展性。

测试驱动开发：采用TDD开发流程，提高软件的设计质量。

领域模型与对象设计：学习领域驱动设计思想，掌握对象建模和职责分配方法。

通过理论学习与实践项目结合，培养学生设计高质量面向对象软件系统的能力。

课程简介（英文）

This course covers the core theories and practices of object-oriented programming, cultivating students' proficiency in modern software development methodologies. The main content includes:

Design Patterns: Studying GoF classic design patterns to develop problem-solving skills.
Refactoring: Mastering code refactoring principles and techniques to enhance software maintainability and extensibility.
Test-Driven Development: Adopting the TDD development process to improve software design quality.
Domain Modeling and Object Design: Learning domain-driven design concepts and mastering methods for object modeling and responsibility assignment.

Through a combination of theoretical study and hands-on projects, the course aims to develop students' ability to design high-quality object-oriented software systems.

教学目标

掌握面向对象的相关技术，了解与面向对象技术相关的软件过程。通过Lab/Pj的训练，使得学生在了解相关理论的基础上，能够将其运用到实际的项目中。

在教学过程中对比国内与国外先进的软件系统在设计和架构上的差异，以及国内取得的进步，鼓励学生形成科技兴国的责任。

教学内容与进度安排

## 教学进度安排与目标

W1
- 教学内容：课程简介，面向对象技术概述，访问者模式
- 教学目标：了解课程整体安排，理解面向对象设计思想，掌握访问者模式的原理和应用

W2
- 教学内容：观察者模式，装饰模式，组合模式
- 教学目标：掌握事件驱动编程，理解装饰器的扩展机制，理解树形结构的递归处理

W3
- 教学内容：迭代器模式，命令模式，模板模式
- 教学目标：理解集合遍历的统一接口，掌握命令模式的解耦思想，掌握模板方法的设计框架

W4
- 教学内容：适配器模式，状态模式，备忘录模式
- 教学目标：理解接口适配技术，掌握状态驱动的编程思维，理解对象状态的保存与恢复

W5
- 教学内容：策略模式，创建者模式，基于Spring Framework的依赖注入
- 教学目标：掌握算法族的设计思想，理解对象创建的分离原则，学会框架的实际应用

W6
- 教学内容：测试驱动开发基础理论，单元测试编写
- 教学目标：理解TDD开发流程，掌握JUnit测试框架，具备基本的测试编写能力

W7
- 教学内容：TDD实战练习，代码重构基本技巧
- 教学目标：能够独立完成TDD开发实践，理解代码异味和重构方法

W8
- 教学内容：重构策略与方法，代码质量评估
- 教学目标：掌握系统性重构技巧，能够识别和消除代码质量问题

W9
- 教学内容：SOLID设计原则详解
- 教学目标：深入理解单一职责、开闭原则等核心设计原则，能够应用于实际开发

W10
- 教学内容：设计模式综合应用，测试驱动开发实验讨论
- 教学目标：综合运用设计模式解决实际问题，能够分析和讨论TDD实践案例

W11
- 教学内容：软件架构概述，三层体系结构，MVC架构模式
- 教学目标：理解软件架构设计思想，掌握MVC模式的应用和优势

W12
- 教学内容：面向对象的领域建模，实体与值对象
- 教学目标：掌握DDD领域建模方法，理解领域对象的本质特征

W13
- 教学内容：对象设计原则，职责分配策略（1）
- 教学目标：掌握高内聚低耦合的设计原则，学会合理分配对象职责

W14
- 教学内容：对象设计案例分析，职责分配实践（2）
- 教学目标：能够独立完成复杂系统的对象设计，具备良好的架构设计能力

W15
- 教学内容：领域驱动开发，微服务架构设计
- 教学目标：理解DDD的实践方法，掌握微服务架构的设计原则和实现策略

W16
- 教学内容：课程总结，问题讨论，答疑解惑
- 教学目标：系统回顾所学知识，解决学习中的疑问，为后续学习奠定基础
