课程简介（中文）

课程内容主要分为两大部分。第一部分，学习申明式的函数式编程方法来理解编程语言的基本概念，包括编程的基本要素，函数抽象、递归函数和高阶函数，符号、数据抽象和闭包，对象、环境和变异(Mutation)，以及解释、Evaluation、Continuation和Lazy evaluation，以及并发和流计算等。第二部分，学习编程语言的基本机制，包括Lambda演算，语义表示，类型系统，作用域和存储管理，面向对象的基本概念，和语言的运行时。

课程简介（英文）

The course consists of two parts. In the Part I, we learn the fundamental concepts of programming language via functional programming language, which is declarative rather than imperative. It covers elements of programming, including: function abstraction, recursive function and high-order function; symbol, data abstraction and closure; object, environment and mutation; interpretation, evaluation, continuation, and lazy evaluation; and also streaming computing and concurrency. In the Part II, we learn some fundamental mechanisms of programming languages, including: Lambda calculus, semantics, type systems, scope, storage management, object-orient, and runtime system.

教学目标

程序设计语言是编程的基础，据统计出现的编程语言近九千个，活跃的语言有七百多，还有一些在创建中。为什么有这么多的编程语言，它们有什么异同？课程介绍程序语言的核心概念和基本理论，并结合实践来运用编程理论。通过本课程的学习，学生应该掌握编程语言的核心理论，可快速使用新的编程语言，甚至根据需求来定制和设计编程语言。
