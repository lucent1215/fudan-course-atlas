课程简介（中文）

本课程主要内容是信息安全概念、物理安全、计算机网络技术概述、TCP/IP协议概述、 信息加密与PKI、 防火墙技术、入侵检测技术、访问控制技术、网络安全检测与评估技术、计算机病毒防范技术、备份技术、无线网络安全与云计算安全、网络安全解决方案基本框架等，注重对概念和基本原理、主要技术方面的讲解。

课程简介（英文）

The main content of this course includes information security concepts, physical security, overview of computer network technology, overview of TCP/IP protocol, information encryption and PKI, firewall technology, intrusion detection technology, access control technology, network security detection and evaluation technology, computer virus prevention technology, backup technology, wireless network security and cloud computing security, basic framework of network security solutions, etc. It focuses on the explanation of concepts, basic principles, and main technical aspects.

教学目标

本课程是信息安全和计算机专业学生的基础课程，针对信息安全和计算机专业低年级本科生，通过对信息安全基本概念、各类信息安全技术的综述性讲解，使学生对信息安全概念以及相关的技术原理有一个总体的、基本的理解，在此基础上能够了解一定的网络安全系统配置和初步的实践开发技术。为高年级或工作后的各类信息安全专业技术的学习和应用打下坚实基础。
