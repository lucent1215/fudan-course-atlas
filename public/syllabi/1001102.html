课程简介（中文）

课程讲授：VB开发环境和基本编程步骤、基本控件和语言基础、基本控制结构、数组、过程、常用控件、菜单、多重窗体和文件等。

课程简介（英文）

This course teaches: VB development environment and basic programming steps, basic controls and language fundamentals, basic control structures, arrays, procedures, common controls, menus, multiple forms, and files, etc.

教学目标

通过本课程的教学，向学生介绍面向对象的程序设计的基本思想和方法。通过学习并结合上机实践，让学生了解计算机解决问题的一般方法，掌握界面制作、程序编写和调试，使得学生具备编写简单应用程序的能力,并为以后进一步自习其它程序语言和提高程序设计能力打下坚实的基础，同时提升学生的逻辑性思维能力和缜密性思维能力。强化学生可迁移能力的培养，也是课程思政的要求。

教学方式

机房授课，通过屏幕广播软件播放演示文稿和操作演示，上机辅导答疑。
