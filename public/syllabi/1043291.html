课程简介（中文）

本课程聚焦于Python编程的核心基础知识，系统讲授变量、分支结构、循环结构、列表、二维列表与字典等基本数据类型与语法结构。通过循序渐进的讲解与练习，帮助学生建立扎实的编程功底。

在掌握基础之后，课程将带领学生将所学知识应用于实际项目场景，重点涵盖图像处理和CSV文件处理等典型任务，使学习者不仅理解Python语法，更能灵活运用编程解决实际问题。

本课程适合零基础或初学编程的学员，以实践为导向，强调动手能力，旨在为后续更深入的计算机科学学习奠定坚实的技术基础。欢迎对编程感兴趣的你，一同开启Python的世界之旅。

课程简介（英文）

This class focus on the fundamentals of Python programming and will cover variables, branching, loops, lists, 2D list, and dictionary. The applications of Python coding include image processing and csv file processing.

教学目标

  • Read a computational problem and formulate an algorithm to solve that problem.
  • Implement a program in Python that performs specific tasks.
  • Use abstractions such as variables and functions to manage complexity in your programs.
  • Describe the functionality of a program that you or someone else has written.

Find and fix errors in programs that you or someone else has written.
