课程简介（中文）

本课程旨在引导学生进入计算机编程的世界，掌握程序设计的基本思想、核心概念和实用技能。通过本课程的学习，已C语言作为桥梁，学生能够理解计算思维。 掌握编程基础，培养解决问题的能力，实践程序开发流程，理解基本的数据结构， 基本语法和基本算法，熟悉使用C编程平台和调试方法。

课程简介（英文）

This course aims to guide students into the world of computer programming, mastering the fundamental ideas, core concepts, and practical skills of program design. Through learning in this course, using C as a bridge, students will be able to:

  • Understand computational thinking.

  • Master programming fundamentals.

  • Cultivate problem-solving abilities.

  • Practice the program development process.

  • Understand basic data structures, basic syntax, and basic algorithms.

  • Become familiar with using the C programming platform and debugging methods.

教学目标

本课程面向技术大类大一新生，以C语言为载体，以计算思维的培养为导向，通过程序设计实践，培养学生掌握使用程序设计的方法和解决问题的能力。通过本课程的学习，培养学生的逻辑思维与计算思维，掌握编程基础，实践程序开发流程，理解基本的数据结构， 基本语法和基本算法，熟悉使用C编程平台和调试方法，培养同学解决问题的能力。通过实践，训练学生养成良好的算法思想及合作开放的编程习惯和代码风格，紧以密对接技术迭代与产业变革的人才培养需求。

教学方式

上课面授及上机实践相结合

教学内容与进度安排

按照48学时授课，32学时上机。分16周进行：

第1周：课程简介，计算机基本原理，简单例子和编程环介绍。介绍软件危机，程序员的合作精神和意义。以及复旦计算机人早年对国产计算机的初创贡献。

第2周：C语言基本数据类型和输入输出基础

第3周：C语言基本运算和表达式

第4周：基本语句和选择结构

第5周：循环结构

第6周：一维数组，通过排序算法，拓展的计算机技术的创新和发展的介绍，启发同学对创新的兴趣。

第7周：多维数组和字符串

第8周：函数和库函数基础

第9周： 期中考试

第10周：指针基础

第11周：数组高级和指针行参

第12周：结构和链表

第13周：存储类别和作用域

第14周：文件处理技术

第15周：指针高级

第16周：例题选讲和期末复习
