课程简介（中文）

把数学应用到各种实际问题，需要构建各种算法，并用程序实现。计算数学、应用数学等方向学生需要有一定的程序设计能力，同时由于大模型的蓬勃发展，利用AI来进行编程越来越成为一种必须。本课程尝试通过在两个具体的领域来进行程序设计实践：科学计算和金融工程。对于这两个方向，我们会分别讨论几个重要的应用，试图让同学们通过具体案例的学习来开始掌握把一些数学的思想和算法，通过程序设计，来进行具体问题的求解和实证。本课程编程工具主要为Python，还会用到C++或者Matlab语言。

课程简介（英文）

Applying mathematics to real-world problems requires constructing various algorithms and implementing them in code. Students in computational mathematics, applied mathematics, and related fields need solid programming skills; moreover, with the rapid rise of large-scale AI models, using AI to assist coding has become essential. This course offers hands-on programming practice in two concrete domains: scientific computing and financial engineering. For each area we will examine several key applications, guiding students—through concrete case studies—to begin translating mathematical ideas and algorithms into working code that solves real problems and supports empirical analysis. The primary language is Python; C++ or Matlab is also  used.

教学目标

在科学计算领域，我们这学期尝试数值求解各类偏微分方程，我们会讨论：

  • 有限差分方法及求解
  • 利用Freefem、iFem等开源软件进行有限元的求解；
  • 利用PINN算法来进行神经网络求解偏微分方程的尝试。

在金融工程领域，我们会讨论几类问题：

  • ETF基金的轮动；
  • wind微盘指数的复现；
  • 中证1000期权卖方策略的复现。

对于这两个领域的问题，通过案例的讲解和分析，使得同学们能理解有关的问题，并动手解决类似的问题。

教学方式

首先是问题介绍，然后分析和算法构建，并进行程序案例讲解，并与学生进行讨论，设立新的研究课题，让同学们能进一步深入研究。
