课程简介（中文）

本课程采用C语言作为载体。C语言是执行效率最高的高级语言，也具有支持AI相关应用的类库。通过本课程的教学，向学生介绍结构化程序设计的基本思想和方法。基本内容包括：基本数据类型及运算、控制结构、数组、函数、结构、文件。并向学生介绍AI在C语言中的应用

课程简介（英文）

This course uses C language as the carrier. C language is the most efficient high-level language and also has libraries that support AI related applications. Through the teaching of this course, introduce students to the basic ideas and methods of structured programming design. The basic content includes: basic data types and operations, control structures, arrays, functions, structures, files, and Introduce AI Progress in C Language.

教学目标

  1. 使学生掌握用计算机解决问题的一般思路和方法。学生能掌握IPO（输入-处理-输出）的程序结构，掌握基本控制流语法，能选择适合具体应用需求的数据结构和相应算法来完成简单计算任务，具有较为扎实的编程基础。
  2. 对于复杂计算任务，学生能够运用自顶向下的模块分解方法，转为简单问题计算。进而能够利用人工智能辅助编程完成简单计算任务，能阅读理解AI生成的程序，进行修改，能够整合模块以完成复杂任务

教学方式

讲授为主。每周一节上课，一节上机实践。机房授课，通过屏幕广播软件或投影仪播放PPT和操作演示。eLearning平台上传课件。
