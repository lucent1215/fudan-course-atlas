课程简介（中文）

本课程主要介绍大数据与数据科学概念、原理、方法与应用，具体包括：大数据挖掘基础算法；大数据获取、管理与计算方法；专题数据挖掘与分析技术；大数据智能前沿技术（大模型、智能体等）；在金融、医疗、电商推荐等领域的应用等。

课程简介（英文）

This course primarily introduces the concepts, principles, methods, and applications of big data and data science. The course focuses on the following areas: fundamental algorithms for big data mining; methods for big data acquisition, management, and computation; advanced techniques for data mining and analysis (such as graph mining, text mining, LLMs and agents); and applications in fields like finance, healthcare, and e-commerce recommendation systems.

教学目标

通过本课程的学习，希望使学生了解大数据和数据科学基本概念，理解大数据和数据科学基本原理，掌握大数据分析技术；培养学生的数据思维，具备数据能力；能够从事大数据算法研究和在金融、医疗、电商推荐等场景灵活应用大数据技术。

教学方式

课堂讲解为主，课程分组PJ与互动结合。

教学内容与进度安排

一、 大数据与数据科学导论（week 1）

1.1 定义及发展历程

1.2 对社会和产业的影响及趋势

1.3 技术架构及基本原理

1.4 应用场景

 

二、大数据获取、管理与计算（week 2-6）

2.1 数据与数据的特征（week 2）

2.2 大数据采集与清洗（week 3）： 数据采集流程和方法；数据质量问题；数据清洗（如缺失值处理、异常值检测和处理、重复值检测和处理）；数据融合。

2.3 大数据存储和管理（week 4）：数据库（MySQL、NoSQL）；数据仓库等。

2.4 大数据分析与计算技术（week 5）：大数据分布式计算技术（Hadoop, HDFS，MapReduce，Spark等）；数据中台；数据湖等。

2.5 数据资源与数据资产（week 6）： 数据资产的定义、框架及其价值评估等。

 

三、基础数据挖掘技术（week 7-11）

3.1 数据挖掘基础（week 7）：介绍数据挖掘的概念、定义、任务和流程，以及常用的数据挖掘技术和算法。

3.2 互动讨论（week 8助教）：获取数据集上，并规划采用哪些数据挖掘方法实现相应的应用价值

3.3 关联规则挖掘（week 9）：介绍关联规则挖掘的概念、原理和算法，以及如何在大数据场景下进行关联规则挖掘。

3.4 聚类分析（week 9）：介绍聚类分析的概念、原理和算法，以及如何在大数据场景下进行聚类分析。

3.5 分类算法（week 10）：介绍分类算法的概念、原理和算法，以及如何在大数据场景下进行分类分析。

3.6 异常分析（week 10）：介绍异常分析算法的概念、原理和算法，以及如何在大数据场景下进行异常分析。

3.7 数据挖掘任务、机器学习基础方法（含深度学习代表模型）与操作案例介绍（week 11 助教）

 

四、专题数据挖掘与分析技术（week 12-15）

4.1 专题数据挖掘与分析技术概述（week12）

4.2 互动讨论：规划专题数据挖掘任务与方法（week13助教）

4.3 文本数据挖掘（week14）：自然语言处理技术、文本预训练大模型技术；

4.3 图数据挖掘（week14）：常见图挖掘于分析任务与算法、社交网络挖掘与分析；

4.4 时序数据挖掘和预测（week15）：常见时序数据挖掘与预测任务和技术；

4.4 结构化数据大模型及其应用（week15）：多模态数据处理任务、多模态大模型技术。

 

六、考察汇报（week 16）
