课程简介（中文）

本课程采用问题驱动教学法，以C++语言为载体，系统性地阐述面向对象程序设计（OOP）的核心范式。教学内容涵盖从C++基础语法、标准模板库到面向对象的高级特性，如类与对象封装、复制控制、运算符重载、模板、继承与多态等。课程注重理论与实践相结合，培养学生运用OOP思想解决复杂问题的能力，为其专业发展奠定扎实基础。

课程简介（英文）

This course employs a problem-driven pedagogical approach, using the C++ programming language to systematically elucidate the core paradigms of Object-Oriented Programming (OOP). The curriculum comprehensively spans fundamental C++ syntax, the Standard Template Library (STL), and advanced OOP features—including classes and object encapsulation, copy control, operator overloading, templates, inheritance, and polymorphism. With a strong emphasis on integrating theory with practice, the course aims to cultivate students' ability to solve complex problems using OOP methodologies, thereby laying a solid foundation for their future professional development.

教学目标

完成本课程后，学生将能够：

  1. 理解核心原理：面向对象程序设计（OOP）的基本思想、原则及其在C++中的实现机制。

  2. 掌握关键技术：运用C++语法、标准模板库及OOP核心特性（如类、继承、多态），设计与实现结构清晰的程序。

  3. 初步解决复杂问题：能够将小型工程问题进行分析和模块化，并运用OOP范式进行基础建模与求解。

  4. 建立专业基础：具备面向对象的编程思维，并掌握C++核心语法与STL的基本使用，为后续专业课程的学习奠定必要的程序基础。

教学内容与进度安排

单周周四13:30-15:10 上课, 双周周四13:30-15:10 上机、答疑

第1章  C++入门（1.5学时）

    1.1 Hello World程序

    1.2 使用标准库进行输出（std、using语句、cout、endl等）

    1.3 字符串类string的使用（定义、初始化、连接、输入输出等）

第2章 组织程序和数据（1.5学时）

    1.1 容器vector类型的使用（定义、push_back等基本操作）

    1.2 将程序分块（引用类型形参、const形参）

    1.3 将各部分代码连接到一起（多个.cpp和多个.h文件项目的组织）

第3章 使用容器（1学时）

    3.1 list类型的使用（定义、删除、排序等）

    3.2 迭代器iterator的原理、类型和操作

第4章 库算法和泛型函数（2学时）

    4.1什么是泛型函数

    4.2 库算法和迭代器

    4.3 泛型函数的编写和使用

第5章 类（2学时）

    5.1 类的成员函数

    5.2 类的非成员函数

    5.3 类的封装性和信息隐蔽

    5.4 构造函数

第6章 模板类（利用模板类实现vector类的简易版本）（3学时）

    6.1 定义模板类

    6.2 复制构造函数

    6.3 赋值运算符

    6.4 析构函数

    6.5 The rule of three

第7章 操作符重载（实现string类的简易版本）（2学时）

    7.1 输入输出运算符

    7.2 友元函数

    7.3其它运算符重载

    7.4 类型转换

第8章 继承与动态绑定（3学时）

    8.1 继承

    8.2 多态和虚函数

    8.3 一个简单的句柄类
