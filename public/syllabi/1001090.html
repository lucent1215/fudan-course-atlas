课程简介（中文）

课程面向零基础学生，以Python为载体，系统讲授程序设计基础（包括数据结构、流程控制、函数与模块化开发等），并结合AI辅助编程技术，帮助学生掌握AI工具在代码生成、调试等环节的高效应用方法。课程采用“理论+实践”模式，培养学生的逻辑思维和解决问题的能力，全面提升学生的AI素养。

课程适用于各专业学生的程序设计与创新能力培养。

课程简介（英文）

This course is designed for beginners with no prior programming experience. Using Python as the teaching language, it systematically covers programming fundamentals including data structures, flow control, functions, and modular development. The course integrates AI-assisted programming techniques to help students effectively utilize intelligent tools for code generation and debugging. Through a combination of theoretical instruction and hands-on practice, it aims to develop students' logic-thinking, problem-solving skills, and AI competency. The course is suitable for students of all academic disciplines to acquire programming design skills and foster innovative thinking.

教学目标

课程以Python为载体，培养计算思维和AI素养；弱化记忆要求，强调对知识的理解和应用，树立严谨创新的科学精神；培养高层次认知能力、创造性解决问题的能力。

知识目标：掌握程序设计基础（数据结构、流程控制、函数与模块化开发等）；掌握用计算机解决问题的一般思路和方法，学生能使用Python第三方库进行数据分析处理及AI应用（机器学习、自然语言理解等），可以和更高阶的人工智能课程衔接。

能力目标：培养逻辑思维和解决问题的能力（通过"理论+实践"），提升AI工具应用水平。

价值目标：强化代码伦理意识，理解技术与社会的关系；培养创新精神；培养终身学习能力，适应AI时代。

教学方式

为实现课程目标，采用“以学生为中心、AI赋能、分层递进”的教学模式，结合理论讲授、项目实践、智能工具辅助及反思评价，具体策略如下：：

  • 授课方式：通过播放PPT和操作演示，eLearning平台上传课件（包括讲课视频录像）；利用AI工具演示代码生成，对比人工编写与AI生成的差异，分析优劣。同时提供课堂lab，任课老师和助教上机辅导答疑。
  • 课外练习：每周一次作业，第10周布置一个大作业PJ。
  • 课外辅导：建立课程钉群，进行线上答疑，个性化辅导
  • AI辅助：鼓励学生运用Deepseek等AI辅助工具，进行个性化学习探索，培养学生持续学习的能力。

教学内容与进度安排

第1周: Python 安装，掌握Python开发环境配置（VS Code+AI插件），Helloworld程序，基本输入输出语句、AI工具演示（代码生成）。通过介绍Python语言开源、开放、兼容的特点，培养学生的兼容并包、开放进取的心态，提高学生接受新生事物，探索前沿技术的能力，提高学生的创新能力。目的：可以进行python安装，熟悉python的IDE的使用，可以编写运行helloword程序。

第2周: 变量与对象，数据类型，运算符和表达式，常用内置函数。目的：理解变量、对象，表达式的含义，会使用对数值类型的处理的常用内置函数。

第3周: 函数简单入门，包括函数定义，形参和实参，字符串基础知识 目的：具备自定义函数的能力。

第4周: 国庆节放假停课

第5周: 模块导入和使用，代码规范，文件名，__name__属性，字符串，简单程序实例。目的：掌握import语句、对字符串对象的处理，可以编写具有一定规范简单的程序。

第6周: 列表，简单循环语句。目的：掌握列表对象的创建、列表对象原地修改，可以使用循环语句对列表对象中的元素进行处理。

第7周: 切片、简单的选择语句、列表推导。目的：掌握切片的概念，可以使用切片对列表进行检索，修改，可以使用列表推导式创建列表。

第8周: 列表排序，元组，目的：掌握元组对象的创建和处理，可以使用sort方法和sorted函数对列表对象进行排序。

第9周: 字典，集合。目的：掌握字典、集合对象的创建和处理，

第10周: 条件表达式，选择语句，目的：掌握条件表达式、if语句的写法。

第11周: 循环语句，break和continue，循环嵌套。目的：掌握while、for语句的写法。

第12周: 字符串，文件操作，通过加解密例子介绍，加强学生信息安全意识。目的：掌握字符串对象处理的方法、以及文件读写的方法。

第13周: 函数 、参数类型、return语句、变量作用域，实例，目的：掌握函数的参数类型，以及变量作用域的概念。

第14周: Pandas数据处理与分析、数据清洗与预处理

第15周: 数据可视化（Matplotlib、Seaborn）。

第16周: 选讲机器学习模型（Scikit-learn）、LLM的API调用与集成开发。复习答疑，目的：衔接更高阶的人工智能课程、梳理课程难点重点，答疑解惑。
