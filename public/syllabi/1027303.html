课程简介（中文）

本课程系统讲授现代编译器的设计与实现方法，围绕一门教学型语言（TeaPL），完整覆盖从源代码到目标机器汇编代码的全过程。课程以“理论—算法—实现”为主线，通过计算器、编译器前端、中间代码与优化、后端代码生成等逐步递进的实例，帮助学生深入理解编译原理的核心思想，并具备实现一个小型编译器的工程能力。

课程内容分为三个阶段：第一阶段聚焦编译器前端，涵盖词法分析、语法分析（自顶向下与自底向上）、文法设计与解析算法；第二阶段介绍抽象语法树、类型推导、LLVM IR、数据流分析、SSA 形式以及过程内与过程间优化技术；第三阶段面向编译器后端，讲解指令选择、寄存器分配和指令调度等关键问题。

通过本课程学习，学生将掌握编译器各阶段的基本理论、常用算法与实现技术，理解现代编译器软件栈的整体结构，并具备分析、设计和实现编译器关键模块的能力。

课程简介（英文）

This course provides a systematic introduction to the design and implementation of modern compilers. Centered on a teaching-oriented language (TeaPL), it comprehensively covers the entire process from source code to assembly code. Guided by the progression of theory–algorithms–implementation, the course uses gradually evolving examples—including a calculator, compiler front end, intermediate representations and optimizations, and back-end code generation—to help students gain a deep understanding of the core principles of compiler construction and develop the practical ability to implement a small-scale compiler.

The course is organized into three stages. The first stage focuses on the compiler front end, covering lexical analysis, syntax analysis (both top-down and bottom-up), grammar design, and parsing algorithms. The second stage introduces abstract syntax trees, type inference, LLVM IR, data-flow analysis, static single assignment (SSA) form, as well as intra-procedural and inter-procedural optimization techniques. The third stage addresses the compiler back end, emphasizing key topics such as instruction selection, register allocation, and instruction scheduling.

Upon completion of this course, students will master the fundamental theories, commonly used algorithms, and implementation techniques across all stages of a compiler, understand the overall structure of the modern compiler software stack, and acquire the ability to analyze, design, and implement key compiler components.

教学目标

本课程旨在使学生系统掌握现代编译器各阶段的基本原理、核心算法与实现技术，理解从源代码到汇编代码的完整转换流程。通过对词法分析、语法分析、中间代码表示与优化以及后端代码生成等关键问题的学习，学生将建立对编译器软件栈的整体认知，具备分析编译器设计取舍的能力，并能够独立实现和调试一个小型编译器的核心模块，为后续从事系统软件、程序语言或相关工程与研究工作奠定坚实基础。

教学方式

课程采用“理论讲解 + 算法分析 + 工程实践”相结合的教学模式。课堂中通过问题定义和算法实现讲解编译器的核心理论，配合典型示例分析和逐步演化的编译器实现，引导学生将抽象理论与具体实现紧密对应。课后配套一整套模块化的编译器实验，强化动手实践能力，巩固和深化课堂所学；在课程的关键阶段引入课堂反转教学，由学生讲解编译器模块的设计思路与实现细节，促进对知识的理解、表达与综合运用。

教学内容与进度安排

课程入门

第1周：课程入门

  • 课程介绍：课程内容和考核方式
  • 计算器实现分析：运算符的优先级和结合性（Pratt算法）、逆波兰表达式
  • 编译概览：前端、中间代码、后端等编译器相关的基本概念和功能

 

第一阶段：前端

第2周：词法分析

  • 词法声明：正则表达式、正则语言判别
  • 正则表达式转换DFA：非确定性有穷自动机、确定性有穷自动机

 

第3周：上下文无关文法

  • 上下文无关文法：BNF范式、语法推导、二义性问题及其消除
  • 使用EBNF定义TeaPL语法

 

第4周：自顶向下解析

  • LL(1)文法：消除左递归、回溯
  • LL(1)文法解析

 

第5周：自底向上解析

  • SLR、LR(1)文法
  • SLR、LR(1)文法的解析方法

 

第6周：课堂反转

  • 学生讲解编译器前端功能实现
  • 老师和助教进行代码、用例问答

 

第二阶段：中间代码和优化

 

第7周：AST和类型推导

  • 抽象语法树：AST定义、语法解析树翻译AST
  • 类型推导：标识符作用域、类型检查、类型转换、类型推断

 

第8周：线性IR

  • 翻译线性IR：AST翻译LLVM IR
  • 解释执行

 

第9周：数据流分析和SSA

  • 常量分析和优化：Lattice-based分析方法、Chaotic iteration
  • 数值流分析：可达性分析、数值流图
  • 静态单赋值形式：支配树、支配边界

 

第10周：过程内代码优化技术

  • 冗余代码优化：死代码、可用表达式分析、繁忙表达式分析
  • 循环优化：循环不变代码、归纳变量优化、条件语句外移

 

第11周：过程间代码优化技术

  • 内联优化
  • 尾递归优化

 

第12周：课堂反转

  • 学生讲解编译器类型检查和中间代码功能实现
  • 老师和助教进行代码、用例问答

 

第三阶段：后端和优化

第13周：指令分配

  • ARM指令集：指令、寄存器、调用规约
  • 指令选择：表达式树、铺树问题

 

第14周：寄存器分配

  • 寄存器分配问题：干扰图
  • 着色算法：贪心算法、最大势算法
  • 溢出策略

 

第15周：指令调度与优化

  • 指令依赖分析
  • 表调度算法
  • 并行和优化

 

第16周：课堂反转

  • 学生讲解编译器后端功能实现
  • 老师和助教进行代码、用例问答
