课程简介（中文）

本课程为科研导向型课程，主要介绍移动计算领域最新科研进展。课程将围绕移动计算领域的一系列热点问题，包括移动社交网络、移动大数据、移动App、人群移动模型、智慧城市、移动云计算、移动计算中的机器学习、移动计算中的安全与隐私保护问题、共享经济与移动计算等方面。

课程简介（英文）

This is a research-oriented course, focusing on the latest research outcomes in mobile computing. We are going to cover a series of emerging topics, including mobile social networks, mobile big data, mobile Apps, human mobility model, smart cities, mobile cloud computing, machine learning in mobile computing, sharing economy in mobile computing, and security/privacy problems in mobile computing.

教学目标

本课程为科研导向型课程，主要介绍移动计算领域最新科研进展。课程将围绕移动计算领域的一系列热点问题，包括移动社交网络、移动大数据、移动App、人群移动模型、智慧城市、移动云计算、移动计算中的机器学习、移动计算中的安全与隐私保护问题、共享经济与移动计算等方面。课程所讨论的学术论文主要来自ACM SIGMOBILE和ACM SIGCOMM组织的一系列国际顶级会议。

This is a research-oriented course, focusing on the latest research outcomes in mobile computing. We are going to cover a series of emerging topics, including mobile social networks, mobile big data, mobile Apps, human mobility model, smart cities, mobile cloud computing, machine learning in mobile computing, sharing economy in mobile computing, and security/privacy problems in mobile computing. We will mainly pick papers from the top international conferences sponsored by ACM SIGMOBILE and ACM SIGCOMM.
