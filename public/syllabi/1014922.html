课程简介（中文）

在当今大数据驱动的人工智能时代，大数据的价值突显。在这种背景下大数据及相关技术的安全漏洞被不断发掘，大数据安全保障也由此成为网络空间安全的核心问题之一。本课程围绕大数据安全问题和技术，从攻击、防御和应用三个角度进行讲解，介绍大数据安全与数据安全的区别和联系、常见的大数据安全问题、机器学习场景下的典型数据安全攻击方法、大数据生命周期安全技术、机器学习场景下的大数据安全技术、大数据安全管理与治理、以及大数据安全分析技术。课程的特色在于将攻击与防御两个角度的技术有效地融合、将新型攻击与传统攻击有机结合。

课程简介（英文）

In the current era of artificial intelligence driven by big data, the value of big data has become increasingly prominent. Against this backdrop, security vulnerabilities in big data and related technologies are continuously being uncovered, making big data security one of the core challenges in cyberspace security. This course systematically explores big data security issues and technologies from three perspectives: attack, defense, and application. It delves into:

  1. The distinctions and interconnections between big data security and traditional data security
  2. Common big data security challenges and emerging threats
  3. Typical data security attack methods in machine learning environments
  4. Lifecycle security technologies for big data (from collection to deletion)
  5. Big data security solutions tailored for machine learning workflows
  6. Governance frameworks and management strategies for big data security
  7. Advanced analytical techniques for big data security detection

The course's distinctive approach lies in its integrated treatment of offensive and defensive strategies, bridging theoretical concepts with practical implementations. It uniquely combines cutting-edge attack vectors with classical security principles, providing a holistic understanding of evolving threats and countermeasures in the big data ecosystem.

教学目标

理解大数据智能与网络安全、数据安全和机器学习的之间的联系；掌握典型的大数据安全问题、机器学习场景下的典型数据安全攻击方法、大数据生命周期安全技术、机器学习场景下的大数据安全技术、大数据安全管理与治理方法、以及大数据安全分析技术。通过该课程的学习，有望为学生建立大数据安全的总体知识体系，填补网络空间安全知识体系的缺陷，并为研究生今后深入开展某个方向的学习和研究提供扎实基础和导引。

教学方式

基础和前沿并重，教师讲课为主，学生汇报相关文献。

教学内容与进度安排

每周教学内容如下：

1.大数据安全概述，包括数据安全的发展、大数据安全与现有安全的联系、知识体系等。

2.介绍典型的大数据安全问题，包括数据泄露、滥用、数据篡改等，以及相应的漏洞利用和攻击方法。

3.介绍机器学习场景下的数据安全攻击，着重于数据层的攻击者属性、逃避攻击的白盒和伪梯度机制。

4.介绍逃避攻击的迁移攻击及其他攻击机理，解读相关前沿文献方法。

5.介绍模型训练阶段的数据安全问题，侧重于训练数据投毒机理。

6.介绍机器学习应用场景下的数据隐私窃取攻击方法、聚类数据的篡改攻击方法。

7.机器学习应用背景下的数据安全相关技术文献交流与讨论。

8.介绍大数据生命周期安全技术，侧重于安全基础技术，并突出大数据所带来的影响和改进。

9.介绍大数据生命周期安全技术，侧重于安全过程技术，并突出大数据所带来的影响和改进。

10.介绍机器学习场景中的大数据安全技术，侧重于数据层面的防御机制，包括数据清洗、噪声处理、异常数据和非平衡数据处理。

11.介绍数据应用中的伦理安全问题，包括数据偏见、信息过滤、机器遗忘等。

12.大数据隐私保护基本问题，隐私问题、隐私度量、结构化数据隐私泄露和k匿名、差分隐私等。

13.大数据隐私保护，包括社交数据、位置数据、时序数据等非结构化数据的隐私泄露和保护。

14.介绍大数据安全治理与管理管理、技术。

15.介绍大数据安全分析技术，包括口令安全、异常检测、态势感知等应用场景。

16.大数据安全防御技术的相关文献交流与讨论。
