课程简介（中文）

课程主要介绍工业大数据分析挖掘，工业大数据应用实践，工业互联网技术。主要内容包括：工业互联网体系架构、工业大数据关键技术与算法模型，大数据处理与大数据平台技术，机器学习与深度学习算法，工业知识图谱，AI智能体与RAG等。

课程简介（英文）

The course mainly introduces industrial big data analysis and mining, industrial big data application practice, and industrial Internet technology. The main contents include: industrial Internet architecture, key technologies and algorithm models of industrial big data, big data processing and big data platform technologies, machine learning and deep learning algorithms, industrial knowledge graphs, AI agents and RAG, etc.

教学目标

针对工业大数据智能分析，工业互联网应用趋势，重点分析介绍：工业互联网体系架构与工业大数据关键技术，工业大数据领域的常用分析算法（机器学习，图像识别算法），工业大数据分析的工程方法论，工业大数据智能优化与工业AI智能体应用。培育学生工业大数据分析挖掘与工业AI应用能力。

教学方式

课程内容以工业数据分析方法与算法PPT介绍为主，辅助工业互联网平台软件演示，AI智能体练习实践。课程相关论文阅读讨论。
