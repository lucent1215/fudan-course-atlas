课程简介（中文）

课程从数据分析技术和数据库管理技术两个方面，以主题的形式帮助学生了解当前数据分析和数据库管理的主流技术及研究方向。数据分析方面主要集中在WEB 数据管理，WEB IR（信息检索），搜索引擎，排序算法，社会网络大数据分析（社会网络统计分析，聚类分析，社区发现，分类分析，推荐系统，社会网络信息传播等）进行教授和讨论。数据库管理方面主要集中在存储结构与文件组织、数据索引技术、查询处理与优化技术，以及空间数据管理技术等进行教授和讨论。

课程简介（英文）

The course covers two main aspects: data analysis technology and database management technology. It aims to help students understand the mainstream technologies and research directions in current data analysis and database management through thematic instruction and discussion. In the terms of data analysis, the emphasis is on WEB data management, WEB IR (information retrieval), search engines, ranking algorithms, and big data analysis of social networks (including social network statistical analysis, clustering analysis, community detection, classification analysis, recommendation systems, and social network information dissemination). In terms of database management, the focus is primarily on storage structures and file organization, data indexing techniques, query processing and optimization techniques, as well as spatial data management techniques.

教学目标

本课程的学习目标是帮助学生掌握WEB数据管理、社会网络分析、数据存储与索引、数据库查询处理与优化等方面的主流技术，了解当前数据分析和数据库管理的技术研究方向，更好地面对数据处理分析与数据库技术的当前新课题、新进展和新挑战，提高学生发现问题、解决问题的能力以及独立科研能力。

教学方式
