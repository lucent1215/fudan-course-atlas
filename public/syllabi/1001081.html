课程简介（中文）

C语言是执行效率最高的高级语言，也具有支持AI相关应用的类库。本课程采用C语言作为载体，向学生介绍结构化程序设计的基本思想和方法。
基本内容包括：基本数据类型及运算、控制结构、数组、函数、结构、文件、AI算法实现：线性回归和聚类、深度学习：TensorFlow C API。

课程简介（英文）

C language is a high-level language with the highest execution efficiency and also possesses class libraries that support AI-related applications. This course uses C language as a medium to introduce students to the fundamental concepts and methods of structured programming.
The basic content includes: basic data types and operations, control structures, arrays, functions, structures, files, AI algorithm implementation: linear regression and clustering, and deep learning: TensorFlow C API.

教学目标

1.使学生掌握用计算机解决问题的一般思路和方法。学生能掌握IPO（输入-处理-输出）的程序结构，掌握基本控制流语法，能选择适合具体应用需求的数据结构和相应算法来完成简单计算任务，具有较为扎实的编程基础。
2.对于复杂计算任务，学生能够运用自顶向下的模块分解方法，转为简单问题计算。进而能够利用人工智能辅助编程完成简单计算任务，能阅读理解AI生成的程序，进行修改，能够整合模块以完成复杂任务。

教学方式

讲授为主。每周1节上课，1节上机实践。机房授课，通过屏幕广播软件或投影仪播放演示文稿和操作演示。eLearning平台上传课件。
