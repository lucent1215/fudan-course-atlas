课程简介（中文）

《机器学习系统》课程探讨机器学习系统从设计到优化的全过程，重点强调大模型、系统软件与硬件架构的深度融合。核心内容包括 GPU 与人工智能加速器架构、CUDA 编程、机器学习编译器、并行训练框架、模型推理与优化技术。课程还将探讨隐私保护、可持续性与系统安全等关键伦理议题。通过实践性实验与课程项目，学生将获得构建可扩展、高效、可靠的机器学习系统的实际经验，面向真实世界的应用场景。

课程简介（英文）

The Machine Learning Systems course provides a comprehensive exploration of the end-to-end design and optimization of machine learning systems, with an emphasis on the integration of large models, system software, and hardware architecture. Core topics include GPU and AI accelerator architectures, CUDA programming, machine learning compilers, parallel training frameworks, model inference, and optimization techniques. The course also addresses critical ethical issues such as privacy, sustainability, and safety. Through hands-on labs and a final project, students will gain practical experience in developing scalable, efficient, and reliable ML systems for real-world applications.

教学目标

本课程旨在使学生深入理解并掌握大规模机器学习系统的设计、优化与部署方法。课程贯通大模型、系统软件与硬件架构之间的协同关系，帮助学生具备构建可扩展、高效机器学习服务的系统能力。学生将在动手实践与项目开发中培养系统性技能，同时也将探讨诸如隐私、公平性与环境可持续性等广泛的伦理问题。课程结束后，学生将能够掌握满足性能与成本要求的端到端机器学习系统的相关设计与优化的知识。

教学方式

以课堂讲授、文献阅读讨论与课程项目为主。课堂讲解介绍相关理论、模型和原理，实践编程和项目作业帮助学生切实了解机器学习系统从设计到部署的全过程，并学会创建适用于快速发展且多样化的人工智能应用的、高效、可扩展且可靠的机器学习系统。

教学内容与进度安排

第1周：机器学习系统课程介绍

  • 课程内容纵览与项目任务说明
  • 深度学习系统整体架构与关键技术综述
  • 冯·诺依曼通用计算架构回顾及其局限性

 

第2周：GPU计算体系架构

  • GPU硬件架构与并行计算模型
  • 深度学习中的GPU加速机制

 

第3–4周：CUDA编程与性能优化

  • CUDA编程模型与执行框架
  • 内存管理、线程调度及并行执行优化方法
  • 实验：典型算子的CUDA实现与性能调优

 

第5–6周：机器学习编译框架与系统栈

  • 主流深度学习框架解析（TensorFlow、PyTorch等）
  • 机器学习编译工具链（TVM等）
  • 面向深度学习与大模型的编译优化实践（Triton等）

 

第7–10周：大规模模型训练系统

  • 并行训练技术：数据并行、模型并行与流水线并行等策略
  • 分布式训练系统与工具链（Megatron、DeepSpeed）
  • 模型微调策略与后训练优化框架（Post-Training Optimization）

 

第11周：模型推理与部署系统

  • 主流推理框架
  • 推理阶段的性能优化与系统集成策略

 

第12周：模型优化与系统性能提升技术

  • 模型剪枝、知识蒸馏与量化技术
  • 混合精度训练机制与训练稳定性提升方法

 

第13周：AI硬件加速与嵌入式部署实践

  • 端侧应用场景中资源限制
  • AI硬件加速技术

 

第14周：课程项目展示与总结研讨

  • 学生课程项目答辩
  • 课程内容回顾与前沿展望

 

第15-18周：机器学习系统工业界报告

  • 邀请业界专家围绕课程内容相关主题进行演讲，这些主题包括但不限于：机器学习编译器与优化、并行训练、推理系统、移动端与边缘设备上的部署、硬件加速器，以及开源社区的实践等。

 

Week 1: Introduction to Machine Learning Systems

  • Course overview
  • Machine learning systems overview
  • Review of the von Neumann computing architecture

 

Weeks 2: GPU Architecture

  • GPU architecture and parallel computing models
  • GPU acceleration mechanisms in deep learning

 

Weeks 3–4: CUDA Programming

  • CUDA programming model and execution framework
  • Memory management, thread scheduling, and parallel execution optimization
  • Lab: CUDA implementation and performance tuning of representative operators

 

Weeks 5–6: ML Compilation

  • Mainstream deep learning frameworks (e.g., TensorFlow, PyTorch)
  • Machine learning compilers (e.g., TVM)
  • Compiler optimization for deep learning and large models (e.g., Triton)

 

Weeks 7–10: Parallel Training

  • Parallel training techniques: data/model/pipeline parallelism, etc.
  • Distributed training systems and toolchains (e.g., Megatron, DeepSpeed)
  • Model fine-tuning strategies and post-training optimization frameworks

 

Week 11: Model Inference and Deployment

  • Mainstream inference frameworks
  • Performance optimization for model inference

 

Week 12: Model Optimization

  • Model pruning, knowledge distillation, and quantization techniques
  • Mixed-precision training and stability improvement methods

 

Week 13: AI Hardware Acceleration and Edge Deployment

  • Resource constraints in edge application scenarios
  • AI hardware acceleration technologies

 

Week 14: Course Project Presentation and Course Summary

  • Student project presentations
  • Course recap and ML System outlook

 

Week 15-18: Machine Learning Systems Seminars

  • We invite industry experts to deliver talks on topics including ML compilers and optimizations, parallel training, inference systems, deployment on mobile and edge devices, hardware accelerators, and open-source community practices.
