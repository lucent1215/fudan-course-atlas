课程简介（中文）

本课程理论与实践紧密结合，将涉及词法分析，语法分析，语义分析，中间代码生成、指令选择、代码优化等内容，并以搭建一个编译器为课程主要实践手段。

课程简介（英文）

This course closely integrates theory and practice, covering topics such as lexical analysis, syntax analysis, semantic analysis, intermediate code generation, instruction selection, and code optimization. The main practical method of the course is to build a compiler.

教学目标

本课程旨在通过对现代编译器核心架构及关键组件的深入研读与系统化实验，引导学生透彻掌握从词法分析到代码生成的全链路原理、实现方法及底层编程技巧。课程强调理论与实践的深度融合，着重培养学生在复杂系统软件中的综合运用能力与工程素养。在当前新型软硬件架构层出不穷的时代背景下，致力于通过严谨的思维训练与技术积淀，赋予学生应对未来技术变革的适应力与创新力，为其后续的学术深造及职业生涯发展奠定坚实基础。

教学方式

教学方式包括面授和上机辅导。每周课堂讲解与讨论。整个学期使用自定义的高级语言，以及相配套的AST，IR，Quad等，进行编译器构造练习。相应材料将在elearning上发布，并将使用一个Git server进行代码、测试集发布。整个学期使用编程语言C++。

本课程每周安排2节上机实践课，进行编程练习和教学辅导。

(1) 课内授课中，可能安排随堂练习环节，根据授课内容进行课上交流与讨论；

(2) 上机实践课中，安排习题环节，通过授课内容与编程习题的结合，锻炼学生实践能力；

(3) 构建班级微信群、邮件等及时进行课外交流与讨论。
