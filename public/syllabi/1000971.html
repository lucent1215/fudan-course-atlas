课程简介（中文）

MATLAB是一种广泛应用于科学计算、工程原型设计以及商业与金融数据分析的计算机语言。该软件提供卓越的编程环境，不仅具备丰富的内置函数，还拥有多种工具箱，能轻松实现问题求解、友好的数据可视化，以及通过极简化的程序开发流程完成算法实现。本课程旨在帮助学生掌握MATLAB编程的核心技能，包括语言基础与工具包认知、基本编程能力培养，以及基于MATLAB的算法实现。教学将通过语言知识讲解与编码实例演示相结合的方式展开。

课程简介（英文）

Matlab is a computer language widely used for scientific computing, engineering prototyping, and data analysis for business and finance. Matlab provides an excellent programming environment with abundant build-in functions as well as toolboxes to enable problem solving with ease, user-friendly visualization of data, and simple implementation that needs as few as possible effort in program development. The goal of this course is to help students establish essential skills in Matlab programming, including basic knowledge about the language and toolkits, fundamental programming skills, and implementation of some algorithms using Matlab. The instruction will be given in terms of both introduction to language and demonstration of coding examples.

教学目标

MATLAB是目前广泛应用的科学与工程计算软件，被广泛地用于各研究领域、解决各种工程计算问题。本课程将培养学生利用MATLAB解决实际问题的能力和创新思维能力，为学生进一步学习和以后工作打下良好的基础。了解该编程工具授权使用的国际现状，激发学习动力，在熟练掌握的基础上不断创新，填补空白。
