课程简介（中文）

介绍软件系统安全的需求和原理，了解软件系统安全机制设计的一系列关键设计元素，其中包括软件漏洞和恶意行为分析技术、认证、访问控制、信息保护与隔离机制等。此外，本课程将以一款主流操作系统及其应用软件为例，介绍操作系统和软件的安全防御机制设计，以及近年来随着系统安全攻防的深入，产生的新型安全威胁与对应的系统安全新机制。并将介绍如何通过软件分析技术和操作系统安全策略等应对恶意软件等传统系统安全威胁。

课程简介（英文）

This course introduces the requirements and principles of software system security, providing an understanding of a series of key design elements in secure software system mechanisms. These include software vulnerability and malicious behavior analysis techniques, authentication, access control, information protection, and isolation mechanisms. Additionally, using a mainstream operating system and its application software as an example, the course explores the design of security defense mechanisms in operating systems and software. It also covers emerging security threats and corresponding new system security mechanisms that have arisen with the evolution of system security attacks and defenses in recent years. Furthermore, the course will discuss how to address traditional system security threats, such as malware, through software analysis techniques and operating system security policies.

教学目标

本课程主要介绍软件安全的基本概念和经典软件安全机制的设计原理，系统地从安全分析技术和安全防护机制两个方面，讨论安全威胁和对应的软件系统安全防护策略。将会讨论软件漏洞和恶意行为分析技术、认证、信息保护与隔离机制、访问控制等安全防护机制。并以最新Ubuntu Linux操作系统为例，分析系统安全技术的使用方法，结合案例分析和课程实验，熟悉主流系统的安全机制设计及常用的安全检测和安全防御技术。
