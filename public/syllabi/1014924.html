课程简介（中文）

本课程旨在软件工程基础上加强学生对软件工程前沿进展的理解，将在智能化软件开发、智能化运维、程序分析、软件开发数据分析与挖掘、软件供应链、机器人软件工程、智能汽车基础软件等前沿方向开展深入的文献阅读和报告研讨。

课程简介（英文）

This course aims to enhance students' understanding of cutting-edge advancements in software engineering, building upon the foundations of software engineering. It will involve in-depth literature review and seminar discussions on emerging frontiers such as intelligent software development, intelligent operations and maintenance, program analysis, software development data analysis and mining, software supply chains, robotic software engineering, and basic software for intelligent vehicles.

教学目标

本课程旨在使学生掌握大模型时代下的软件工程新技术和新方法，了解软件工程的最新前沿发展方向，提高学生对于软件工程的理解和实践能力，同时培养学生的文献调研、工作汇报、技术研讨、协作沟通等基本研究能力，能够成为独立的软件工程研究者。

教学方式

教学将主要以汇报与研讨的方式开展。

教学内容与进度安排

第1-2周：课程概述与学生介绍

介绍课程整体规划与要求，了解学生的研究背景，确定各个前沿方向的汇报分组。

第3-4周：智能化软件开发

理解大模型技术对智能化软件开发的应用价值、及在代码理解与生成、缺陷检测与修复等软件工程任务上的应用。

第5-6周：智能化运维

理解以容器化和微服务架构为主要特点的云原生软件，掌握包含调用链路、运行日志、时序指标等的运维大数据分析技术体系，实现异常检测、根因定位、架构评估等智能化运维支持。

第7-8周：程序分析

理解程序性质的分析和构建技术，掌握基于抽象解释的可扩展的程序分析方法，自动判别程序的各种性质，提高软件的可用、可靠、安全和可维护性。

第9-10周：软件开发数据分析与挖掘

理解各类软件开发数据的分析与挖掘技术，包括代码演化分析、克隆检测与管理、依赖分析、缺陷分析等，助力企业软件开发效能分析与代码质量提升。

第11-12周：软件供应链

理解软件供应链的安全风险、法律风险与维护风险，掌握基于程序分析、大模型等技术的高精度风险分析与治理技术，保障软件的自主可控性。

第13-14周：机器人软件工程

理解服务机器人、物流机器人以及智能汽车等机器人应用场景，掌握机器人程序的自动构造、在线适应和自主演化技术，以及数据驱动机器人系统异常检测、缺陷分析与自动修复等运维保障技术。

第15-16周：智能汽车基础软件

理解智能汽车的软件架构，包括通信中间件、面向服务的架构设计及系统支撑，掌握针对基础软件及智能驾驶等应用层软件的测试评价体系及支撑技术。
