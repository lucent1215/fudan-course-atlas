课程简介（中文）

本课程全面系统地介绍现代软件工程的基本概念、原则和方法，结合开源软件以及现代企业软件工程实践案例，向学生展示工程化软件开发的质量关注点、基本开发过程、实践方法和常用工具。课程侧重软件过程以及软件需求、软件设计、软件构造、软件测试等软件开发的基本方法和技术。

课程简介（英文）

This course provides a comprehensive and systematic introduction to the fundamental concepts, principles, and methodologies of modern software engineering. By integrating open-source software and practical cases from modern enterprise software engineering practices, it demonstrates to students the quality focus areas, basic development processes, practical methods, and commonly used tools in engineering-oriented software development. The course places emphasis on software processes as well as the core methods and technologies throughout the software development lifecycle, including software requirements analysis, software design, software construction, and software testing.

教学目标

通过知识讲授、案例分析和课程实践相结合的方式，使学生初步掌握软件项目工程化开发的基本过程，熟悉软件需求分析、设计、实现、测试和维护的基本方法，熟练掌握软件构造基本技术和工具，了解软件技术的发展和现实需求、软件技术体系与供应链生态、软件工程师职业道德要求、软件质量及其伦理道德影响等。

教学方式

本课程教学方式包括：知识介绍、案例分析、课程项目实践、互动讨论等

教学内容与进度安排

第1周 课程简介与软件工程概述（软件与信息技术的广泛需求、软件工程的含义、软件开发的根本性困难）

第2周 软件过程（软件开发过程的含义、经典软件过程模型、敏捷开发、开发运维一体化DevOps）；案例分析与课堂讨论

第3周 版本与开发任务管理（配置管理、软件产品发布计划、软件产品版本命名规则、代码版本与分支管理、特性开发任务管理、变更管理与缺陷修复过程管理）；案例分析与课堂讨论

第4周 高质量编码（软件工程师道德与质量责任、代码质量的含义和要求、规范化代码风格、代码逻辑要求）

第5周 高质量编码（安全与可靠性编码、防御式编程、代码质量控制手段、代码质量度量指标）

第6周 软件设计（软件设计的目标和内容、软件设计思想、面向对象设计过程与描述方法）

第7周 软件设计（典型的内聚与耦合类型、面向对象设计原则、面向切面编程、契约式设计、设计模式、演化式设计、代码坏味道与软件重构）

第8周 软件复用（软件复用的概念与层次、组件级软件复用、软件开发框架以及框架级软件复用、平台级软件复用、开源软件协议与软件版权）

第9周 案例分析与课堂讨论：高质量编码、软件设计与软件复用实践

第10周 软件体系结构（软件体系结构的概念与设计思想、软件体系结构设计决策、软件体系结构多视图建模与描述、软件体系结构风格）

第11周 软件体系结构（分布式软件体系结构的特点及相关技术、云原生软件、微服务体系结构的思想和相关技术体系）

第12周 软件需求（软件需求的含义与类型、软件需求工程与质量要求、需求精化、常用的需求分析和描述方法、敏捷开发中的需求分析与管理、可靠性与安全性等软件可信性需求）

第13周 软件测试（软件测试的概念与原则、软件测试过程、软件产品质量模型）

第14周 软件测试（软件测试用例设计、软件测试工具与技术）

第15周 案例分析与课堂讨论：软件体系结构、软件需求与软件测试实践

第16周 软件集成与发布（持续集成与发布、软件构建与依赖管理、软件发布技术）
