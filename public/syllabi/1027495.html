课程简介（中文）

《程序设计语言原理》是一门研究程序设计语言本身的学科基础课程，其核心目标不是教授如何使用某种具体的编程语言进行编程，而是深入探讨程序设计语言的设计思想、基本原理、核心机制与实现技术。通过本课程的学习，学生将理解不同编程语言在语法、语义和语用上的差异与共性，掌握程序设计语言中关键概念与结构（如类型系统、控制结构、函数、模块、对象、并发等）的本质含义与实现方式，从而提升对程序设计语言的深刻理解和灵活运用能力，为未来学习新的编程语言、从事语言设计、编译器开发、软件工程及相关研究奠定坚实的理论基础。

课程简介（英文）

"Principles of Programming Languages"​ is a foundational course that focuses on the study of programming languages themselves. Its core objective is not to teach how to program using any specific programming language, but rather to deeply explore the design philosophy, fundamental principles, core mechanisms, and implementation techniques​ of programming languages.Through this course, students will gain an understanding of the differences and commonalities among various programming languages in terms of syntax, semantics, and pragmatics. They will also learn the essential concepts and constructs in programming languages. This course lays a solid theoretical foundation for future learning of new programming languages, engaging in language design, compiler development, software engineering, and related research.

教学目标

通过本课程的学习，学生将能够：

  1. 解程序设计语言的基本构成要素，包括词法、语法、语义等；
  2. 握主流程序设计语言中的关键机制与特性，如变量与绑定、控制结构、数据类型、函数与过程、模块化、面向对象、异常处理、并发机制等；
  3. 分不同语言范式（如命令式、函数式、逻辑式、面向对象等）的特点与适用场景；
  4. 解程序设计语言的设计原则与权衡，例如灵活性与安全性、表达力与简洁性、运行效率与开发效率等；
  5. 悉程序设计语言的语法分析与语义解释/编译的基本原理与方法。

教学方式

课堂讲授，学生讨论汇报，程序实践练习

教学内容与进度安排

 

第1章 程序设计语言的导论与发展史 6学时

主要内容： 程序设计语言的基本概念、发展过程和阶段、代表语言。

第2章 程序设计语言的设计概述 6学时

主要内容： 程序设计语言设计的基本概念、设计目标、设计准则、语法规格。

第3章 过程式程序设计语言与类型系统 6学时

主要内容： 类型的表示与存储，面向复合对象的操作，类型语义与类型规则，类属域与多态类型系统

第4章 面向对象程序设计语言 6学时

主要内容： 讲解面向对象——OO的基本概念和特点，面向对象程序设计语言的起源和发展过程，基本的几种面向对象语言和各自的实现特点。

第5章 函数式程序设计语言 6学时

主要内容： 函数式程序设计语言的概念，发展过程和特点，λ符号逻辑演算系统。

第6章 并发程序设计语言 2学时

主要内容： 并行处理与程序的并发性、线程、信号灯、消息传递。
