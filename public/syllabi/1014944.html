课程简介（中文）

本课程将讲授高速计算机网络设备（如交换机，路由器，防火墙，入侵检测设备等）中常用的软硬件体系结构及高速数据包处理算法，包括IP路由表查找，流分类，网络流量调度，网络流量测量，数据包交换网络设计及调度，流量控制和拥塞控制，数据包内容检测，软件定义网络，网络功能虚拟化等内容；使学生掌握设计高速网络设备并对其进行性能分析所需的基本知识。

课程简介（英文）

This course will cover the commonly used hardware and software architectures as well as high-speed packet processing algorithms in high-performance computer network devices (such as switches, routers, firewalls, intrusion detection systems, etc.). The content includes IP routing table lookup, traffic classification, network traffic scheduling, network traffic measurement, design and scheduling of packet switching networks, packet content inspection, flow control and congestion control Software-Defined Networking (SDN), and Network Function Virtualization (NFV). The goal is to enable students to master the fundamental knowledge required for designing high-speed network devices and performing performance analysis.

教学目标

This course aims to teach students the common architectures used in high-speed computer networking devices (such as switches, routers, firewalls, etc.) and high-speed packet processing algorithms. It will equip students with the fundamental knowledge necessary for designing high-speed networking devices and conducting performance analysis.
