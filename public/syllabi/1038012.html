课程简介（中文）

《数据挖掘》课程融合数据库、统计学与人工智能技术，系统讲解数据预处理、数据仓库与OLAP分析、关联规则挖掘、分类预测（含深度学习）、聚类与异常检测等核心技术，结合Python、Weka等工具实现算法应用。课程注重理论与实践结合，通过案例分析培养数据建模与工程实践能力，为不同领域需求提供智能方案，强化创新能力。

课程简介（英文）

Data Mining integrates database systems, statistics, and AI to teach core techniques including data preprocessing, OLAP, association rule mining, classification (with deep learning), clustering, and outlier detection. Using Python and Weka, students master algorithm implementation and apply skills to real-world projects (e.g., risk assessment, medical prediction). The course bridges theory and practice, fostering innovation and data-driven problem-solving for industries like e-commerce and healthcare.

教学目标

We live in an era where big data accumulates over time. As the volume of data increases, it becomes an important requirement to be able to recognize, extract, analyze and utilize these data. This course aims to enable students to understand the significance of data mining, the scenarios and purposes of its use, as well as its related applications and historical development. Specifically, this course hopes that students can understand the basic information of data, the indicators of data, and simple assessment and processing methods; it hopes that students can have a certain understanding of related technologies such as data warehouses and data cubes; it hopes that students can master the specific algorithms of frequent pattern mining proficiently; it hopes that students can master various algorithms of classification and clustering and be able to apply them flexibly in different data scenarios; it hopes that students can have some understanding of the related algorithms for outlier detection; finally, this course hopes to expand more research on related cutting-edge fields for the students.

教学方式

The class covers the core algorithm principles (such as decision trees, neural networks, association rules) and statistical fundamentals, with real case studies, revealing the technical application scenarios. Tools like Python and SQL Server Analysis Services are used to complete data preprocessing, model training and evaluation. Design of phased experimental tasks to enhance practical skills; Group members complete comprehensive projects, covering requirements analysis, data acquisition, algorithm implementation and report writing. In class， the basic theories are learned and group discussions and results presentations are conducted to enhance the ability of self-study.

教学内容与进度安排

Week 1: What is data mining (KDD)
Definition of Data Mining, KDD Process, Tasks and Application Scenarios

Week 2: Data Preprocessing and Quality Improvement
Data Cleaning, Integration, Transformation and Reduction, Data Transformation and Dimensionality Reduction, Principal Component Analysis

Week 3-4: Holidays

Week 5: Data Warehouse, Data Cube and OLAP
Data Warehouse Architecture, OLAP Operations (Drill-down, Slice) and Data Cube Design,Data Cube Calculation and Data Generalization, Feature Description, Generalization, Comparison and Description

Week 6: Association Rules and Pattern Discovery
Apriori Algorithm, Frequent Itemset Mining and Rule Evaluation (Support, Confidence)

Week 7-8: Classification and Prediction Techniques
Decision Tree, Bayesian Classification, K-Nearest Neighbor, SVM and Model Evaluation

Week 9-10: Deep Learning
Core Differences between Deep Learning and Traditional Machine Learning, Common Deep Learning Models in Data Mining, Practice Process of Deep Learning in Data Mining

Week 11-12: Clustering and Anomaly Analysis
K-means, Hierarchical Clustering, DBSCAN Algorithm and Outlier Detection Method

Week 13: Midterm Exam - Covering the Content of Weeks 1-12

Week 14-15: Mining Complex Data (stream, time series, spatial, graph, social network, web), Application and Trends
Time Series Prediction (ARIMA), Graph Data Mining (Community Discovery), Natural Language Processing (TF-IDF), Project Proposals and Planning

Week 16: Project Progress Reporting and Trend Outlook
Project Presentations, LLMs, AutoML, and Explainable AI
