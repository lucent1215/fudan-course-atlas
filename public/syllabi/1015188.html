课程简介（中文）

人工智能导论课程系统讲解人工智能核心概念与技术框架，涵盖智能体、问题求解与搜索算法、逻辑推理与知识表示、概率推理与贝叶斯方法、机器学习（含决策树、神经网络、深度学习）、自然语言处理与信息检索、机器人学等核心领域，结合理论与实践，探索AI技术原理及其在跨学科场景中的应用。

课程简介（英文）

This course introduces the fundamentals of artificial intelligence, covering core topics such as intelligent agents, problem-solving and search algorithms, logical reasoning and knowledge representation, probabilistic models (e.g., Bayesian networks), machine learning (including decision trees, neural networks, and deep learning), NLP, information retrieval, and robotics. It integrates theoretical foundations with practical applications to explore AI's interdisciplinary potential.

教学目标

  1. Knowledge Objectives: Master the fundamental concepts and development trajectory of artificial intelligence, understand the core technical principles of search algorithms, logical reasoning, probabilistic models, machine learning (e.g., neural networks, deep learning), and familiarize oneself with the foundational theories of natural language processing and robotics.  
  2. Skill Objectives: Apply AI methodologies to solve complex problems (e.g., optimized search, pattern recognition) and design simple intelligent systems; through experiments and project-based practice, cultivate the ability to implement algorithmic prototypes using tools like LLMs and deep learning frameworks.
  3. Ethical and Professional Objectives: Develop awareness of technological ethics, consider AI's societal impacts and security risks; nurture interdisciplinary innovative thinking, adapt to human-machine collaboration scenarios, and strengthen responsibility and practical spirit in solving real-world problems.

教学方式

This course is structured around lectures, literature reading discussions, and course projects. Classroom instruction introduces relevant theories, models, and principles, while course projects are organized to align with the following three objectives:

  1. Integration of Theory and Practice: Analyze algorithmic logic through case studies (e.g., game problems, information retrieval systems) and deepen technical understanding by implementing code (e.g., using Python).
  2. Hierarchical Task-Driven Approach: Design progressive experiments (e.g., decision tree classification, simple NLP tasks) to guide students in transitioning from theoretical derivation to model training and optimization.
  3. Interdisciplinary Project Collaboration: Organize teams to complete comprehensive projects (e.g., prototypes of intelligent Q&A systems), emphasizing requirement analysis, solution design, and ethical evaluation to cultivate systematic engineering thinking.

教学内容与进度安排

Week 1: Overview of Artificial Intelligence  

  • Definition and Brief History of AI (Symbolicism, Connectionism, Behaviorism)  
  • Agent Classification (Reactive, Goal-Driven, Utility-Driven)  
  • AI Ethics and Societal Impact (Algorithmic Fairness, Data Privacy)  

Learning Objectives:  

Understand foundational AI concepts and historical context, differentiate characteristics of agent types, and establish ethical awareness.  

 

 

Week 2: Agents and Problem Modeling  

  • Agent-Environment Interaction Model (PEAS Framework)  
  • State Space and Problem Formulation (Initial State, Goal State, Operators)  
  • Case Study: Maze Pathfinding Problem  

Learning Objectives:  

Master environmental modeling methods and translate real-world problems into state-space representations.  

 

 

Week 3: Fundamentals of Search Algorithms  

  • Uninformed Search (BFS, DFS, Uniform Cost Search)  
  • Heuristic Search (A* Algorithm, Manhattan Distance Heuristic)  
  • Application Case: Shortest Path Planning  

Learning Objectives:  

Implement classic search algorithms and evaluate the efficiency of different heuristics.  

 

 

Week 4: Game Theory and Constraint Satisfaction Problems (CSP)  

  • Game Trees and Minimax Algorithm  
  • Alpha-Beta Pruning Optimization  
  • CSP Modeling (Variables, Constraints, Backtracking Search)  

Learning Objectives:  

Master game strategies and CSP-solving methods, applicable to board games or scheduling problems.  

 

 

Week 5: Logical Reasoning and Knowledge Representation  

  • Propositional and First-Order Predicate Logic  
  • Resolution Principle and Automated Reasoning  
  • Knowledge Graph Basics (Triple Representation)  

Learning Objectives:  

Represent knowledge using logical rules and implement simple reasoning systems.  

 

 

Week 6: Uncertain Reasoning and Probabilistic Models  

  • Bayes’ Theorem and Conditional Probability  
  • Bayesian Network Modeling (Causal Reasoning, Evidence Updating)  
  • Case Study: Medical Diagnosis System  

Learning Objectives:  

Apply probabilistic reasoning to construct Bayesian networks for uncertain problems.  

 

 

Week 7: Fundamentals of Machine Learning  

  • Supervised vs. Unsupervised Learning Paradigms  
  • Decision Trees (ID3 Algorithm, Information Gain)  
  • Introduction to Inductive Logic Programming (ILP)  

Learning Objectives:  

Understand machine learning categories and implement a decision tree classifier.  

 

 

Week 8: Midterm Practical Project Presentation  

Project Theme: Intelligent Path Planning and Game System  

  • Task 1: Implement path planning in dynamic obstacle environments using the A* algorithm.  
  • Task 2: Develop a tic-tac-toe game AI integrating the minimax algorithm with alpha-beta pruning.  

Evaluation Criteria:  

  • Code Implementation (40%)  
  • Lab Report (30%): Analyze algorithm performance and optimization strategies.  
  • Demo Defense (30%): Showcase interactive outcomes and decision logic.  

 

 

Week 9: Neural Networks and Deep Learning Fundamentals  

  • Perceptrons and Multilayer Feedforward Networks  
  • Backpropagation Algorithm Principles  
  • Activation and Loss Function Selection  

Learning Objectives:  

Master forward propagation and training processes of neural networks, and build simple fully connected networks.  

 

 

Week 10: Advanced Deep Learning and Vision Applications  

  • Convolutional Neural Network (CNN) Architecture and Feature Extraction  
  • Transfer Learning and Pretrained Models  
  • Case Study: Image Classification Task  

Learning Objectives:  

Understand CNN principles and apply pretrained models to image recognition tasks.  

 

 

Week 11: Natural Language Processing (NLP) Fundamentals  

  • Bag-of-Words Model and TF-IDF  
  • Sequence Models (RNN, LSTM)  
  • Case Study: Text Sentiment Analysis  

Learning Objectives:  

Master text representation methods and implement a basic sentiment classification model.  

 

 

Week 12: Large Language Models (LLMs) and Generative AI  

  • Transformer Architecture and Self-Attention Mechanism  
  • Generative AI Techniques (e.g., ChatGPT Principles)  
  • Ethical Discussion: Authenticity of Generated Content  

Learning Objectives:  

Understand the core ideas of Transformers and evaluate strengths/weaknesses of generative models.  

 

 

Week 13: Information Retrieval and Knowledge Extraction  

  • Inverted Index and Similarity Computation (Cosine Similarity)  
  • Entity Recognition and Relation Extraction  
  • Case Study: Building a Simple Search Engine  

Learning Objectives:  

Implement keyword-based retrieval systems and extract structured knowledge.  

 

 

Week 14: Robotics and Embodied Intelligence  

  • Perception-Action Cycle in Robotics  
  • Basics of SLAM (Simultaneous Localization and Mapping)  
  • Case Study: Obstacle Avoidance in Simulation Environments  

Learning Objectives:  

Understand robot-environment interaction mechanisms and design basic control strategies.  

 

 

Week 15: Final Project Paper Presentation  

Project Theme: End-to-End AI System Development  

  • Task 1: Implement multi-class image generation (e.g., style transfer) using CNNs and transfer learning.  
  • Task 2: Develop a dialogue system integrating intent recognition and response generation.  

Evaluation Criteria:  

  • System Integrity (40%): Functional module collaboration.  
  • Innovation (30%): Model optimization using course concepts.  
  • Academic Paper (30%): Theoretical process and scientific analysis.  

 

 

Week 16: AI Future Prospects and Comprehensive Assessment  

Content:  

  • Knowledge Review and Frontier Technology Outlook (e.g., Multimodal AI, Embodied Intelligence)  
  • Written Exam: Covering core concepts and algorithmic principles  

Learning Objectives:  

Reinforce course knowledge and inspire exploration into AI’s future development.
