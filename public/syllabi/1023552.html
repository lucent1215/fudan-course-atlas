课程简介（中文）

本课程内容包括数据挖掘的对象，包括数据的基本类型、统计指标等；数据挖掘的流程，包括数据的评估手段、数据预处理的方法等；数据挖掘的具体算法，包括频繁模式挖掘、多种分类算法、多种聚类算法等；以及数据挖掘中对异常信息的定义和处理手段，如离群点检测等；同时会介绍数据挖掘的前沿应用。

课程简介（英文）

This course covers the following aspects of data mining: Data mining objects - including fundamental data types and statistical metrics; Data mining processes - encompassing data evaluation methods and data preprocessing techniques; Core algorithms - featuring frequent pattern mining, various classification algorithms, and diverse clustering algorithms; Anomaly detection - including definitions of abnormal information and processing methods like outlier detection; Cutting-edge applications - the course will also introduce advanced contemporary applications in the field of data mining.

教学目标

我们生活在大数据日积月累的时代，随着数据量的增多，学会认识、抽取、分析、利用这些数据成为一项重要的需求。本课程期望学生们能够了解数据挖掘的重要性、数据挖掘使用的场景和目的、数据挖掘的相关应用和历史发展。具体地，本课程希望学生能够了解数据的基础信息、数据的指标以及简单的评估处理手段；本课程希望学生能够对数据仓库、数据立方体的相关技术能够有一定的了解；本课程希望学生能够对频繁模式挖掘的具体算法能够熟练掌握；本课程希望学生能够熟练掌握分类和聚类的各项算法，能够灵活应用在不同的数据场景中；本课程希望学生能够对离群点检测的相关算法有所了解；最后，本课程希望能为同学们拓展更多关于相关前沿领域的研究。

教学方式

现场授课

教学内容与进度安排

按36学时共计18周，18周含考试周

1.  本次课程将会介绍数据挖掘的基本概念，包括数据挖掘的重要性、数据挖掘所适用的场景和目的、数据挖掘的相关应用以及数据挖掘的历史发展。

2.  本次课程将会介绍数据相关内容，包括数据的基本类型、数据的统计指标、数据的可视化以及数据相似度的衡量。

3.  本次课程将会介绍数据预处理的相关概念，包括数据质量评估、数据清洗、数据整合、数据去重以及数据离散化等。

4.  本次课程将会简单介绍数据仓库的相关概念，包括数据立方体的相关知识、联机事务处理技术、数据仓库的设计与用途以及数据仓库的实现。

5.  本次课程将会介绍数据立方体的相关技术，包括数据立方体的计算方法、基于数据立方体的查询处理以及基于数据立方体的多维数据析。

6.  本次课程将会介绍频繁模式挖掘的相关概念，包括频繁模式、关联相关性、频繁模式挖掘方法、频繁模式的评估。

7.  本次课程主要将会介绍频繁模式挖掘在复杂数据中的挖掘方法，包括多层次多维度空间中的挖掘、有限制的频繁模式挖掘等。

8.  错题讲解、课程project布置，介绍

9.  期中复习

10. 本次课程主要介绍分类的相关概念，包括决策树、贝叶斯分类器、基于规则的分类器以及分类器的评估。

11. 本次课程主要将会介绍分类的高级算法，包括贝叶斯信念网络、后向传播、支持向量机、利用频繁模式的分类、惰性学习以及一些其他分类器。

12. 本次课程将会介绍聚类的相关算法，包括基于划分的方法、层次聚类、基于密度的聚类还有基于网格的聚类。

13. 本次课程将会深入介绍聚类的方法，包括基于概率模型的聚类、聚类高维数据、聚类图和网络以及带有约束的聚类。

14. 错题讲解、课程project交流

15. 本次课程主要介绍离群点检测，包括离群点的定义、基于统计、聚类、分类、相似性的离群点检测、情景离群点、集体离群点以及高维数据的离群点检测。

16. 复习
