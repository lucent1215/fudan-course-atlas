课程简介（中文）

课程从安全概念、攻击方式、网络安全解决方案入手，系统讲解防火墙的核心技术、策略配置、应用部署等知识。结合安全实战，讲解防火墙的攻防作用。课程主要内容包括：防火墙核心技术、基本结构、模型与分类、防火墙典型应用、防火墙产品配置与部署、防火墙新技术、数据安全治理与防火墙技术保护等。

课程简介（英文）

The course starts with security concepts, attack methods, and network security solutions, and systematically explains the core technology, policy configuration, application deployment, and other knowledge of firewalls. Combining security practical experience, explain the offensive and defensive functions of firewalls. The main content of the course includes: core technologies of firewalls, basic structures, models and classifications, typical applications of firewalls, configuration and deployment of firewall products, new technologies of firewalls, data security governance and firewall technology protection.

教学目标

通过对防火墙技术的深入学习，掌握防火墙的原理和技术，学习防火墙的配置和部署，更好掌握网络安全攻击与防御技术，提高安全知识和能力。从国家数据安全法出发，利用防火墙技术提升数据保护能力，增强数据防泄密的安全意识，树立正确的安全素养。通过国内外攻防技术的发展以及最近几年我国遭受到的国外网络攻击，建立国家网络安全观，提升社会责任感。

教学方式

1、课堂教学，讲解防火墙基础知识

2、案例分析，结合信息安全实际案例，分析防火墙的实际应用

3、分组讨论，根据安全需求，通过分组讨论的方式研究防火墙的具体使用，满足安全需要

4、布置作业，结合课堂内容，完成相关作业

教学内容与进度安排

第一周：防火墙概论与安全基本知识（网络安全问题、防火墙介绍、防火墙功能与特点、防火墙局限性、防火墙分类）

第二周：TCP/IP协议与防火墙工作原理（TCP/IP协议层次、数据链路层、网络层、传输层协议介绍、防火墙数据识别）

第三周：网络传输与防火墙工作原理（一个网络的数据传输方式、多个网络之间的数据传输方式、防火墙网络访问行为识别）

第四周：包过滤防火墙技术（防火墙技术分类、简单包过滤防火墙）

第五周：状态检测防火墙（防火墙检测技术、过滤规则、状态检测包过滤防火墙）

第六周：应用代理防火墙（工作协议、安全策略、复合型应用防火墙）

第七周：WAF防火墙（Web网站的安全问题、Web应用防火墙主要技术）

第八周：防火墙核心技术（DMZ、虚拟专用网技术、网络地址转换技术）

第九周：网络地址翻译NAT与应用代理技术、防火墙案例分析

第十周：防火墙安全策略、ASA5505防火墙功能及使用

第十一周：操作演示,防火墙安全规则设置与验证与防火墙DMZ配置及访问控制

第十二周：防火墙体系结构与部署（防火墙体系结构及功能、防火墙部署方式）

第十三周：防火墙重要功能（双机热备、端口映射、地址绑定）

第十四周：防火墙指标与案例分析（功能分类、性能指标、防火墙案例分析）

第十五周：防火墙应用设计（防火墙体设计原则、防火墙类型及评估）

第十六周：防火墙攻防技术与数据安全法对网络保护的要求（多种网络攻击手段以及防火墙的防御技术、数据安全法内容以及对防火墙的更高指标要求）

第十七周：复习与答疑

第十八周：考试
