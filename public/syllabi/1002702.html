课程简介（中文）

《程序设计》是计算机科学的基础课程，重点讲解C语言语法、程序结构及基础算法设计。课程涵盖数据类型、流程控制、函数、数组、指针、文件操作等核心内容，通过实践培养学生逻辑思维与编程能力。学生将掌握结构化程序设计方法，为后续学习数据结构、操作系统等课程奠定基础。适合零基础学习者，强调理论与实践结合。

课程简介（英文）

Programming Language is a foundational course in computer science, focusing on C syntax, program structure, and basic algorithm design. It covers core concepts such as data types, control flow, functions, arrays, pointers, and file operations. Through hands-on practice, students develop logical thinking and programming skills. The course teaches structured programming methods, preparing learners for advanced topics like data structures and operating systems. Suitable for beginners, it emphasizes a balance of theory and practice.

教学目标

以C语言程序设计为载体，实现以下教学目标：​​

  1. ​​价值引领​​：培养严谨求实的编程态度。通过代码调试与优化，养成精益求精的工匠精神。

  2. ​​知识传授：​​掌握C语言核心语法（数据类型、流程控制、函数、数组、指针等）及结构化程序设计思想。初步理解计算机底层逻辑（如内存管理、文件操作），为后续专业课程奠定基础。

  3. ​​能力培养​：​提升逻辑思维与算法设计能力，能独立解决实际问题。培养开发能力，并适应新技术自主学习的需求。

教学方式

课堂教学（每周三课时）+上机实践（每周两课时）

教学内容与进度安排

教学内容与进度安排（理论48学时+实验32学时）​​

​​理论教学（48学时）​​

  1. ​​C语言基础（8学时）​​

    • 程序设计概念与开发环境（2学时）
    • 数据类型、运算符与表达式（4学时）
    • 标准输入输出与格式化（2学时）

  2. ​​流程控制（8学时）​​

    • 条件语句（if-else、switch-case）（2学时）
    • 循环结构（for/while/do-while）（4学时）
    • 流程控制综合应用（2学时）

  3. 数组与字符串（8学时）​

    • 一维/二维数组（4学时）
    • 字符数组与字符串处理（4学时）

     

  4. ​函数与模块化编程（8学时）​​

    • 函数定义与调用（2学时）
    • 参数传递机制（2学时）
    • 递归函数与案例（4学时）

  5. ​​​指针与内存管理（6学时）​​

    • 指针基础与运算（4学时）
    • 指针与数组/函数（2学时）

  6. ​​结构和链表（8学时）​​

    • 结构体（3学时）
    • 动态内存管理和链表（5学时）
  7. 文件操作（2学时）

​​实验教学（32学时）​​

  1. ​​基础实验（8学时）​​

    • 开发环境与基础语法（2学时）
    • 流程控制编程（3学时）
    • 函数实现与调试（3学时）

  2. ​​基础数据结构实验（12学时）​​

    • 数组应用（4学时）
    • 字符串处理（4学时）
    • 指针与内存操作（4学时）
  3. 习题讲解和提高（12学时）
