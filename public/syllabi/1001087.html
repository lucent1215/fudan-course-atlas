课程简介（中文）

从零基础出发，系统讲解Python核心语法、数据结构（列表、字典等）、流程控制、函数定义、文件操作及面向对象基础。课程强调实践应用，通过大量上机练习和项目实战，培养学生利用Python解决实际问题的能力，并初步接触常用库（如数据处理、可视化）。旨在提升学生的计算思维、逻辑分析能力和跨学科工具应用技能，为数据分析、人工智能等领域学习奠定基础，开启编程之旅。

课程简介（英文）

Starting from scratch, this course systematically covers core Python syntax, data structures (lists, dictionaries, etc.), flow control, function definition, file operations, and object-oriented fundamentals. It emphasizes practical application, fostering students' ability to solve real-world problems using Python through extensive hands-on exercises and project-based practice, while providing initial exposure to commonly used libraries (e.g., for data processing and visualization). The course aims to enhance students' computational thinking, logical analysis skills, and cross-disciplinary tool application abilities, laying a foundation for learning in fields like data analysis and artificial intelligence, and kickstarting their programming journey.

教学目标

• 系统掌握Python核心编程范式：语法结构、数据结构（列表/字典/集合）、字符串处理、函数、文件操作，正则表达式。

• 理解常用库（如NumPy/Pandas/Matplotlib）在数据分析与可视化中的应用逻辑。

• 了解：异常处理，及面向对象编程基础。

• 通过代码行实战训练，形成独立编写程序解决工程/科研场景问题的能力。

• 提升计算思维（问题分解、模式抽象）与跨学科工具迁移能力，为人工智能、金融建模等前沿领域奠定开发基础。
