课程简介（中文）

通过学习c语言的基本数据类型及运算、控制结构、数组、函数、指针、结构、文件等内容，掌握C语言的基本概念和语句，以及c程序设计的基本思想和方法，能够编写和调试C应用程序。

课程简介（英文）

‌By studying the following content in C language:‌

  • Basic data types and operations
  • Control structures
  • Arrays
  • Functions
  • ‌Pointers‌
  • Structures
  • File handling

‌Students will:‌

  1. Master ‌fundamental concepts and syntax of C programming‌;
  2. Acquire ‌core principles and methodologies of structured programming‌;
  3. Develop the ability to ‌write and debug C applications‌.

教学目标

  1. 使学生掌握用计算机解决问题的一般思路和方法。学生能掌握IPO（输入-处理-输出）的程序结构，掌握基本控制流语法，能选择适合具体应用需求的数据结构和相应算法来完成简单计算任务，具有较为扎实的编程基础。
  2. 对于复杂计算任务，学生能够运用自顶向下的模块分解方法，转为简单问题计算。并掌握编写和调试C语言应用程序的能力,并为以后进一步自习其它程序语言和提高程序设计能力打下坚实的基础。
