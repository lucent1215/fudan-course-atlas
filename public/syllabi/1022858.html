课程简介（中文）

简要概括和总结基本的线性代数和统计学概率与数理统计知识、熟悉编程语言和数据库的基本知识、主要介绍机器学习的主要流程以及主要的概念， 包括监督学习、非监督学习、回归、分类以及现如今广泛应用的主流算法和理论。在基础知识之上，简单介绍在材料领域中用到的机器学习的范例，同时介绍量子化学和分子动力学模拟在机器学习中的重要性。

课程简介（英文）

    This course will briefly summarize the fundamental knowledge of linear algebra, statistical probability and distribution theory, python programming language and databases. In addition, this course will introduce the main workflow and concepts in machine learning, including supervised learning, unsupervised learning, regression, classification and some mainstream algorithms. Importantly, some representative examples of machine learning in material science will be introduced. Meanwhile, the importance of quantum chemistry and molecular dynamics simulations in machine learning will be emphasized at the end.

教学目标

本课程是一门融合统计学机器学习理论与材料化学领域的跨学科交叉课程。课程的目的是给同学们普及统计学和机器学习在材料科学中的应用。在一定的线性代数、概率论和统计学的基础上，利用基础学科中的知识熟悉人工智能中的主流算法和相关应用方法以及利用代码实现的方法。因此本课程旨在理论、编程和实际应用三个方面加强同学们对于人工智能在材料科学中的应用。 这对于未来利用机器学习提高材料领域的发展效率有重要的意义。

  1. 核心知识：熟悉机器学习相关的概念和常用的机器学习的模型。
  2. 学以致用：掌握数据科学和Python语言的基础编程方法，利用机器学习解决材料学科领域中的问题。
  3. 触类旁通：熟知现阶段领域内的新方法和新技术
  4. 人性维度：认识人工智能在社会中的作用
  5. 志趣情怀：深入体会了解学科交叉和融合，推陈出新，创建人工智能领域的新方向
  6. 学会学习：创建有意义的学习方法，并且合理的分配学习的时间

This course is an interdisciplinary curriculum integrating statistical machine learning and material science. The purpose of the course is to introduce the diverse applications of machine learning in material science. Building on the fundamental knowledge of linear algebra, probability theory and statistics, this course will further introduce the mainstream machine learning algorithms, the python programming language, and the representative examples in practical applications. Therefore, this course aims to reinforce the application of machine learning in material science from three aspects, including theory, programming, and practical application. This is of great significance for the application of machine learning to improve the development of the material science in the future.
