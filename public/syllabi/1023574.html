课程简介（中文）

本课程深入剖析现代计算机系统的内部工作原理与软硬件权衡策略。内容涵盖数据表示、指令系统、CPU架构（流水线）、存储层次及I/O互联。旨在帮助学生建立完整的整机概念，掌握硬件基础理论及性能评测方法，培养对编程语言与应用开发的底层全局把握能力，为深入研究计算机系统奠定坚实基础。

课程简介（英文）

This course provides an in-depth analysis of the internal mechanisms and hardware-software trade-offs of modern computer systems. Topics cover data representation, instruction systems, CPU architecture (pipelining), memory hierarchy, and I/O interconnection. The course aims to help students build a comprehensive system-level perspective, master fundamental hardware theories and performance evaluation methods, and cultivate a holistic understanding of the low-level foundations supporting programming languages and applications, laying a solid basis for advanced study in computer systems.

教学目标

本课程教学目标涵盖三个维度：

知识目标： 深入理解现代计算机系统的内部运作机理，构建完整的软硬件整机概念，夯实系统的硬件理论基础。

能力目标： 掌握软硬件界面划分的权衡策略，具备从底层视角审视编程语言与应用开发的全局把握能力，能进行系统性能评测。

素养目标： 培养宏观的系统工程思维，领会“软硬协同”与“时空转换”的工程设计哲学，确立严谨的科学实践态度。
