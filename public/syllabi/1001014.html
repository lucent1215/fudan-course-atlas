课程简介（中文）

  1. 信息系统安全概论，讲解信息系统安全的基本概念、发展历史、典型的方法学；
  2. 信息系统安全理论和方法，讲解分析系统安全威胁的方法；网络空间身份管理的理论和方法；授权和访问控制理论和方法；信息审计的理论与方法；密码工程；程序安全概论；系统安全理论分析方法；可信计算；物理安全。
  3. 典型信息系统安全：Web安全、区块链安全、安全多方学习；

课程简介（英文）

1. Introduction to Information System Security: Covers the basic concepts, development history, and typical methodologies of information system security.

2. Theories and Methods of Information System Security: Explains approaches to analyzing system security threats; theories and methods of cyberspace identity management; authorization and access control theories and methods; theories and methods of information auditing; cryptographic engineering; introduction to program security; theoretical analysis methods for system security; trusted computing; physical security.

3. Typical Information System Security Topics: Web security, blockchain security, and secure multi-party learning.

教学目标

信息系统安全课程从构建安全系统的角度，为学生讲解信息系统安全的基本理论和技术，通过大作业和实验训练，使得学生掌握分析信息系统安全威胁、设计信息系统安全保障方法和机制的能力，为保障国家数字化转型中的网络空间安全培养优秀人才。
