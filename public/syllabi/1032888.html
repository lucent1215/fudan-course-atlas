课程简介（中文）

【课程提供AI coding资源】本课程根据Agent时代智能软件构建特点，讨论Agent软件设计和构建的核心技术和过程，包括：AI Coding, Agent软件架构，Agent UI，Agent软件评估。具体包括：Coding Agent架构（Claude Code, DeepAgent）、Agent软件核心技术（Voice Agent、Agent编排和AI Native UI）、Skills（UI-UX）、观测与评估（Observation and Evaluation）。案例结合学术前沿论文和工业最佳实践，培养AI时代研究生Agent软件研发能力。

 

课程简介（英文）

This course discusses the core technologies and processes for building AI Agent software, including AI Coding, Agent Frameworks, Agent UI, and Agent software UX. Specifically, it covers Coding Agent Architecture (Claude Code, DeepAgent), Core Technologies for Agent Software Interfaces (Voice Agent, Agent Orchestration, and AI Native UI), Skills (UI-UX), and Observation & Evaluation. Case studies combine cutting-edge academic papers and industrial best practices to solid research and development skills in Agent software for graduate students.
