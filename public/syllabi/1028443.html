课程简介（中文）

本课程以Java程序设计语言为核心，深入讲解面向对象程序设计的核心理念与技术实现。课程涵盖Java的封装、继承、多态等基本特性，穿插C++、Python、C#等面向对象语言对比分析，同时对照了函数式编程语言的区别，帮助学生建立全面编程思维。课程还介绍Spring Framework框架应用，包括依赖注入、面向切面编程等现代企业级开发技术，培养实际项目开发能力。

课程简介（英文）

This course centers on the Java programming language and provides in-depth coverage of core concepts and technical implementation of object-oriented programming. The curriculum covers fundamental Java features such as encapsulation, inheritance, and polymorphism, while incorporating comparative analysis of other object-oriented languages like C++, Python, and C#, as well as contrasting with functional programming languages to help students develop comprehensive programming thinking. The course also introduces Spring Framework applications, including dependency injection, aspect-oriented programming, and other modern enterprise-level development technologies, cultivating practical project development capabilities.

教学目标

通过本课程的学习，学生在已有的C语言程序设计的基础上，掌握Java程序设计语言，并深入掌握面向对象程序设计的原则和技能，训练学生能够熟练使用面向对象的方法编写具有一定复杂度的应用。同时，在学习的过程中， Java与其他其他面向对象的程序设计语言，函数式语言进行对比，拓宽对面向对象技术的理解。

课程还会从面向对象的视角介绍Springframework，作为面向对象应用的案例。

教学方式

课堂讲授

课后上机实习、Lab(5次)+Pj, 课堂讨论(1次)

教学内容与进度安排


第1周
- 教学内容：课程简介，Java语言发展历史与特点，Java开发环境搭建
- 教学目标：了解课程整体安排，熟悉Java语言发展历程，掌握开发环境配置方法

第2周
- 教学内容：Java基本语法，数据类型，运算符，控制结构，方法定义与调用
- 教学目标：掌握Java语言基本语法规则，能够编写简单的Java程序，理解程序执行流程

第3周
- 教学内容：对象与类的概念，类的定义与实例化，构造方法，成员变量与方法
- 教学目标：理解面向对象基本概念，掌握类的定义和对象创建方法，学会封装基本数据

第4周
- 教学内容：面向对象的思想，封装原则，访问修饰符，getter/setter方法
- 教学目标：深入理解面向对象编程思想，掌握封装概念的应用，学会设计合理的类接口

第5周
- 教学内容：继承的概念与实现，子类与父类关系，方法重写，super关键字应用
- 教学目标：理解继承机制，掌握方法重写技术，学会利用继承构建类层次结构

第6周
- 教学内容：多态的概念，动态绑定，抽象方法，instanceof操作符使用
- 教学目标：深入理解多态机制，掌握动态绑定原理，学会编写多态性代码

第7周
- 教学内容：抽象类与接口的区别，接口定义与实现，多接口实现，接口回调机制
- 教学目标：区分抽象类与接口的适用场景，掌握接口设计与实现，理解接口在系统设计中的作用

第8周
- 教学内容：异常处理机制，try-catch-finally语句，自定义异常，文件I/O操作
- 教学目标：掌握异常处理编程技巧，学会文件读写操作，能够编写健壮的程序

第9周
- 教学内容：课程内容讨论，问题解答，实践项目交流，编程技巧分享
- 教学目标：巩固前8周学习内容，提高问题分析能力，促进同学间经验交流

第10周
- 教学内容：泛型的基本概念，类型参数，泛型类与泛型方法，泛型约束
- 教学目标：理解泛型编程思想，掌握泛型类的定义和使用，学会编写类型安全的代码

第11周
- 教学内容：Java Collections框架，List、Set、Map接口，常用实现类，集合遍历
- 教学目标：熟练使用Java集合框架，掌握不同集合类型的特点，能够选择合适的集合存储数据

第12周
- 教学内容：面向对象的IO库java.io，字节流与字符流，文件读写操作，序列化与反序列化
- 教学目标：掌握Java IO编程，理解不同IO流的特点，学会文件处理和数据持久化

第13周
- 教学内容：JavaFX概述，FXML界面设计，JavaBeans概念，事件驱动编程基础
- 教学目标：了解JavaFX框架，学会创建用户界面，理解事件驱动的编程模型

第14周
- 教学内容：JavaFX事件处理，绑定机制，属性监听，响应式UI设计
- 教学目标：掌握JavaFX事件处理机制，学会创建响应式用户界面，理解属性绑定原理

第15周
- 教学内容：Spring Framework概述，依赖注入概念，Bean配置，Spring Boot快速开发
- 教学目标：了解企业级开发框架，掌握依赖注入原理，学会使用Spring简化开发流程

第16周
- 教学内容：课程总复习，重点知识梳理，问题答疑，学习方法指导
- 教学目标：系统回顾课程内容，查漏补缺，掌握面向对象编程的核心技能
