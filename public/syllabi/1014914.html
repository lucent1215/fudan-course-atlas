课程简介（中文）

本课程面向硕士/博士研究生全面地讲述高级网络原理与核心技术，包括TCP/IP核心网络协议、网络QoS 与拥塞控制、软件定义网络、网络功能虚拟化、数据中心网络、多媒体传输网络协议、多媒体通信系统与流媒体协议、无线网络、内容分发网络、未来网络体系架构等。结合网络领域主流国际会议Sigcomm、Infocom、NSDI、ICDCS、ICNP、IWQoS和国际权威期刊TON、JSAC、IEEE Network、TMC等展开与此相关的网络前沿专题研究。最后讨论和展望网络领域各种相关的前沿技术发展。

课程简介（英文）

This course comprehensively covers advanced network principles and core technologies for master's/doctoral students, including TCP/IP core network protocols, network QoS and congestion control, software defined networks, network function virtualization, data center networks, multimedia transmission network protocols, multimedia communication systems and streaming media protocols, wireless networks, content distribution networks, future network architecture, etc. Conduct cutting-edge research on network related topics by combining mainstream international conferences such as Sigcomm, Infocom, NSDI, ICDCS, ICNP, IWQoS, and authoritative international journals such as TON, JSAC, IEEE Network, TMC, etc. Finally, discuss and look forward to the development of various cutting-edge technologies in the field of networking.

教学目标

本课程面向硕士/博士研究生全面地讲述高级网络原理与核心技术，包括TCP/IP核心网络协议、网络QoS模型与算法、拥塞控制模型与方法、网络路由机制、软件定义网络与网络功能虚拟化、数据中心网络、多媒体传输网络协议、多媒体通信系统与流媒体协议、无线网络、内容分发网络、可编程网络、云原生网络、未来网络体系架构等。课程教学中讲述内容与专题研究相结合，培养研究生在理解教师讲授内容的基础上能够开展小组专题研究和论文讨论，提高网络技术方面的学术研究能力。并将研究与系统设计相结合，在研究的基础上培养研究生能够进行网络相关系统的分析和一些关键技术方案的设计与实施。总体上，重点培养学生理解现有网络体系结构中面临的根本性问题，以及未来网络体系结构的发展趋势。在此基础上在网络技术相关的模型算法与系统设计中具备分析、解决问题的能力，为未来开展网络技术相关的研究、设计和开发工作打下坚实基础。
