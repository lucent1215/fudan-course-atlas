课程简介（中文）

云原生技术已经成为软件开发行业中广泛采用的技术之一，是许多企业软件开发的必备技能。本课程围绕云原生中的容器、微服务、持续交付、Devops等核心概念开展教学，介绍这些技术的基本原理与应用模式，结合项目任务实训锻炼学生技能，使学生能够清楚理解云原生软件技术的内涵，基本掌握云原生相关工作的使用。

课程简介（英文）

Cloud native software technology is now widely used in software development and has become a crucial skill for many enterprises.In this course,we'll explore the key cloud native concepts including containers, microservices, continuous delivery and DevOps. We'll delve into their principles and application patterns,and through hands-on project training, the students can gain a solid understanding of cloud native technology and become proficient in using related tools.

教学目标

通过本课程，使学生了解云原生技术的核心内涵，基本掌握云原生的重要知识点，包括容器、Kubernetes编排、微服务、Devops等，能够使用工具实现云原生应用的开发、容器编排、服务治理等实践。培养学生自主学习前沿技术，并通过团队合作进行工程实践和创新的能力，树立科技强国的志向。

教学方式

采用理论知识教学与项目实训结合的方式。课堂上按照教学内容开展云原生软件技术的教授，穿插助教的云原生工具使用讲解，围绕专题内容的课堂讨论，以及企业专家经验分享。项目实践方面，Lab大致分为容器技术实践、容器编排实践、微服务拆分设计、服务网格技术实践等环节，由助教进行面试评分。

教学内容与进度安排

第一周  内容：课程简介与云原生软件技术概述。目标：对云原生软件技术有初步理解。

第二周  内容：虚拟化与云计算。目标：对虚拟化技术的分类、发展，云计算技术的内涵、发展等具有初步理解。

第三周  内容：容器化技术与Docker。目标：对容器化技术的特点、原理等具有初步理解，学习对Docker工具的基本使用方式。

第四周  课堂实践：Docker技术实践。作业：布置Docker相关Lab。

第五周  内容：容器编排Compose和Swarm。目标：基本理解Compose和Swarm的特点与使用方式。

第六周  内容：容器编排Kubernetes。目标：基本理解Kubernetes的基本内涵、结构与应用场景。

第七周  内容：容器编排Kubernetes。目标：深入理解Kubernetes的workload、配置等技术内容。

第八周  课堂实践：Kubernetes技术实践。作业：布置Kubernetes相关Lab。

第九周  内容：微服务架构基础。目标：基本理解微服务架构的特点与原则。

第十周  内容：微服务应用设计与开发。目标：基本掌握基于微服务架构的应用的设计原则与开发过程。

第十一周  内容：面向生产的微服务。目标：基本理解微服务的服务治理与服务网格等技术。

第十二周  内容：邀请企业专家经验分享。目标：接触实际企业中云原生应用情况与未来发展趋势。作业：布置微服务拆分设计方面的Lab。

第十三周  内容：无服务器架构Serverless。目标：基本理解Serverless的特点与应用方式。

第十四周  内容：监控与可观测。目标：基本掌握云原生可观测性技及其应用。

第十五周  内容：面向边缘环境的云原生技术。目标：基本理解云边协同KubeEdge框架的技术架构。

第十六周  考试。
