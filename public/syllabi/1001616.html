课程简介（中文）

课程面向零基础学生，当前流行的Python非常适合作为非计算机专业学生的第一种编程语言。

本课程采用Python语言作为载体，学习内容包括：Python序列：列表、元组、字典、集合，控制结构：选择、循环，字符串常用操作方法，字符串函数，正则表达式，函数定义与使用，模块定义与使用，文件操作，异常处理。

课程简介（英文）

This course is designed for beginners with no prior programming experience.The currently popular Python is very suitable as the first programming language for non-computer science students. 
Using Python as the teaching language, it systematically covers programming fundamentals including:
Python sequences: lists, tuples, dictionaries, sets; control structures: selection, loops; common string operation methods, string functions, regular expressions, function definition and usage, module definition and usage, file operations, exception handling.

教学目标

课程作为通识教育专项课程，课程目标是面向非计算机专业学生，使学生熟练掌握Python常用数据类型，控制结构，字符串处理，函数，文件操作等基本语法，了解：正则表达式，模块，异常处理等同时，了解用计算机解决问题的一般思路和方法，掌握编程的基本过程和方法；也使学生具备在自己专业领域运用Python进行数据分析与科学计算、人工智能与机器学习等应用的持续学习能力。培养学生终身学习意识，强化学生可迁移能力的培养，促进学生可持续发展。

教学方式

课程以老师课堂讲解和学生实践练习相结合方式：

  • 授课方式：第1，2节，通过播放PPT讲解和操作演示，eLearning平台上传课件（包括讲课视频录像）；第3，4节学生在机房上机练习,同时提供课堂lab，任课老师和助教上机辅导答疑。
  • 课外练习：每周一次作业，第10周布置一个大作业PJ。
  • 课外辅导：建立课程钉群，进行线上答疑，个性化辅导
  • AI辅助：鼓励学生运用Deepseek等AI辅助工具，进行个性化学习探索，培养学生持续学习的能力。

教学内容与进度安排

教学内容安排 (按64学时共计16周，18周含考试周，具体到每节课内容):
第1周: Python 安装，掌握Python开发环境配置（VS Code+AI插件），Helloworld程序，基本输入输出语句。课程思政元素：通过介绍Python语言开源、开放、兼容的特点，培养学生的兼容并包、开放进取的心态，提高学生接受新生事物，探索前沿技术的能力，提高学生的创新能力。目的：可以进行python安装，熟悉python 的IDE使用，可以编写运行helloword程序。
第2周: 变量与对象，数据类型，运算符和表达式，常用内置函数。目的：理解变量、对象，表达式的含义，会使用对数值类型的处理的常用内置函数。
第3周: 函数简单入门，包括函数定义，形参和实参，字符串基础知识 目的：具备自定义函数的能力。
第4周: 国庆节放假停课
第5周: 模块导入和使用，代码规范，文件名，__name__属性，字符串，简单程序实例。目的：掌握import语句、对字符串对象的处理，可以编写具有一定规范简单的程序。
第6周: 列表，简单循环语句。目的：掌握列表对象的创建、列表对象原地修改，可以使用循环语句对列表对象中的元素进行处理。
第7周: 切片、简单的选择语句、列表推导。目的：掌握切片的概念，可以使用切片对列表进行检索，修改，可以使用列表推导式创建列表。
第8周: 列表排序，元组，目的：掌握元组对象的创建和处理，可以使用sort方法和sorted函数对列表对象进行排序。
第9周: 字典，集合。目的：掌握字典、集合对象的创建和处理，
第10周: 条件表达式，选择语句，目的：掌握条件表达式、if语句的写法。
第11周: 循环语句，break和continue，循环嵌套。目的：掌握while、for语句的写法。
第12周: 字符串，文件操作，课程思政元素：通过加解密例子介绍，加强学生信息安全意识。目的：掌握字符串对象处理的方法、以及文件读写的方法。
第13周: 正则表达式，目的：掌握正则表达式写法，以及python中re模块的使用。
第14周: 函数 、参数类型、return语句、变量作用域，实例，目的：掌握函数的参数类型，以及变量作用域的概念。
第15周: 异常处理。目的：掌握python中异常处理基本框架。
第16周: 复习答疑。目的：梳理课程难点重点，答疑解惑。
