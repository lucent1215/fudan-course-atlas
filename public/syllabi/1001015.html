课程简介（中文）

介绍信息系统安全的需求和原理，了解信息系统安全机制设计的一系列关键设计元素，其中包括信息系统软件漏洞和恶意行为分析技术、认证、访问控制、信息保护与隔离机制等。此外，本课程将以数据处理、数据库等信息系统软件为例，介绍从底层操作系统到上层软件的安全防御机制设计，以及近年来随着信息系统安全攻防的深入，产生的新型安全威胁与对应的系统安全新机制。并将介绍如何通过软件分析技术和操作系统安全策略等应对恶意软件等传统信息系统安全威胁。

课程简介（英文）

This course introduces the needs and principles of information system security, and examines a series of key design elements in security mechanism development, including software vulnerabilities in information systems, malicious behavior analysis techniques, authentication, access control, and mechanisms for information protection and isolation.

Using examples such as data processing systems and database software, the course explores the design of security defense mechanisms from the underlying operating system to the application layer. It also covers emerging security threats that have arisen from the evolving offense-defense dynamics in information system security in recent years, along with the corresponding new system security mechanisms.

In addition, the course discusses how to address traditional information system threats, such as malware, through software analysis techniques and operating system security policies.

教学目标

本课程主要介绍信息系统安全的基本概念和经典信息系统安全机制的设计原理，系统地从安全分析技术和安全防护机制两个方面，讨论安全威胁和对应的系统安全防护策略。将会讨论信息系统漏洞和恶意行为分析技术、认证、信息保护与隔离机制、访问控制等安全防护机制。并以最新数据处理应用软件为例，分析信息系统安全技术的使用方法，结合案例分析和课程实验，熟悉主流信息系统的安全机制设计及常用的安全检测和安全防御技术。
