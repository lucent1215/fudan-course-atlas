课程简介（中文）

本课程主要任务是通过课堂教学和上机实践，使学生了解数据库基本概念和原理，以及数据库编程语言，初步了解数据库编程的基本概念。（1）理解数据模型和数据库管理系统，关系数据库和表；（2）掌握关系数据库标准语言SQL语言基本概念和操作方法，包括数据查询、更新；（3）理解数据库查询执行、查询优化等。

课程简介（英文）

The main tasks of this course are to enable students to understand basic database concepts and principles, as well as database programming languages, and to gain a preliminary understanding of the fundamentals of database programming through classroom teaching and hands-on practice. (1) Understand data models and database management systems, relational databases and tables; (2) Master the basic concepts and operational methods of the standard relational database language SQL, including data query and update; (3) Understand database query execution, query optimization, etc.

教学目标

本课程旨在通过系统化的理论教学与实践训练，使学生全面掌握数据库的核心概念、基本原理及编程开发技术。课程内容涵盖数据库系统的基础理论，包括数据模型、数据库系统结构、关系数据库设计原理以及数据完整性等关键知识点，帮助学生建立系统的数据库认知框架。在实践技能培养方面，课程重点讲授关系数据库标准语言SQL，使学生熟练掌握数据定义、数据操纵、数据查询等核心操作，能够针对实际业务需求编写复杂查询语句，并初步了解存储过程、触发器、视图等高级数据库对象的应用。同时，课程注重培养学生的主流数据库开发工具使用能力，通过上机实践使学生熟悉MySQL等数据库管理系统的操作环境，掌握基本的数据库设计与前端应用数据交互的方法。本课程不仅为学生后续学习Web开发、大数据技术、数据仓库与数据挖掘等专业课程奠定坚实的理论和实践基础，更致力于培养学生的数据思维能力和工程实践素养，使其能够理解数据库编程在软件开发生命周期中的重要地位，为成为具备数据驱动开发能力的应用型工程技术人才做好准备。

教学方式

本课程以主讲教师讲授为主，兼以课堂学生对若干具体问题分析讨论，另外通过上机操作，增强动手能力；通过课后应用系统设计对课堂所学内容进行回顾、总结；并用课堂所学知识，解决实际的问题。
