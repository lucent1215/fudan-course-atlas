课程简介（中文）

课程基本内容包括信息系统建设概论、系统规划、系统分析、系统设计、系统实施和系统维护；主要知识点包括系统分析阶段的流程建模、用例建模、领域对象建模，和系统设计阶段的结构化设计方法、面向对象设计方法、面向服务设计方法和详细设计。最后简要介绍信息系统工程进展，主要是云计算、大数据、人工智能和多智能体等信息系统技术和应用。

课程简介（英文）

The course covers the following key topics: an introduction to information system construction, system planning, system analysis, system design, system implementation, and system maintenance. The main knowledge points include process modeling, use case modeling, and domain object modeling during the system analysis phase, as well as structured design methods, object-oriented design methods, service-oriented design methods, and detailed design during the system design phase. Finally, the course provides a brief overview of the progress in information system engineering, with a focus on technologies and applications such as cloud computing, big data, artificial intelligence, and multi-agent systems.

教学目标

本课程面向保密技术和信息安全专业同学，主要讲解信息系统分析与设计的相关概念、思想、方法。通过本课程教学，使学生对信息系统分析与设计有一个全面和体系化的了解，掌握信息系统分析与设计的基本思想和方法步骤，能将所学的知识运用到企事业单位的信息系统分析与设计工作的具体实践中。

教学方式
