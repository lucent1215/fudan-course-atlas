课程简介（中文）

基于大模型与Agent等AI技术的生成式软件开发方法及工具已经在企业得到广泛采用，实现了软件开发质量与效率的大幅提升。本课程将在背景与原理介绍的基础上，讲授如何利用大模型及智能化IDE（集成开发环境）并通过问题拆解、方案规划、过程迭代、代码评审、软件测试实现完整的生成式软件开发。

课程简介（英文）

Generative software development methods and tools based on AI technologies such as large language models and agent have been widely adopted in enterprises, significantly improving both software development quality and efficiency. This course will build upon an introduction to the background and principles of generative software development, teaching how to leverage large language models and intelligent IDEs (Integrated Development Environments) to achieve complete generative software development through problem decomposition, solution planning, iterative processes, code review, and software testing.

教学目标

在理解软件开发基本过程的基础上，了解生成式软件开发的基本原理以及多种不同的生成式开发模式，掌握常见的智能化IDE使用方式。掌握与生成式软件开发相关的提示工程、上下文工程以及记忆管理策略，能够使用大模型及智能化IDE并通过问题拆解、方案规划、过程迭代、代码评审、软件测试等手段实现多种不同类型的小规模软件的完整和高质量的生成式开发。

教学方式

1）方法、技术与原理介绍

2）软件开发案例分析与讲解

3）生成式开发课堂练习与现场指导

4）个人化软件开发实践作业

5）专题问题小组研讨

教学内容与进度安排

第1部分：课程背景与基础知识

第1周：生成式开发导论与提示工程

教学目标：理解生成式软件开发与传统开发的差异，建立工程化与验证意识。完成一次结构化提示驱动的零代码生成与发布体验。

教学内容：软件开发的含义及其工程化要求；生成式软件开发与氛围编程（Vibe Coding）的基本原理及其与传统软件开发的区别；生成式软件开发初步体验；提示工程基本原理与结构化提示词的设计方法，以及 AI 生成内容的边界与验证方法。

 

第2周：生成式软件开发环境与工具

教学目标：基于大模型的生成式软件开发环境与工具的核心功能与配置；区分并熟练运用 Chat、Copilot、Agent三种交互模式。

教学内容：基于大模型的生成式软件开发环境与工具的核心功能与配置；介绍工具演进路径；Chat、Copilot、Agent三种交互模式的定义，以及开发环境和工具内的上下文管理与结构化提示。

 

第2部分：脚本和单文件应用的构造

第3周：氛围编程的关键实践（1）

教学目标：掌握生成式软件开发与氛围编程的基本过程与基本实践，包括精确描述需求、小步行进（模块化拆分）、快速迭代。

教学内容：介绍生成式软件开发与氛围编程的关键实践，包括精确描述需求、小步行进（模块化拆分）、快速迭代等。作为示例，演示基于问题描述的Python 脚本程序生成，利用AI生成处理结构化数据（Excel/CSV）的Python 脚本。

 

第4周：氛围编程的关键实践（2）

教学目标：进一步掌握氛围编程更深入的一些关键实践，包括规划先行、代码审查与理解、融入领域API等。

   教学内容：介绍氛围编程的进阶实践，包括规划先行、代码审查与理解、以及领域API的高效使用。作为示例，演示基于Streamlit框架的交互式 Web 应用生成，涵盖数据加载、图表构建（趋势图/饼图）及交互逻辑实现的完整流程。

 

第5周：[讨论课] 阶段性实践分享与讨论

 

第3部分：使用上下文工程管理复杂的多文件项目

第6周：上下文工程简介

   教学目标：了解上下文工程的基本原理，掌握多文件项目中的上下文管理策略。前后端项目的架构简介以及使用氛围编程的开发策略。

.  教学内容：介绍上下文工程的基本原理，展示上下文管理的效果，以及相关工具对多文件项目中管理上下文的策略。

 

第7周：API优先的后端开发

教学目标：理解 Vibe Coding 中 API-First 开发实践，掌握先定义接口再实现完整应用的流程。利用 AI 生成后端逻辑与 API 接口 ，并完成验证。

教学内容：API-First 模式简介；使用 AI 辅助设计 接口定义并进行评审；生成后端代码及 文档；使用 IDE 插件进行接口测试。

 

第8周：前端生成与全栈集成

教学目标：掌握 AI 驱动的前端代码生成与 API 对接技巧。实现前后端数据交互与完整的用户体验流程。初步了解验证和测试的实践。

教学内容：基于 API 文档生成前端组件；前后端集成、测试与错误排查；UI 细节优化与交互体验打磨。

   

第9周：[讨论课] 阶段性实践分享与讨论

 

第4部分：复杂系统的构建

第10周：规格说明驱动开发

教学目标：理解规格说明（Spec）驱动的开发流程。掌握对包括需求在内的各种文档的评审方法。

教学内容：软件工程中的基本概念（ 需求分析、规格定义、迭代开发）以及大模型如何应用在这个流程的各个环节。

 

第11周：模型上下文协议（MCP）

教学目标：MCP 的基本原理以及应用场景。

教学内容：MCP 架构以及Client、Host、Server的交互机制，针对演示系统配置MCP连接 Excel/PDF 等本地知识库。

 

第12周：智能体集成

教学目标：了解智能体的基本概念，智能体架构与组成，包括其应用场景、 自主性和工具调用的能力 。在演示中集成嵌入式智能体，提升自动决策能力。

教学内容：智能体基本原理，大模型作为智能体的执行引擎；角色设定、计划-执行-反思循环；通过MCP 连接本地知识库或者API，介绍低代码Agent平台基础使用，快速搭建流水线。

 

第13周：验证与测试

教学目标：建立从生成到验证的质量保障闭环，掌握自动化测试脚本的生成与执行。

教学内容：需求评审（基于需求文档的—致性检查，测试用例生成（利用 AI 生成单元测试与集成测试脚本）。

 

第5部分：项目展示与课程总结

第14周：项目讨论和展示1

形式：分组演示与答辩

演示内容：Live Demo（现场运行演示），以及提示词、上下文管理、Spec的使用技巧。

 

第15周：项目讨论和展示2

形式：分组演示与答辩

演示内容：Live Demo（现场运行演示），以及提示词、上下文管理、Spec的使用技巧。

 

第16周：课程总结与行业前瞻

教学目标：总结课程内容，了解行业发展趋势。

教学内容：软件开发角色的未来，新兴的AI编程范式以及行业发展趋势。
