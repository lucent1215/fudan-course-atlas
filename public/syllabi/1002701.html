课程简介（中文）

C语言的基本语法和基本结构，程序设计的基本原理和基本算法，C编程平台的使用和调试方法。

课程简介（英文）

This is the first course@fudan of computer programming. Through this course, we will learn the basic syntax and structure of the C language, the fundamental principles and basic algorithms of program design, and the usage and debugging methods of C programming platforms.

教学目标

面向技术大类大一新生，以C语言为载体，以计算思维的培养为导向，通过程序设计实践，掌握使用程序设计的方法解决问题的能力。

本课程将讲授四个层面的内容，具体如下：
1）C语言本身，包括C的关键词、语法等；
2）C语言和算法，包括一些经典算法的启蒙（如分治、递归、递推等）；
3）C语言和系统，通过C语言的运行解读，来启发同学们思考计算机程序在系统中的运行；
4）C语言和行业行为规范，学习开源生态的一些基本职业素养。

教学方式

面授和上机辅导

教学内容与进度安排

第1周：课程简介，计算机基本原理，简单例子和编程环介绍。介绍开源代码使用的道德。

第2周：C语言基本数据类型和输入输出基础，使用“Hello, China”例子

第3周：C语言基本运算和表达式

第4周：基本语句和选择结构

第5周：循环结构

第6周：一维数组

第7周：多维数组和字符串。使用Hello+China的例子讲述字符串拼接。

第8周：函数和库函数基础

第9周： 期中考试

第10周：指针基础

第11周：数组高级和指针行参

第12周：结构和链表

第13周：存储类别和作用域

第14周：文件处理技术

第15周：指针高级和联合位域枚举

第16周：例题选讲和期末复习
