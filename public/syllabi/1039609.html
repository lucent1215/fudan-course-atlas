课程简介（中文）

本课程面向零基础计算机专业大一新生，系统讲授C语言程序设计，涵盖类型与表达式、控制流、函数、指针、数组、结构体等内容，并结合数学问题训练C语言编程能力。课堂教学与上机实践相结合，培养编程与调试能力，配套作业、答疑与实践环节，为后续专业课程打下坚实基础。

 

课程简介（英文）

This course is designed for first-year computer science undergraduates with no prior programming background. It systematically covers C programming, including data types and expressions, control flow, functions, pointers, arrays, and structures, with mathematical programming exercises in C to reinforce core concepts. Combining classroom instruction with hands-on lab practice, the course builds programming and debugging skills through assignments, Q&A sessions, and practical exercises, laying a solid foundation for subsequent computer science courses.

教学目标

本课程旨在使零基础学生系统掌握C语言基础语法，包括类型与表达式、控制流、函数、指针、数组、结构体等核心知识，具备独立编写、调试C程序的能力。课程注重数学思维培养，通过结合数学问题的编程训练，提升学生的抽象建模与逻辑推理能力。同时强调系统思维训练，引导学生从整体角度理解程序结构与数据组织方式，养成良好的编程规范。通过课堂讲授与上机实践相结合，全面提升学生的编程实践与自主学习能力，为后续专业课程学习打下坚实基础。

 

 

教学方式

本课程采用"讲授+实践"相结合的教学方式，以实现知识传授、能力培养和习惯养成的教学目标。

  • 课堂讲解：系统讲授C语言的基本概念与程序设计方法，帮助学生构建清晰的知识体系；
  • 课堂小练习：每次课穿插5分钟左右的随堂小练习，及时巩固所学知识点，检验课堂理解效果；
  • 上机实验：安排上机实验课，强化动手能力，指导学生在真实编程环境中进行编程训练与调试；
  • 课后作业：通过在线题库（如LeetCode）布置编程题目，帮助学生巩固课堂内容、提升编程熟练度；
  • 助教答疑：课后通过微信群等渠道开展作业辅导与答疑，鼓励学生主动思考、独立解决问题，培养自主学习能力。

同时，课程引导学生使用命令行工具、AI代码编辑器、分布式版本控制系统（如GitHub、Gitee）以及在线题库等工程实践资源，提升学生的工程素养，为后续专业学习打下良好基础。
