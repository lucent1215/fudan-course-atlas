课程简介（中文）

数据库系统的基本概念，关系模型的运算理论，SQL 语言，规范化设计理论，数据 库设计全过程，数据库的存储结构，数据库查询处理过程，数据库管理系统实现技 术，数据库安全，NoSQL 数据库。

课程简介（英文）

Basic concepts of database systems, operational theory of the relational model, SQL language, normalization design theory, the entire process of database design, storage structures of databases, database query processing, implementation techniques of database management systems, database security, and NoSQL databases.

教学目标

使学生掌握数据库技术的基本原理、方法和应用技术，能有效地使用现有的数据库 管理系统和软件开发工具，掌握数据库管理系统的核心实现技术、数据库模式的设 计和数据库应用系统的开发原理。使学生了解国际上研究领域的最新问题和技术。结合当前的AI背景，进行少量AI4DB的拓展。

教学方式

•    课堂讲授
•    上机实习。主要包括 SQL 使用、信息系统开发。

教学内容与进度安排

第一周：数据库系统的基本概念，数据描述，数据模型 DB 的体系结构，DBMS 的功能与组成， DBS 的组成。 
第二周：关系模型基本概念，关系代数基本操作。 
第三周：SQL 的数据定义，SELECT 语句。 
第四周：数据更新语句，视图的操作，嵌入式 SQL。 
第五周：数据库设计的全过程，ER 模型，转换规则。 
第六周：模式的冗余问题，函数依赖。 
第七周：关系模式的分解特性，关系模式的范式。 
第八周：关系演算，关系逻辑，基于关系代数的优化。 
第九周：期中考试。 
第十周：数据库存储结构。 
第十一周：索引结构。 
第十二周：数据库查询处理技术。 
第十三周：数据库查询优化技术。 
第十五周：事务处理，DB 的恢复，DB 的并发控制、DB 的完整性，DB 的安全性。
第十六周： AI4DB拓展知识。 
第十七周：NoSQL 数据库，总复习。
