课程简介（中文）

本课程采用当前流行的 Python 语言作为载体。Python 具有语法简洁、功能强大、社区活跃等特点，非常适合作为非计算机专业学生的第一种编程语言。课程内容涵盖 Python 序列（列表、元组、字典、集合）、控制结构（选择、循环）、字符串常用操作方法与函数、正则表达式、函数与模块的定义与使用、文件操作及异常处理等基础编程知识。

为提升学习效率与问题解决能力，课程还引入了AI辅助编程环节。通过使用如 Cursor  Trae等人工智能工具，学生可以获得代码建议、自动补全、错误提示与调试建议，从而更高效地完成练习与项目开发。在学习基础编程技能的同时，也培养学生正确理解和使用 AI 工具的能力，增强其在未来职场环境中的技术适应性与创新能力。

课程简介（英文）

This course uses the popular Python language as its instructional medium. With its clean syntax, powerful features, and active community support, Python is particularly well-suited as a first programming language for students from non-computer science backgrounds. The course covers fundamental programming concepts including Python sequences (lists, tuples, dictionaries, sets), control structures (conditionals and loops), common string operations and functions, regular expressions, function and module definition and usage, file operations, and exception handling.

To enhance learning efficiency and problem-solving ability, the course also incorporates AI-assisted programming. By utilizing AI tools such as Cursor and Tabnine (Trae), students receive real-time code suggestions, auto-completion, error prompts, and debugging guidance, enabling them to complete exercises and projects more efficiently. While mastering core programming skills, students are also trained to properly understand and use AI tools, thereby strengthening their adaptability and innovation capabilities in future professional environments.

教学目标

课程目标是使学生了解用计算机解决问题的一般思路和方法，掌握编程的基本过程和方法，能够运用 Python 作为（大量）数据分析与处理的工具。同时，通过系统的编程训练，使学生更容易地将所学编程思想迁移到其他语言，提升其跨平台编程与应用能力。

本课程特别引入AI辅助编程内容，鼓励学生借助如 Cursor、Trae 等人工智能工具进行代码生成、补全、调试与优化，从而提升编程效率与解决实际问题的能力。通过引导学生科学合理地使用 AI 编程助手，增强其对新兴技术的理解与运用能力，进一步培养学生的技术迁移能力、批判性思维与创新意识。

强化学生可迁移能力的培养，是课程思政的重要目标之一；引导学生以开放、进取的姿态面对人工智能时代的挑战，是提升综合素养的重要路径。

教学方式

机房授课。通过屏幕广播软件播放PPT和操作演示，eLearning平台上传课件（包括讲课视频录像），上机辅导答疑。

教学内容与进度安排

 

第1周：Python 初识与思政引导

  • Python 安装与环境配置（IDLE / Cursor Trae 等 AI 编程工具简介）

  • 变量、数据类型、运算符与表达式

  • 常用内置函数（print(), type(), input(), len() 等）

  • 课程思政元素：介绍 Python 语言开源、开放、兼容的特点，培养学生的开放包容和探索精神，提升创新能力。

第2周：输入输出与程序结构

  • 标准输入输出、格式化输出

  • 模块导入与使用（import, from ... import）

  • Python 文件命名规范，name 属性讲解

  • 简单程序实例（如温度转换器）

  • AI辅助编程引入：体验 ChatGPT 或 Cursor 辅助编写简单程序，理解 AI 的协同能力

第3周：列表与切片

  • 列表的定义、访问、更新与遍历

  • 切片操作及常见应用

  • 常用列表方法（append(), pop(), remove(), sort() 等）

第4周：列表推导与元组

  • 列表推导式的使用与效率优势

  • 列表排序与自定义排序

  • 元组的基本概念与不可变特性

第5周：字典与集合

  • 字典操作：增删改查、遍历

  • 集合的定义、去重功能、集合运算（并、交、差）

  • 示例：词频统计、唯一值筛选

  • 国庆节放假停课

第6周：条件表达式与选择结构

  • if、elif、else 条件判断语句

  • 条件嵌套与简写表达

  • 实例：分数评级、小型决策程序

第7周：循环结构

  • for 循环与 while 循环语法

  • break 与 continue 控制流程

  • 循环嵌套与二维结构遍历

第8周：字符串处理与信息安全意识

  • 字符串操作：查找、替换、切片

  • 常用字符串方法（split, join, strip, upper, lower 等）

  • 课程思政元素：通过加密与解密的示例，强化信息安全意识

第9周：正则表达式

  • re 模块介绍

  • 常见正则语法：匹配数字、邮箱、URL等

  • 应用案例：文本过滤与格式提取

第10周：文件操作

  • 打开文件、读写文件、关闭文件

  • with语句的使用

  • 示例：处理日志文件或简单数据集

第11周：函数定义与调用

  • 自定义函数与代码复用

  • 形式参数与实际参数

  • AI 辅助编程：使用 AI 工具自动生成函数模板，提高结构化能力

第12周：函数进阶与作用域

  • return语句与函数输出

  • 变量作用域：局部与全局变量

  • 模块化思维：将大问题分解为小函数模块

第13周：异常处理

  • try-except 结构与异常类型

  • finally 子句的使用

  • AI 辅助调试：使用 AI 解释错误信息、辅助修复逻辑错误

第14周：复习与答疑

  • 课程重点梳理、易错点讲解

  • 典型编程题目回顾

  • 闭卷模拟测试准备

第15周：专题习题课

  • 大量练习题分组解决

  • 编程任务实战练习（如数据清洗、简单小游戏）

  • 分析 AI 代码与人类写法异同，提升反思能力

第16周：课程总结与项目展示

  • 个人/小组项目展示

  • 教学与学习反馈、课程建议

  • 专题讲座：AI对未来编程的影响

第17周（周六或周日）：期末考试

  • 闭卷纸质考试，包含理论题与手写程序题

  • 题型：填空、选择、简答、编程综合题
