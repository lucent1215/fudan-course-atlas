课程简介（中文）

课程内容包括系统级编程接口和服务的特点及使用方法、系统性能分析。重点讲解文件系统及I/O性能，进程环境和进程控制, 进程间通信，信号机制，linux驱动开发的概念、并行编程方法。

课程简介（英文）

The course content includes the characteristics and usage of system-level programming interfaces and services, as well as system performance analysis. It focuses on file systems and I/O performance, process environments and process control, inter-process communication, signal mechanisms, fundamental concepts of Linux driver development, and parallel programming methods.

教学目标

使学生掌握使用操作系统接口实现系统软件的方法，培养学生复杂系统程序设计的能力，熟悉典型系统级程序设计与实现方法，了解软件架构和开发技术对系统性能的影响，在程序设计中去考虑系统性能。丰富学生的系统编程知识、改善知识结构，为进一步学习、深造与就业打下良好的基础。

教学方式

课堂讲授、课堂练习及讨论、课后上机实践

教学内容与进度安排

第1周  文件系统及IO性能优化（3学时）

   文件及目录结构，文件系统的IO模式及性能

第2周  标准I/O库的性能 （3学时）

   标准I/O库的实现原理及效率，与文件IO效率的对比及优化

第3周  Unix 进程环境 （3学时）

   介绍与进程相关的概念，环境变量，内存分布，共享库，setjmp控制.

第4周  进程控制 （3学时）

   介绍进程创建，中止，以及进程的等待，竞争条件

   进程的权限、set user ID特点，system的实现

第5周  进程组及终端控制 （3学时）

   包括登录，进程组，控制终端，UNIX作业控制

第6周  信号的概念 （3学时）

   信号基本概念，不可靠信号和可靠信号,可重入函数。

第7周  信号的应用

  被中断的系统调用，信号阻塞，挂起、sigsuspend，作业控制接口等

第8周  终端 I/O （3学时）

   介绍I/O终端的设置，stty的功能，规范模式.

第9周  文件锁机制和IO复用 （3学时）

   介绍非阻塞 I/O，锁概念，IO复用.

第10周  异步IO性能 （3学时）

   异步 I/O开发模式及性能，Memory Mapped I/O.

第11周  进程间通信 （3学时）

   Pipes，Message Queues，Semaphores，Shared Memory.

第12周  concurent and parallel programming

   并行计算概念及多线程开发模

第13周  多线程控制

   线程属性、同步属性、可重入函数、线程IO

第14周  并行程序设计 （3学时）

   openMP、MPI开发模式

第15周 Linux驱动开发概念 （3学时）

   Linux驱动的功能，module概念，开发框架，字符驱动开发架构

第16周 硬件和内存管理（3学时）

  内存管理、硬件管理与中断
