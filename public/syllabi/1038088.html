课程简介（中文）

本课程采用VB语言作为载体，非常适合作为非计算机专业学生的第一种编程语言。

基本内容包括：

  • VB开发环境和基本编程步骤
  • 基本控件和语言基础
  • 基本控制结构
  • 数组
  • 过程
  • 常用控件
  • 菜单
  • 多重窗体和文件等。

课程适用于各专业学生的程序设计与创新能力培养。

课程简介（英文）

    This course uses the VB language as the carrier. VB is highly suitable as the first programming language for non-computer major studennts.

   The main content includes:

• VB development environment and basic programming steps

• Basic controls and language fundamentals

• Basic control structures

• Arrays

• Procedures

• Common controls

• Menus

• Multiple forms and files, among others.

     This course is suitable for cultivating the programming and innovative capabilities of students from various majors.

教学目标

通过本课程的教学，向学生介绍面向对象的程序设计的基本思想和方法。通过学习并结合上机实践，让学生了解计算机解决问题的一般方法，掌握界面制作、程序编写和调试，使得学生具备编写简单应用程序的能力,并为以后进一步自学其它程序设计语言和提高程序设计能力打下坚实的基础，同时提升学生的逻辑性思维能力和缜密性思维能力。
