课程简介（中文）

课程涉及计算机内外存的数据组织，重点在内存数据组织，包括数组、顺序表、链 表、栈和队列、递归、非递归、树与森林、图、堆与优先级队列、集合与搜索结构、排 序、索引与散列结构等结构的有关性质及相关算法。

课程简介（英文）

This course covers the data organization in both internal and external memory of computers, with a focus on memory data organization. It includes the properties and related algorithms of structures such as arrays, sequential lists, linked lists, stacks and queues, recursion and non-recursion, trees and forests, graphs, heaps and priority queues, set and search structures, sorting, indexing, and hash structures.

教学目标

本课程介绍信息处理的基本数据结构，包括顺序表、链表、栈、队列、树和图。本 课程探讨这些数据结构的实现，并研究将这些结构用于排序、搜索等任务的经典算法。 较高强度的作业要求和严格的在线自动评测方式，帮助学生切实提升代码实现能力。通 过本课程的学习，使学生深透理解数据结构的基本概念以及有关算法，培养良好的程序 设计技能，锻炼通过编程解决实际问题的能力，培养批判求真、严谨求实、理性思辨、 勇于探索、勇于创新的科学精神，为后续计算机专业课程的学习打下坚实基础，为从事 计算机理论和技术的研究和开发打下理论和实践基础。
