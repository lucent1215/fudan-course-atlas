课程简介（中文）

这是一门面向非专业、零基础学生的程序设计课程，以Python语言为教学载体介绍程序设计基本思想和方法。Python语言简洁易学、功能强大，尤其适合作为非计算机专业学生的首门编程语言，在数据分析处理及人工智能（AI）应用开发领域具有显著优势。学习内容包括：Python序列（列表、元组、字典），控制结构（顺序、选择、循环），字符串操作及格式化，函数定义与使用，文件操作，Pandas数据处理与分析、数据可视化（Matplotlib、Seaborn）等。

课程简介（英文）

This is a programming course designed for non-computer students with no prior programming experience. It introduces the fundamental concepts and methodologies of programming using the Python language as the instructional medium. Python is renowned for its simplicity, ease of learning, and robust functionality, making it particularly well-suited as the first programming language for students from non-computer science backgrounds. It holds significant advantages in the fields of data analysis and processing, as well as in the development of artificial intelligence applications.

The course content encompasses the following areas:

  • Python sequences (including lists, tuples, and dictionaries)
  • Control structures (such as sequential execution, conditional selection, and iterative loops)
  • String manipulation and formatting
  • Function definition and utilization
  • File operations
  • Data processing and analysis using Pandas
  • Data visualization (utilizing libraries like Matplotlib and Seaborn)

教学目标

  1. 培养学生计算机问题解决能力：
    使学生掌握运用计算机解决实际问题的通用思路与方法。学生能够熟练运用IPO（输入-处理-输出）程序结构，掌握基本的控制流语法，并能够根据具体应用需求选择合适的数据结构和算法，以完成简单的计算任务，从而奠定坚实的编程基础。

  2. 提升复杂问题处理能力：
    面对复杂计算任务时，学生能够运用自顶向下的模块化分解方法，将复杂问题转化为若干简单子问题进行计算。进一步地，学生能够借助人工智能辅助编程工具完成简单计算任务，具备阅读并理解AI生成程序的能力，能够对其进行必要的修改与优化，并能够整合各个模块以高效完成复杂任务。

  3. 掌握数据分析技能：
    学生能够熟练使用Python的第三方库进行数据分析与处理，为后续学习高阶课程奠定坚实基础，实现课程间的有效衔接。
