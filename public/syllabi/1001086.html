课程简介（中文）

本课程采用Python语言作为载体。Python非常适合作为非计算机专业学生的第一种编程语言，适合进行数据分析处理和编写AI相关应用。学习内容包括：Python序列：列表、元组、字典，控制结构：选择、循环，字符串操作及格式化，函数定义与使用，文件操作，Pandas数据处理与分析、数据可视化（Matplotlib、Seaborn），机器学习模型（Scikit-learn）。

课程简介（英文）

This course utilizes Python as the medium. Python is highly suitable as the first programming language for non-computer science students, especially for data analysis and processing, as well as writing AI-related applications. The learning content includes: Python sequences: lists, tuples, dictionaries; control structures: selection, looping; string operations and formatting; function definition and usage; file operations; Pandas data processing and analysis; data visualization (Matplotlib, Seaborn); and machine learning models (Scikit-learn).

教学目标

1.使学生掌握用计算机解决问题的一般思路和方法。学生能掌握IPO（输入-处理-输出）的程序结构，掌握基本控制流语法，能选择适合具体应用需求的数据结构和相应算法来完成简单计算任务，具有较为扎实的编程基础。
2.对于复杂计算任务，学生能够运用自顶向下的模块分解方法，转为简单问题计算。进而能够利用人工智能辅助编程完成简单计算任务，能阅读理解AI生成的程序，进行修改，能够整合模块以完成复杂任务。
3.学生能使用Python第三方库进行数据分析处理及AI应用，可以和更高阶的人工智能课程衔接。

教学方式

讲授为主。每周一节上课，一节上机实践。机房授课，通过屏幕广播软件或投影仪播放演示文稿和操作演示。eLearning平台上传课件。
