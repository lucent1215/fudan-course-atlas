课程简介（中文）

本课程主要包括计算机数据的基本组织与表达形式、汇编语言的基本语法及C语言程序如何与汇编语言互译、时序CPU的架构、机器相关与机器无关的程序优化方法、存储器架构、链接、异常控制流等。

课程简介（英文）

This course mainly includes the basic organization and expression of computer data, the basic syntax of assembly language and how C language programs translate into assembly language, the architecture of sequential CPU, machine-dependent and machine-independent program optimization methods, memory architecture, linking, exception control flow, etc.

教学目标

使学生了解支撑应用软件运行的计算机系统的概况，涵盖二进制、汇编语言、单周期CPU设计、存储系统架构、并发等核心内容。掌握计算机系统的基本概念，并运用这些概念解决实际问题。这些概念还将成为后续计算机系统类课程的基础。

教学方式

理论讲授：通过课堂讲解、案例分析和文献阅读，使学生掌握相关理论知识。

实验操作：包括多次课程实验，学生以个人或组为单位讨论和完成。

教学内容与进度安排

第一周：计算机系统漫游、人工智能软硬件基础。

第二周：信息存储、整数表示、整数运算、浮点数。

第三周：程序编码与数据格式。

第四周：算术和逻辑操作、控制。

第五周：过程、数组的分配和访。

第六周：浮点代码、常见的与内存相关的错误。

第七周：处理器体系结构。

第八周：简易处理器设计主题研讨。

第九周：处理器体系结构。

第十周：优化编译器的能力和局限性、消除循环的低效率、减少过程调用。

第十一周：消除不必要的内存引用、确认和消除性能瓶颈、存储技术。

第十二周：局部性、存储器层次结构、高速缓存。

第十三周：编写高速缓存友好的代码、高速缓存对程序性能的影响。

第十四周：简易处理器实现主题研讨。

第十五周：简易处理器实现主题研讨（自动生成探索）。

第十六周：简易处理器优化主题研讨。

第十七周：课程总结、复习。

第十八周：课程报告提交。
