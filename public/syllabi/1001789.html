课程简介（中文）

介绍并行计算的基本概念、原理和编程模型，包括：并行计算基础、进程间通信、并行算法分解模式、并行程序结构设计、CUDA编程；分布式计算的模型、逻辑时间、全局状态记录与快照算法、消息序列与组通信、终止监测、MapReduce 编程框架等。

课程简介（英文）

Parallel computing is a field of computer science that involves the use of multiple processors to perform computational tasks simultaneously. The basic concepts of parallel computing include the use of multiple processors to divide a task into smaller sub-tasks that can be executed concurrently. The principles of parallel computing involve the coordination of these processors to ensure that the sub-tasks are executed in a coordinated and efficient manner.

The programming models used in parallel computing include shared memory models, distributed memory models, and hybrid models. In shared memory models, multiple processors share a common memory space, while in distributed memory models, each processor has its own memory space. Hybrid models combine elements of both shared and distributed memory models.

教学目标

通过本课程的学习，使学生掌握并行和分布式计算的概念、基本原理和模型。深入了解实际的并行和分布式计算中所涉及的系统难点包括互斥、死锁检测、全局状态、逻辑时间等，并结合当前热点在并行和分布式算法设计、实现以及应用等方面开展实践。

教学方式

本课程以课堂讲授为主，结合课后实验。
