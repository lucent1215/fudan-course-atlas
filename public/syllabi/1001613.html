考核与成绩构成

  • 出勤Attendance 10.0% 从第3周开始打卡考勤。得分=出勤次数/考勤次数*100。
  • 作业/实验/实践Assignment 40.0% 平时作业若干次，项目大作业1次。作业若迟交则该次作业成绩打8折。得分=平时各次作业成绩平均*50%+大作业成绩*50%。
  • 期末考试Final Examination：闭卷 50.0% 试卷设计紧扣教学大纲，重点考查学生对知识的理解和应用能力，题型多样，难易适中。

课程简介（中文）

本课程采用当前流行的Python语言作为载体。Python非常适合作为非计算机专业学生的第一种编程语言。学习内容包括：Python序列：列表、元组、字典、集合，控制结构：选择、循环，字符串常用操作方法，字符串函数，正则表达式，函数定义与使用，模块定义与使用，文件操作，异常处理。

课程适用于各专业学生的程序设计与创新能力培养。

课程简介（英文）

This course uses the currently popular Python language as the carrier. Python is highly suitable as the first programming language for non-computer major students. The learning contents include: Python sequences: lists, tuples, dictionaries, sets; control structures: selection, loops; common operation methods of strings, string functions, regular expressions, function definition and usage, module definition and usage, file operations, and exception handling.
This course is suitable for cultivating the programming and innovative capabilities of students from various majors.

教学目标

课程目标是使学生了解用计算机解决问题的一般思路和方法，掌握编程的基本过程和方法，会运用Python作为（大量）数据的分析和处理的工具。学生可以更容易地迁移到其他编程语言。强化学生可迁移能力的培养，也是课程思政的要求。

教学方式

机房授课。通过屏幕广播软件播放PPT和操作演示，eLearning平台上传课件（包括讲课视频录像），上机辅导答疑。

教学内容与进度安排

按周次：

  1. Python 安装，IDLE，变量，数据类型，运算符和表达式，常用内置函数。课程思政元素：通过介绍Python语言开源、开放、兼容的特点，培养学生的兼容并包、开放进取的心态，提高学生接受新生事物，探索前沿技术的能力，提高学生的创新能力。
  2. 基本输入输出，模块导入和使用，代码规范，文件名，__name__属性，简单程序实例
  3. 列表，切片
  4. 国庆中秋放假停课
  5. 列表推导，列表排序，元组
  6. 字典，集合
  7. 条件表达式，选择语句
  8. 循环语句，break和continue，循环嵌套
  9. 字符串。课程思政元素：通过加解密例子介绍，加强学生信息安全意识。
  10. 正则表达式
  11. 文件操作
  12. 函数定义，形参和实参
  13. 校运会停课
  14. 参数类型、return语句、变量作用域，实例
  15. 异常处理
  16. 复习答疑
