课程简介（中文）

本课程采用当前流行的Python语言作为载体。Python非常适合作为非计算机专业学生的第一种编程语言。学习内容包括：Python序列：列表、元组、字典、集合，控制结构：选择、循环，字符串常用操作方法，字符串函数，正则表达式，函数定义与使用，模块定义与使用，图形界面，绘图，文件操作，异常处理。

课程简介（英文）

This course uses the currently popular Python language as the carrier. Python is very suitable as the first programming language for non computer major students. The learning content includes: Python sequences: lists, tuples, dictionaries, collections, control structures: selection, loops, common string operation methods, string functions, regular expressions, function definition and usage, module definition and usage, graphical interface, drawing, file operation, exception handling.

教学目标

课程目标是使学生了解用计算机解决问题的一般思路和方法，掌握编程的基本过程和方法，会运用Python作为（大量）数据的分析和处理的工具。学生可以更容易地迁移到其他编程语言。强化学生可迁移能力的培养，也是课程思政的要求。

教学方式

机房授课：通过屏幕广播软件播放PPT和操作演示，eLearning平台上传课件，上机辅导答疑。

教学内容与进度安排

  • 第1周:Python 安装，IDLE，变量，数据类型，运算符和表达式，常用内置函数。课程思政元素：通过介绍Python语言开源、开放、兼容的特点，培养学生的兼容并包、开放进取的心态，提高学生接受新生事物，探索前沿技术的能力，提高学生的创新能力。
  • 第2周:基本输入输出，模块导入和使用，代码规范，文件名，__name__属性，简单程序实例
  • 第3周:列表，切片
  • 第4周:列表推导，列表排序，元组
  • 第5周:字典，集合
  • 第6周:条件表达式，选择语句
  • 第7周:循环语句，break和continue，循环嵌套
  • 第8周:字符串。课程思政元素：通过加解密例子介绍，加强学生信息安全意识。
  • 第9周:正则表达式
  • 第10周:文件操作
  • 第11周:函数定义，形参和实参
  • 第12周:参数类型、return语句、变量作用域，实例
  • 第13周:异常处理
  • 第14周:习题课，大作业指导
  • 第15周:复习答疑；
  • 第16周:已返校学生模拟考试（不计成绩，熟悉考试系统）。
