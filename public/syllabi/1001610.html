课程简介（中文）

本课程采用当前流行的Python语言作为载体。Python非常适合作为非计算机专业学生的第一种编程语言。

学习内容包括：

  • Python序列：列表、元组、字典、集合；
  • 控制结构：顺序、选择、循环；
  • 字符串常用操作方法，字符串函数，正则表达式；
  • 函数定义与使用，模块定义与使用；
  • 文件操作，异常处理。

课程适用于各专业学生的程序设计与创新能力培养。

课程简介（英文）

This course uses the currently popular Python language as the carrier. Python is highly suitable as the first programming language for non-computer major students. The learning contents include: Python sequences: lists, tuples, dictionaries, sets; control structures: selection, loops; common operation methods of strings, string functions, regular expressions, function definition and usage, module definition and usage, file operations, and exception handling.

This course is suitable for cultivating the programming and innovative capabilities of students from various majors.

教学目标

课程目标是使学生了解用计算机解决问题的一般思路和方法，掌握编程的基本过程和方法，会运用Python作为（大量）数据的分析和处理的工具。学生可以更容易地迁移到其他编程语言。强化学生可迁移能力的培养，也是课程思政的要求。
