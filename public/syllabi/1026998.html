课程简介（中文）

课程系统讲授数据库的基本概念、数据模型、关系代数与SQL语言、数据库设计方法与规范化理论、索引与查询优化、事务管理、并发控制与故障恢复等内容。课程结合实际案例与实验项目，培养学生构建、操作和管理数据库系统的综合能力，是数据工程、软件开发及信息管理等方向的重要基础课程。

课程简介（英文）

This course provides a comprehensive introduction to fundamental concepts, data models, relational algebra, and SQL. It covers database design and normalization, indexing, query optimization, transaction management, concurrency control, and recovery techniques. Through practical cases and hands-on projects, students develop skills in designing, implementing, and managing database systems. This course lays a solid foundation for careers in data engineering, software development, and information management.

教学目标

使学生掌握数据库技术的基本原理、方法和应用技术，能有效地使用现有的数据库 管理系统和软件开发工具，掌握数据库管理系统的核心实现技术、数据库模式的设 计和数据库应用系统的开发原理。使学生初步了解新型数据库管理系统。通过理论教学与项目实践，培养学生分析问题、设计方案和解决实际数据管理问题的能力，提升其工程素养与创新意识，为在大数据、人工智能等领域从事高水平研发与应用打下坚实基础。

教学方式

  • 课堂讲授
  • 上机实践。主要包括数据库设计、SQL使用等。

教学内容与进度安排

第一周：数据库系统的基本概念，数据描述，数据模型，DB的体系结构，DBMS的功能与组成，DBMS的组成。国内数据库技术和产业的发展背景和过程。

第二周：关系模型基本概念，关系代数基本操作。

第三周：SQL的数据定义，SELECT语句。

第四周：数据更新语句，视图的操作，嵌入式SQL。

第五周：数据库设计的全过程，ER 模型，转换规则。

第六周：模式的冗余问题，函数依赖。

第七周：关系模式的分解特性，关系模式的范式。

第八周：关系演算，关系逻辑，基于关系代数的优化。

第九周：期中考试。

第十周：数据库存储结构。

第十一周：索引结构。

第十二周：数据库查询处理技术。

第十三周：数据库查询优化技术。

第十四周：事务处理，并发控制。

第十五周：数据库的恢复与安全性。

第十六周：新型数据库简介（包括NoSQL和NewSQL数据库）。

第十七周：习题课、复习答疑。
