课程简介（中文）

本课程旨在培养面向对象（OOP）的编程思维与实战能力。内容涵盖C++类与对象、继承与派生、多态与虚函数等核心机制，深入讲解STL标准库（容器、迭代器、算法）及现代C++新特性。通过引入设计模式初步，强化代码复用与架构设计意识。课程强调“做中学”，通过上机实践，帮助学生掌握构建高质量、可扩展软件系统的关键技术。

课程简介（英文）

This course is designed to cultivate an Object-Oriented Programming (OOP) mindset and foster practical coding skills. Key topics include core mechanisms such as C++ classes and objects, inheritance, polymorphism, and virtual functions. The course also provides in-depth coverage of the Standard Template Library (STL)—including containers, iterators, and algorithms—and modern C++ features. By introducing fundamental design patterns, the course emphasizes the importance of code reusability and architectural design awareness. Adopting a 'learning by doing' approach, the course utilizes extensive hands-on practice to enable students to master the key techniques required for building high-quality, extensible software systems.

教学目标

本课程教学目标涵盖三个维度：

知识目标： 深入理解C++面向对象核心机制（封装、继承、多态）及STL标准库原理，掌握现代C++新特性与设计模式初步。

能力目标： 能运用OOP思想进行模块化程序设计，熟练使用泛型算法与动态绑定技术解决复杂问题，具备构建高质量、可扩展软件系统的实战能力。

素养目标： 建立抽象与复用的系统工程思维，摒弃线性过程逻辑，养成规范严谨的编码习惯，确立好的架构设计意识。

教学方式

教学过程中，采用混合式教学方法，把教学分为课前；课中和课后三个部分。

课前：对于知识性的内容，要求预习，并通过问题集来巩固；

课中：回顾预习的内容，并讲解难点；

课后：布置适量的练习，巩固美堂课的内容。

教学内容与进度安排

以下内容可能会进行修订！
1. C++标准库的应用(3次)
1.1 简单C++程序
C++程序；使用字符串。
1.2 使用批量数据
组织程序和数据；异常处理；函数重载。
1.3 使用序列式容器
Vector和list的使用
1.4 使用库算法
随机数使用；库函数使用。
1.5 使用关联式容器
使用map；map排序。
1.6 使用泛型算法
函数泛化；编写泛型函数；迭代器介绍及使用。
 
2. 类和对象(3次)
2.1 定义新类型
从struct到class；成员函数；非成员函数；成员变量；保护标签；访问器函数；内联函数；对象创建过程；构造函数；对象初始化规则；默认构造函数；构造函数的初始化列表；UML类图，序列图等。
2.2 内存模型与内存管理
对象和指针；变量及变量属性；函数的连接性；字符串；动态数组；main函数；C++内存分配方法。
2.3 定义抽象数据类型
类定义中的正规函数；Nice类；识别调用的函数；深拷贝与浅拷贝；构造vec类；实现vec类；vec内存分配；对象行为的控制：copy控制；赋值控制；析构函数；类的默认操作；三位一体原则；构造动态可索引的vec类。
2.4 具有数值特性的类
类对象的自动转换；转换的安全性；输入输出操作；友元函数；两元运算符。
 
3. 类的继承、多态与组合(2次)
3.1 类的继承
继承的概念；继承的实例；继承的可见性；继承的类型；继承对象的创建与删除；多继承；多继承对象的创建与删除。
3.2 类的多态
绑定；类型转换；向上类型转换；向下类型转换；多态；多态的应用；动态绑定的实现；虚析构函数；函数隐藏； 
3.3 类的组合
组合的概念；组合示例；组合对象的创建与删除。
 
4. 类的封装、虚函数和模式(可选内容)
4.1 类的封装
多态的类型；封装的原则。
4.2 虚函数
虚函数；纯虚函数；抽象类。
4.3 软件设计模式
设计模式的概念；Singleton模式。
 
5. 使用SFML库*(1次，可选内容)
5.1 SFML库介绍
5.2 使用SFML开发Game
