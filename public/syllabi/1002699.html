课程简介（中文）

本课程对基于C程序设计语言的程序设计基于原理和方法进行讲授，主要内容包括：C语言的基本语法和基本结构；程序设计的基本原理和基本算法；C语言编程实践。课程主要面向无编程基础的低年级同学开设。通过课程学习使同学具备使用C语言进行常规程序设计的能力，并为进一步学习计算机相关课程打下基础。

课程简介（英文）

This course teaches the principles and methods of programming based on C programming language, and the main contents include: the basic syntax and basic structure of C programming language; the basic principles and basic algorithms of programming; C programming practice. The course is mainly for junior students who have no elementary programming knowledge. Through the course study, students will have the ability to use C programming language for routine programming, and lay a foundation for further study of computer-related courses.

教学目标

本课程面向技术大类一年级学生，以C语言为载体，以计算思维的培养为导向，通过程序设计的教学和实践，培养学生掌握使用C语言程序设计的方法解决问题的能力。同时训练学生养成良好的合作开放的编程习惯和代码风格。

教学方式

教学内容与进度安排

第1周：课程简介，计算机基本原理，简单例子和编程环介绍。介绍软件危机，程序员的合作精神和意义。以及复旦计算机人早年对国产计算机的初创贡献。

第2周：C语言基本数据类型和输入输出基础

第3周：C语言基本运算和表达式

第5周：循环结构

第6周：一维数组，通过排序算法，拓展计算技术的创新和发展，启发同学对创新的兴趣。

第7周：多维数组和字符串

第8周：函数和库函数基础

第9周： 期中考试

第10周：指针基础

第11周：数组和指针行参

第12周：结构和链表

第13周：存储类别和作用域

第14周：高级指针和联合位域枚举

第15周：文件处理技术

第16周：例题选讲和期末复习

第17周：期末考试

第18周：批阅试卷、登分
