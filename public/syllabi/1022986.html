课程简介（中文）

《数据库引论》专业必修课，主要讲授数据库概述，关系数据库模型和关系语言，SQL语言和中高级SQL使用，形式化查询语言，数据库设计与E-R模型，关系数据库设计，关系数据库理论，数据存储结构，数据存取技术，索引与哈希，查询处理，查询优化，事务及其处理，并发控制，故障恢复等内容。基本要求包括掌握数据库系统的基本概念和架构；掌握关系模型的关系运算理论，SQL语言的使用技术；.掌握关系数据库的规范化理论及数据库设计；掌握关系模型中索引和查询评估原理；掌握数据库系统的实现和管理技术。

课程简介（英文）

“Introduction to Databases” is a major required course, which mainly covers an overview of databases, the relational database model and relational languages, SQL language and intermediate to advanced SQL usage, formal query languages, database design and E-R models, relational database design, relational database theory, data storage structures, data access techniques, indexing and hashing, query processing, query optimization, transactions and their management, concurrency control, and fault recovery. The basic requirements include mastering the basic concepts and architecture of database systems; understanding relational algebra theory and SQL usage skills; mastering relational database normalization theory and database design; understanding the principles of indexing and query evaluation in relational models; and mastering database system implementation and management techniques.

教学目标

使学生掌握数据库的基本概念、模型和原理、方法和应用技术，掌握数据库管理系统的设计和实现方法，能熟练操作、配置、使用和维护数据库，掌握数据库管理系统中涉及的相关数据结构，以及索引、查询的处理与优化等相关的底层算法；了解国内外数据库及其相关领域学界和业界的最新技术趋势，以及我国在数据库核心技术和大规模（分布式）、高效、可靠数据库系统亟待进一步突破的现状，树立学生投身国家高精尖缺领域研究的志向。

教学方式

课堂授课（3 课时/周） +上机实验（2 课时/周）

教学内容与进度安排

第1周：第一节，数据库简介；第二节，关系数据库模型（数据库模式、键、模式图）；第三节，关系数据库模型（关系查询语言、关系操作）

第2周：第一节，SQL简介（SQL数据定义、SQL查询基本结构、集合操作、空值、聚集函数、嵌套子查询）；第二节，中级SQL（连接表达、视图、事务、完整性约束）；第三节，高级SQL（函数与过程、触发器）

第3周：第一~二节，形式化查询语言（关系代数）；第三节形式化查询语言（元组关系算子）

第4周：第一节，数据库设计与E-R模型（实体-关系模型、约束）；第二节，数据库设计与E-R模型（E-R图、模式约简）；第三节，数据库设计与E-R模型（E-R设计）

第5周：第一~二节，关系数据库设计（原子域与1NF、函数依赖）；第三节，关系数据库设计（BCNF）

第6周：第一节，关系数据库设计（3NF）；第二节，关系数据库设计（多值依赖、关系分解）；第三节，关系数据库设计（4NF、数据库设计过程与方法）

第7周：第一节，数据存储与文件系统（RAID、文件系统、记录的组织、数据库缓存）；第二~三节，索引与哈希（有序索引、B+树索引文件、多键值访问）

第8周：第一~二节，索引与哈希（静态哈希、动态哈希）；第三节，索引与哈希（位图索引）

第9周：第一节，查询处理（查询代价）；第二节，查询处理（选择操作）；第三节，查询处理（排序操作）

第10周：第一~二节，查询处理（连接等操作）；第三节，查询处理（查询表达式赋值）

第11周：第一节，查询优化（关系表达式转换）；第二节，查询优化（表达式结果的估计统计）；第三节，查询优化（查询计划的选择）

第12周：第一节，事务（事务的概念）；第二节，事务（ACID性质）；第一节，事务（序列化）

第13周：第一节，并发控制（基于锁的协议）；第二节，并发控制（死锁处理）；第三节，并发控制（多粒度锁）

第14周：第一节，并发控制（基于时间戳的协议）；第二节，并发控制（多版本模式）；第三节，并发控制（快照隔离）

第15周：第一节，系统恢复（失效分类）；第二~三节，系统恢复（恢复的原子性）

第16周：第一~二节，系统恢复（恢复算法、缓存管理）；第三节，系统恢复（缓存管理）
