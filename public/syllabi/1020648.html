课程简介（中文）

本课程包括R语言的介绍，数据的输入输出，R的作图，基于R语言的统计分析：包括如描述性统计分析，属性数据和列联表，线性回归，方差分析，广义线性模型，主成分和因子分析，聚类分析等。

课程简介（英文）

This course covers an introduction to R language, data input and output, plotting in R, and statistical analysis based on R language, including descriptive statistical analysis, categorical data and contingency tables, linear regression, analysis of variance (ANOVA), generalized linear models (GLM), principal component and factor analysis, cluster analysis, etc.

教学目标

现代的统计分析离不开软件， R软件是现阶段科研和业界最常用的统计软件之一。本课程旨在培养学生

 (1) 掌握使用R进行编程，数据可视化以及进行统计分析的能力；

（2）培养和锻炼学生通过软件实践动手，进行数据分析和解决实际问题的能力。
