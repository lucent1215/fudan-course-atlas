课程简介（中文）

本课程全面讲述云计算与虚拟化技术的核心概念、关键技术、主要应用和工业界平台。在介绍云计算主要概念和原理的基础上，重点对国际主流云计算平台、主流开源云架构、虚拟化技术、容器技术、云原生技术、云计算数据中心、云际计算技术和国内主流云计算技术和平台进行讲述，同时还对云计算应用实例进行了介绍。并指导学生在OpenStack、KVM、Docker、Kubernetes、阿里云等云计算与虚拟化平台的实际操作、实践开发和案例设计。

课程简介（英文）

This course provides a comprehensive introduction to the core concepts, key technologies, major applications, and industrial platforms related to cloud computing and virtualization. Building on the fundamental principles of cloud computing, the course focuses on international mainstream cloud platforms, popular open-source cloud architectures, virtualization technologies, container technologies, cloud-native technologies, cloud data centers, inter-cloud computing, as well as leading domestic cloud computing technologies and platforms. In addition, practical applications of cloud computing are presented. The course also guides students through hands-on operations, practical development, and case design using platforms such as OpenStack, KVM, Docker, Kubernetes, and Alibaba Cloud.

教学目标

云计算与虚拟化平台是软件技术中重要的平台软件之一，也是新型平台软件特色的软件学院培养学生的必不可少的课程之一。
本课程综合讲述了云计算与虚拟化技术的基本原理、主要标准、关键技术、主要应用和相关平台操作开发技术。通过学习这些内容，使学生在理解云计算与虚拟化领域主要技术原理和平台的基础上为今后在相关领域开展开发或研究工作打下良好的基础。

教学方式
