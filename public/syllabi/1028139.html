课程简介（中文）

本课程旨在使学生透彻理解面向对象的核心概念，牢固树立面向对象的程序设计思想，并能够熟练运用 Java 语言开展面向对象的程序设计实践。

课程简介（英文）

The course aims to enable students to thoroughly understand the core concepts of object-oriented programming, firmly establish the ideology of object-oriented program design, and proficiently use the Java language to carry out object-oriented programming practices.

教学目标

通过本课程的学习，使得学生在已有的C语言编程基础上掌握抽象层次更高的Java语言的程序设计方法，理解并掌握面向对象程序设计的思想和方法。

该课程的教学不仅需要培养学生Java语言的软件开发知识，而且需要培养学生具有使用面向对象的问题分析方法，掌握高质量面向对象程序的设计能力。

教学方式

课堂理论授课，同时通过实验来提升学生的实践能力
