课程简介（中文）

本课程是面向大一新生的4学分大类基础课程，是计算机相关专业的重要基础课程。共18周(含考试周2周)，教学周16周，每周理论课3课时，上机实践2课时。课程内容以C语言为载体教授程序设计的基本原理，以计算思维的培养为导向，通过程序设计实践，帮助学生掌握使用程序设计的方法解决问题的能力，为后续的专业课程学习打下坚实的基础。

课程简介（英文）

This course is a 4-credit general basic course for freshmen and an important basic course for computer-related majors. It lasts for 18 weeks (including 2 weeks of examination), with 16 weeks of teaching. Each week, there are 3 theoretical class hours and 2 computer practice class hours. The course content teaches the basic principles of programming with C language as the carrier, and is oriented towards the cultivation of computational thinking. Through programming practice, it helps students master the ability to solve problems using programming methods, laying a solid foundation for subsequent professional course studies.

教学目标

通过这门课程的学习，学生可以阐述程序设计的基本概念和原理，能解释C语言的基本语法和基本结构，可以使用C编程平台进行程序设计并调试，并运用C语言设计和实现一个文本界面的生命游戏这样规模的程序。同时，通过该课程的学习，学生可以初步了解软件工程专业，培养兴趣和自学能力，能阐述相关专业伦理，树立信息化强国的抱负。贯穿整个教学的重要理念是掌握程序设计这一计算机相关专业的核心能力并培养计算思维，并培养团队协作、交流表达、解决较为复杂的问题的工程素养等能力。

教学方式

课堂教学（每周3学时）与上机实践（每周2学时），课堂采用超星平台提供学生自主学习的学习资源、课内外讨论，并采用超星学习通等工具进行课堂互动，以及微信群进行课外讨论等。
