课程简介（中文）

软件代码安全分析是发现和验证软件可能存在安全漏洞的重要手段。本课程介绍安全漏洞的利用和防御方法，并以代码行为理解为切入点深入学习安全分析的基本原理以及相关方法。结合当前实际场景中安全问题，引领学生进行安全分析实践，培养学生动手能力。为学生在系统安全领域的学习打下良好的基础。

课程简介（英文）

Software code security analysis is a crucial approach for identifying and verifying potential security vulnerabilities in software. This course introduces techniques for exploiting and defending against security vulnerabilities, and delves into the fundamental principles and methodologies of security analysis through the lens of code behavior understanding. By connecting with real-world security challenges, the course guides students through hands-on security analysis practices, enhancing their practical skills. It lays a solid foundation for students pursuing further studies in the field of system security.

教学目标

通过介绍软件代码安全分析的基本概念和基本方法，帮助学生掌握该领域的基本技术，为对系统安全和软件安全感兴趣的学生从事相关领域研究打开一扇大门。课程还将通过经典文献阅读、经典方法与应用验证，锻炼学生独立思考和动手解决问题能力。此外，课程教学中还将引入学术道德教育，以培养学生形成良好价值观念、学术道德与学术规范。

教学方式

课堂讲解为主，并且通过项目以及课堂研讨让学生巩固和运用课堂上所学的知识。在授课过程中，在可能的情况下，用案例的方式对涉及的问题和技术进行讲演，使学生都能够理解所介绍的主要思想和技巧。同时，在教学中给出了足够多的细节，使学生能够将讲解过的技术和方法方便地变成现实软件安全实践。

教学内容与进度安排

本课程教学计划包括以下几个方面：

  • 第1-2周 安全概述
    介绍常见计算机语言和安全漏洞类型
  • 第3-5周 常见代码分析技术介绍
    学习常见代码分析技术，并掌握其原理，包括静态（控制流、数据流、污点、指针、抽象解释）、动态（符号执行、fuzzing）、AI驱动等
    并以课题组自主研发的莲花系统为例，讲解技术实现和使用
  • 第6-7周 C语言代码漏洞分析和防范
    从C语言的视角入手，研究导致C语言漏洞的原因及其改进思路
    介绍课题组自主开发的内存安全语言yian，并学习类型安全分析、以及主流防范思路
  • 第8周   项目选题
    从授课老师提供的题目中选取感兴趣的题目，开始调研
  • 第9周   Web代码漏洞分析和防范
    以web漏洞为切入点，讨论传统web漏洞场景，以及新型场景，包括小程序、node.js等
  • 第10周  移动代码安全
    介绍传统移动安全情况，如intent漏洞、数据安全等
  • 第11周  项目期中
    更新项目进度
  • 第12周  AI软件安全
    介绍常见的AI安全场景，以及AI软件（如pytorch）的安全问题
  • 第13周  动态语言代码分析
    学习动态语言的分析难点挑战和分析技术
  • 第14周  期末汇报
    完善项目内容，并在课堂汇报
  • 第15-16周 编写论文
