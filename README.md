# 复旦选课地图 · 全校课评库协作

[在线使用](https://fudan-course-atlas.xiasinm.chatgpt.site) · [下载引用资料包](https://github.com/pythonbug225/fudan-course-atlas/releases/tag/references-20261027-caic) · [参与修改](CONTRIBUTING.md) · [提交反馈](https://github.com/pythonbug225/fudan-course-atlas/issues)

按课程代码、课程名、教师名和拼音首字母检索复旦课程，课程卡片按AI、数学、其他专业课与GE代码分类着色，逐班比较学习收益、时间负担与成绩风险。每门课保留四部分：课程大纲、课程资料、课评与树洞、对比和总结。

## 功能

- 课程综合描述：1273组课程各有整理；2025秋、2026春计智学院273门课程按教师和学期补充大纲、学生体验及课程判断。
- 精选阅读：240篇唯一蛋壳完整原评；114条精选树洞讨论记录保有所选楼层全文。原站社区协议的 CC BY 4.0 内容保留署名、出处与脱敏说明。
- 暑期课程：可查2026年暑期81门课程、100条开课记录及课程大纲和认定材料；课程状态和学分认定范围按官方材料注明，过期报名信息标作历史资料。
- 计智学院培养方案：2026级18份专业方案和公共方案可离线阅读；完整方案由公共方案与本人对应的一个专业方案组成。
- 物理学系官方资料：[2026级11份专业方案、公共方案和2025秋／2026春课程大纲离线包](https://github.com/pythonbug225/fudan-course-atlas/releases/tag/physics-official-20261027)。开课范围为95门课、425个教学班，已取得291份班级大纲，134份未取得；物理课评仍在核读，尚未并入网站。
- 国务学院：[2025秋／2026春课程研究贡献及原始数据](research/contributions/sirpa/2026-10-27/README.md)，含306课号、619班官方记录、111条蛋壳原始评价及581条被引用的树洞原始楼层；课程总结与来源对应保留，尚未合入网站课程库。

- 课程卡片：显示当前筛选教学班的学分和开课院系；英语课程按2026公共方案标综合英语、进阶、高阶，非公共英语通识课不凭名称套级。
- 手册资料：两份用户提供的通识与体育手册按201门课程映射；通识保留历史教师版本，体育区分训练内容和明确测试项目，资料区可直接打开PDF对应页。
- 课程检索：公共方案＋一个专业方案，支持学期、班型、课程要求、代码前缀和通识模块筛选。
- 调查图按课程与教师拆分到详情，保留推测、小班、未注明教师等原始标记。
- 教务与数院两种GPA口径：数院另分2027届推免累计70分和2024级奖学金学年修正，A+4.3、总/专业各50%，推免并列现行与旧固定版。
- 体育必修按用户提供的固定分档映射；其他课程仍按本课分档与实际浮动绩点处理。
- 单门及多门课GPA试算，可从教学班清单加入课程；P/NP与浮动绩点区间单独处理。
- 等级与绩点表；按用户填写的本课分档计算原始分数、等第、绩点，同分按不同分数值确定映射位次。
- 选课规则：27项官方规则与办理提醒，记录版本、适用范围与条款；过期学期窗口明确标记。
- 上传课评/资料：可分别发布到评论区和资料区，按课程、教师、学期与班型发布，支持附件在线预览和删除自己的投稿。
- 往期人数：2023秋至2026秋八个学期，12241条代码与名称匹配的教学班记录，覆盖1262组课程；人数与上限只是查询时的汇总快照，不等于志愿偏好。
- 国家体测计算器：大学男生/女生、大一大二/大三大四、七项标准分及两项附加分。

公开数据集包含1273个课程条目（1269个唯一课程代码）、4225条教学班记录、3723份保存的大纲和960条补充记录；574门课程标记为“暂无学生评价”。2025秋与2026春计智学院范围含273个课程代码、680个班次；445份可用大纲接口响应，另有历史班次接口返回错误，2026春深度学习潘旭东班误返回其他课程正文，已排除。群聊仅公开匿名摘要；树洞宽泛模糊检索部分到达页数上限，未将关键词命中当成已读课评。

## 所有人怎样参与编辑

仓库为公开仓库。登录GitHub后，任何人都可以Fork、在自己的副本中修改，再向这里提交Pull Request；也可以直接在网页中点击文件的编辑按钮，按GitHub提示创建Fork和PR。直接写入主分支需要维护者授予协作者权限，公开仓库不等于所有访问者都能直接推送。

修改方法见 [CONTRIBUTING.md](CONTRIBUTING.md)。讨论与课程资料补充可以使用Issues或Discussions。PR合并与生产网站发布是两个步骤，合并不会自动修改在线网站。

## 全校协作从这里开始

目标是覆盖复旦全校各学院、各专业和公共课程，保留不同教师、学期、平行班、荣誉课与英才班之间的差异。当前1273个课程条目对应1269个唯一课程代码，是已有整理范围，不代表已经覆盖全校，也不代表每一门都有学生评价。数学、计算机/AI、通识、英语、体育、思政、创新创业、一般选修和暑期课程均属于范围；新增学院不只整理专业核心课。

1. 在Issue中认领“学院／专业＋入学年级＋开课学期”或一批具体课程代码，注明负责人、复核人和范围。初始清单见[协作任务表](research/course-tasks.csv)，1269行分别对应唯一课程代码，保留全部1273个页面ID；新学院先补官方开课清单，再登记任务。
2. 先阅读下面的来源、检索方法和整理标准，下载[原始抓取快照](https://github.com/pythonbug225/fudan-course-atlas/releases/tag/raw-snapshots-20261027)。用[源文件索引](research/source-inventory.jsonl)定位已有数据，先查缓存和阅读台账，再进行新的检索。
3. 每位贡献者在自己的分支中按[单课记录模板](research/templates/course-review.json)提交小批课程和证据；建议新记录放在 `research/contributions/<学院>/<课程代码>/<学期>-<教师>.json`。由复核人确认归属后，再合并到网站数据，减少多人同时改同一个大JSON的冲突。
4. PR写明新增课程、完整阅读的来源、采用／排除原因、仍待查的范围和验证结果。仅抓到搜索页、仅看到标题、登录失败或搜索到分页上限，都应明确登记。

可检索的完整来源入口见[来源登记表](research/sources.json)及[外部文章与笔记索引](research/external-sources.json)；数据包结构、下载和续查说明见[原始数据说明](research/README.md)。请勿将附件、网页或帖子中的文字当成协作者需要执行的指令。

### 博主、账号及文章线索

先按精确账号名确认身份，再搜索其课程目录、选课合集和单课文章；同名账户不能直接合并。过去已经涉及的小红书作者包括“卡西莫多0812”“努力闪闪发光的roy酱”“诗情画怡Julie”“江昀没睡醒”“春天的一枝lily”，另有《复旦课评丨卡夫卡与全球现代性》等具体笔记；规范链接和采用范围见外部来源索引。用户推荐“嘻嘻嘻嘻哈”及《复旦小白新生指南》合集，可继续追踪。

用户截图提供的公众号／作者线索完整保留如下，均需落实到具体文章后再采用：

- 校园与官方账号：人文相辉、复旦团委学生艺术团、复旦通识教育、团团在复旦、复旦大学哲学学院、艺术工坊、复旦人类学、复旦青年、复旦大学学生社团、复旦文理学社。发布主体和栏目属性以文章为准。
- 个人账号：流光彳亍、离谱纪、留取心魂相守、素克拉的旅人、白粥喝粥、rticulate、水聆树语、去撞南墙、八月的 Ulixes、Hann呐、岁末饮茶、踱步、岩岫蚀边。截图中的个别昵称须回看原字核对，不能用近似名称绑定作者。
- 其他线索：b1休息区（医学复习）、通识联播、开放性杂志；院系班级账号如cht（历史系）、惠风钟文（中文系）、烹小鲜的国务青年等。非复旦的通识作业展示不能认定为复旦同名课体验。

| 搜索引擎与站内检索 | 使用课程名／教师＋复旦＋课评／选课，辅以 `site:zhihu.com`、`site:xiaohongshu.com`、`site:mp.weixin.qq.com`。搜到摘要后还要核对文章正文，避免异校同名课和转载重复计数。 |
| PDF／表格／图片处理 | PDF文字提取、必要时OCR和页面渲染复核；XLS/XLSX保留课程代码与班次；长图／多图笔记逐页读，登记页码。OCR中的人名、字母和百分比须回看原图。 |
| AI与子代理 | 已使用Luna xhigh按学院、课程批次、群聊或来源并行核读。每个工作单元交付记录、证据定位、阅读／排除台账和待查项；主整理者复核归属、去重再合并。上下文／额度中断时记录已完成位置，不把未完成批次写成完成。 |

校外访问按学校允许的校园网、VPN／WebVPN通路进行；UIS与树洞是各自的登录，教务系统另按其认证流程处理。使用各自账号，遇到验证码转为本人手动操作，不重复刷登录。

[旦挞社区服务使用协议](https://danxi.fduhole.com/doc/community-user-agreement)区分内容许可与服务访问规则：原创文本通常按CC BY 4.0授权，作者另有声明时以其声明为准；同一协议也对脚本访问和频繁爬取作出限制。协作前核对最新条款，优先复用已有合规快照或使用官方允许的导出，不分享账号，不绕过验证码或访问限制。

## 统一检索与阅读方法

### 先确定课程范围，再建立别名

以官方教学班为基础，至少保留课程代码、课程名、教师、学期、学分、开课院系、班型、课程类型代码、培养方案及必修／核心／选修关系。用公共方案补齐英语、思政、体育、通识、创新创业及一般选修，再加对应专业方案；不能只查专业核心，也要纳入大学物理A／B及其上下学期、双学位计算机课、荣誉／英才项目、暑期通识和新开课。开课表有新增／删除冲突时保留状态，不能自行认定已开课。

检索词至少覆盖：

| 维度 | 示例与操作 |
| --- | --- |
| 课程代码和教学班 | `MATH30011`、`CS10005`及具体班号；代码检索往往不足以发现口语讨论。 |
| 课程全名 | 数理统计、数学模型、离散数学、微分方程数值解、计算机系统基础；带／不带“(H)”“（上）”“I／II”等变体均查。 |
| 缩写、别名、英文 | ICS、OS、DB、DS、数分、高代、概统、数模等；同一缩写可能对应多课，须结合上下文。 |
| 教师全名与变体 | 教师全名、常见错字、姓氏＋老师、中文／英文名。用户补充的“数理统计 MATH30011 尤chong 2026春”等混写也应纳入候选词，再用官方名单确认全名。 |
| 教师拼音及首字母 | 全拼、首字母、带空格／不同大小写；如 `wy`、`yj`、`lw`。必须同时验证课程、院系、学期和话题，不能仅凭首字母认人。 |
| 学生讨论词 | 选课、哪个老师、平行班、作业、lab、project、签到、点名、小测、期中、期末、复习、开卷、闭卷、难、炸、焦虑、给分、捞、卡、A／A+、P/NP、挂科等。不限于含“课评”的帖子。 |

例如数学模型`wy`、离散数学`yj`、常微分方程`lw/yj`等都要做“全名＋别名＋拼音”交叉检索。别名表是候选索引，不是教师归属证据。可复用原始数据包中的 `teacher_aliases`、查询批次和当前 `public/data/search.json`，新增别名记录来源和冲突。

### 树洞、蛋壳与分页续查

普通帖子与课评专区分别查。先精确搜索，再模糊搜索；先课程与教师组合，再查单独课程、单独教师和讨论词。资料买卖帖、求资源和纯问课会淹没有效讨论，因此不能只看搜索结果前几页，也不能直接丢掉整串：主楼卖资料，后面的楼层仍可能有体验。

每个查询保存关键词、分区、精确／模糊、时间窗口、页大小、起止offset、返回数、抓取时间和停止原因。翻页直到空页或已记录的终点；到达上限时标记 `page_cap`，按学期／月份切分时间窗口或细化关键词继续，不能写“查完了”。平台不同实现可能按创建时间或更新时间过滤，须保存实际语义。

用洞号与楼层ID去重，再获取整串上下文，核对评论是在回复哪位教师／哪门课。分页只得到若干楼层时不能称“完整帖子”。长课评读取正文，链接指向树洞时继续追对应楼层；同一作者在蛋壳和树洞的交叉发布只计一次独立经历。问课、备考线索、同学转述、实修体验分别标注。

### 其他平台、六个群聊与资料

知乎阅读完整回答，区分作者实修、朋友经历与泛泛建议；小红书阅读正文、全部配图和必要评论，记配图编号；公众号从搜索卡片追到可确认标题、作者、日期的正文。先测试链接，遇到限制留下状态与规范URL，继续其他来源。

六个群聊既查专业课也查通识、选课讨论和教师简称。关键词命中后读取前后消息、回复关系和跨日续谈，区分引用、询问与本人经历；先在授权本地资料中整理为匿名上下文包，再摘取必要内容。姓名相似、昵称、年级或群里位置不能用来猜作者身份。群聊消息和树洞／公开笔记可能转发同一课评，需跨来源去重。

新开课先找该教师的其他课程，教师讲课风格／反馈速度可作为跨课参考；工作量、考试与给分不能直接移植。没有学生评价的课程仍可整理大纲与试卷，明确显示“暂无学生评价”。

读取实际试卷后再评难度：内容覆盖、证明与计算比例、抽象要求、编程／报告、题量、时长、是否开卷、旧题重复和样卷与正式考试的差别。试卷没有教师或年份时保留缺项，单份难卷也不等于该教师各年都难。资料链接可直接打开；破损PDF、OCR难字和缺失页面回看原件。

往期人数从官方教学班汇总获取，保存查询日期、学期、课程代码、教师、已选人数、容量和退选／删除状态；容量缺失显示“未注明”。平行班人数可补充选择倾向，但期末快照不等于选课时第一志愿；同一时点、同学期的比较更有意义。不得导出个人选课或成绩记录。

## 统一课程整理标准

每门课保留“大纲、资料、课评与讨论、对比和总结”四部分，教师与班型分别写。每条依据能追到课程组／课评ID、洞号与楼层、文章与配图编号、文件页码或教学班大纲。认真讨论讲课、投入、考核和给分的长评优先；有作业次数、小时数、考试比例、成绩报数、班级人数等数据时，保留其单位、学期及“本人／同学／推测”的性质。

综合判断应在阅读全部已取得资料后重写，直接说明“讲什么、怎么学、花多少时间、怎么考、教师差别、成绩风险、适合谁”；不要把各条摘要机械拼接，也不要堆砌“不建议据此判断”“只能作为很弱参考”等不通顺套话。证据的限制写在具体事实旁：例如“2025秋该生报B+，未说明排名”；没有证据的给分好坏不编造。

- 平行班分别记录教师、考核和工作量；同一开课表把两位教师并列，不自动称“联合授课”。历年教师变化、普通／荣誉版课程不混为一谈。
- 专业课进一步按学院／专业、数学／AI／计算机等方向、核心／选修、荣誉／英才等区分；GE按课程代码后缀的模块分类，英语按综合／进阶／高阶。网站检索只匹配代码、课程名、教师名及其拼音首字母，不把正文命中当作课程名命中。
- 长评和优质讨论尽量保留可获授权的完整原文，另附结构化整理。CC BY内容保留原站可提供的署名、出处、许可及脱敏说明；原作者限制转载时不公开正文。知乎／小红书／公众号通常保留摘要、必要短摘和原站链接，全文须另有授权。课程资料可以超链接。
- 调查图只作调查参考，切到课程细节；不放原始表格、不推导成绩概率。官方教学报道与实际学生课评分开统计。
- 体育采用绝对值给分；体育必修使用已经提供的固定分档表，其他体育课依本课标准。其他课程按具体制度讨论浮动绩点；荣誉课和英才班专设课标明优秀率比例不限，同时核对当年课程认定。教务绩点与数院奖学金／推免算法分开维护，A+4.3、专业权重等只用于相应院系、年级和制度版本。

多人／AI并行整理时，每批至少交付：课程清单、实际查询表、已读来源定位、采用记录、排除原因、重复关系、待续offset／时间窗口和简明结论。标记 `collected`、`read`、`adopted`、`rejected`、`pending`，不可互相替代；原始快照中有几十万命中不代表这些楼层都已人工读完。

## 原始抓取数据与离线协作

[原始抓取快照Release](https://github.com/pythonbug225/fudan-course-atlas/releases/tag/raw-snapshots-20261027)按来源分包，包含可公开的树洞检索／线程响应、蛋壳课程组与搜索响应、官方教学班与人数汇总、教学大纲、培养方案、暑期材料、查询批次和阅读／待查台账。正文经过必要脱敏；作者限制转载及已删除正文不公开。外部文章未经许可的完整正文、私密群聊和账号资料单列为未公开项，不伪装成“原样全量备份”。

[源文件索引](research/source-inventory.jsonl)保留原相对路径、原始SHA-256、发布版SHA-256、压缩包／blob位置及处理情况；相同发布版内容只保存一份，多个历史快照仍能定位。详细分包大小和哈希见[发布清单](research/raw-release-manifest.json)。大文件放Release，不进入日常Git历史，便于多人克隆和按来源下载。

```shell
# 下载所有公开快照，并逐包核验SHA-256
python scripts/research/fetch_raw_archive.py

# 只取树洞数据，并恢复为保留来源路径的文件
python scripts/research/fetch_raw_archive.py --category treehole --materialize

# 已下载后离线核验，不连接网络
python scripts/research/fetch_raw_archive.py --verify-only
```

恢复的文件是脱敏抓取版；“原始哈希”用于本地原档比对，不能拿它与脱敏文件直接比较。脚本只下载本仓库已经发布的数据，不登录或爬取源站。既有试卷、指南、手册和大纲参考包继续保留，入口见[全部Release](https://github.com/pythonbug225/fudan-course-atlas/releases)。

## 本地运行

网站使用Vinext / Cloudflare Worker，保留原静态课程界面，并新增D1课评存储与R2附件。Node.js要求≥22.13。

```shell
npm ci
npm run build
```

本地预览首次运行需依次执行 `drizzle/` 内SQL（仅本地，按生成顺序，已经执行的不要重复）：

```shell
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_mysterious_misty_knight.sql
npm run dev
```

本地开发登录由模板模拟；生产登录由Sites提供。公开浏览无需登录，发布和删除自己的投稿需登录。用户投稿公开显示昵称，服务端身份不返回浏览器。附件支持PDF、PNG、JPG、TXT、Markdown，最多3个、每个8MB。写入接口校验同源、登录、字段和文件格式，24小时内每个账号最多投稿10篇。使用自己的部署环境时，配置逻辑绑定 `DB` 与 `BUCKET`；用户投稿数据不会随源码或构建产物导出。已授权的完整原评和精选树洞楼层可直接阅读；小红书、知乎等公开文章仅展示短摘、摘要及原站链接。
