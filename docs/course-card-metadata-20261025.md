# 课程卡片与手册补充

卡片与详情标题新增学分、开课院系、英语课程分级。学分按所选学期/班型内的教学班字段展示，多学分值并列，不取平均。院系优先使用2026春秋教务查询的openDepartment，辅以用户开课PDF的院系列、分节标题和变更表，不使用限选对象或教师任职单位推断。目前3524个教学班、991组课程有明确院系；其余保留待补。

英语等级按2026公共方案明确的课程清单对应45门课：综合英语、进阶、高阶。高级英语GEEF20012是进阶；学术英语（综合）GEEF30023是高阶。预科与GEEC英语通识课程不按名称套入分级，学生A/B/Y入学级别不当作课程等级。搜索仍只匹配课号、课名、教师与拼音。

新增206页通识手册（封面2024、正文页眉2023）和141页2024体育手册。通识125份课程资料映射111门课，按历史主讲教师分别保留；体育51条项目/部分说明映射90门课。合计201门课程在大纲、资料、总结中可查。材料链接跳到PDF实际页，其他部分仅展示文字来源。手册资料不计入匿名课评数量，也不覆盖当前班大纲与评分。

原资料异常单独处理：通识若干考核权重不全或疑似串页，仅保留可靠部分；体育太极推手章节误用了咏春拳内容，不采用对应训练细节。课程身体素质35%与国家体测评分分开；体育必修仍沿用用户确认的固定等第映射。
