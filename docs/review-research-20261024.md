# 2026-10-24 课评补搜与复读

本轮加入128条补充整理记录，覆盖82组课程。其中51条来自公开网页、知乎和小红书，77条来自树洞课评专区和普通帖子。记录按课程、教师、学期、班型组织；它们不是128个独立评价样本，同一作者跨平台同步的经历不重复计算为独立样本。

## 检索和阅读范围

- 课评专区：258组查询，重新取得274个课程组、1628条去重评价。对比旧库，新检出7条此前未收录的教师相关评价；不是7条新发表的评价。原有评价未发现正文变更。
- 长评复读：完整阅读70条旧库长评，另阅读7条新检出评价。和已有阅读账本取并集后，新增74个已读编号，累计2939个已读编号。未将“取得全文”标记为“读完全文”。
- 普通树洞：297组查询，返回7343条去重楼层、涉及5791帖；取得89帖共4351层。重点完整复读9帖、787层，并把后续纠正纳入判断。75组查询达到分页上限，本轮不声称穷尽所有帖子。
- Edge：20组已核对实际导航的关键词检索，包含课程名、教师名和常见缩写。定向阅读小红书7篇笔记的正文及60张配图，以及用户提供的知乎回答；搜索结果页的AI自动汇总没有作为课评来源。
- 微信公众号内容采用可读的公开转载；教师公布的班级统计、校方采访、团学联指南和学生亲历分开标注。

重点覆盖数院英才与荣誉课程、大学物理A/B、ICS、数据结构、AI双学位、思政与通识课程。创新创业关键词有检索结果，但本轮没有找到足以新增具体教师判断的学生亲历长评。

## 资料归属

《谈艺录》导读（GECC10021）与《卡夫卡与全球现代性》（GECC10049）都列入2026公共方案课程池，新增为历史参考课程，尚未确认本学期教学班。历史课只在“全部学期、全部班型”条件下出现，不冒充本期开课，也不凭旧经历生成当前GPA教学班。

教务处公开通识手册已保存为原版离线PDF：第31页为《谈艺录》，第87页为卡夫卡课程。新旧课程代码分别保留；手册考核与学生本人修读描述明确区分。

来源在“树洞评论”和“对比和总结”显示为平台、作者或匿名编号、文章标题、楼层及学期。仅“课程资料”保留链接；课程搜索仍只匹配正式课号、课程名/别名、教师名及拼音首字母。
